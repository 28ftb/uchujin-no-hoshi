## 準備
- [ ] Console の「Clear on Play」をオン、「Error Pause」をオンにする（最初の例外で止まる）。
- [ ] Game ビューの解像度は 1920×1080（16:9）にする。UI は高さ 1080 の仮想解像度で描いている。
- [ ] 以前のセーブを消したい時は、メニュー「宇宙人の星 → すべてのセーブを削除」。
- [ ] 再生しても何も起きない時は、メニュー「宇宙人の星 → 自動起動を切り替える」で自動起動が無効になっていないか確認する。

## どの段階でも見ること（共通）
- **文字化け・豆腐（□）**：日本語が □ や ? にならないか。OS フォント（Yu Gothic UI → Meiryo …）を使う設計（`Core/UI/UIStyles.cs`）。
- **ピンク色のマテリアル**：地面・建物・住民・パーティクルがピンクになっていないか。ピンクなら Shader.Find が失敗している（`Core/Visual/MaterialCache`、`World/Scene/MeshBatcher.Unlit`、`Weather/WeatherVisuals.UnlitMat`、`Rocket/RocketShipView.ParticleMaterial`）。
- **Console**：赤いエラー・例外、黄色の警告（特に `[XxxSystem.YYY]` で始まるもの＝各システムの例外を Game が受け止めたもの）。
- **フレームレート**：Stats で極端に重くないか（地形・街灯・住民16人）。

## 1. 再生 → タイトル
- [ ] 再生すると Hierarchy に `Game` が自動で作られ、タイトル画面が出る。
- [ ] タイトルロゴ「宇宙人の星」、副題、「プロトタイプ版」が読める。
- [ ] 背景の 3D（星空・輪のある星・ロケット・流れ星）が見える。ピンクや真っ黒でない。
- [ ] ボタン：新しい星で始める／続きから／友達の星へ行く／設定／クレジット／ゲームを終了 が押せる。
- [ ] 「設定」で言語を English に切り替えて戻せる。

## 2. キャラクターメイク
- [ ] 「新しい星で始める」→ シード入力（空欄でランダム）・星の呼び名・「プロローグを飛ばす」（今回は**オフ**のまま）→「次へ」。
- [ ] 3D プレビューにアバターが表示される（RenderTexture が真っ黒・真っ白でない）。ドラッグで回る。
- [ ] 体型・顔・目・髪・服・靴・アクセサリー・色を変えるとプレビューに反映される。「おまかせ」「最初に戻す」が動く。
- [ ] 髪・帽子と目が重ならないか、半透明（ヘルメット・メガネ）がおかしくないか。
- [ ] 名前入力欄で日本語入力（IME）ができるか。

## 3. プロローグ
- [ ] 光跡 → 衝撃（フラッシュ・揺れ・煙・火花）→ 主人公の脱出 の演出が流れる。シネマ帯と字幕が出る。
- [ ] 宇宙語の字幕（宇宙文字・表面形）が表示され、日本語訳は**出ない**こと（仕様どおり）。
- [ ] 操作できる区間：WASD で動ける。案内役（まんまる系の住民）が近づくと驚いて逃げる。
- [ ] 修理屋・料理好きが来て、料理を1つもらえる（持ち物に入る）。
- [ ] 「ついていく区間」で案内役が先導し、暗転して村へ。カメラが建物や木に隠れないか。
- [ ] スキップ：Esc / Enter / Space を2秒以内に2回押すと飛ばせる。

## 4. 自由行動
- [ ] 移動（WASD・矢印、Shift で走る）、カメラ（右ドラッグ回転・ホイール・Z/C・V で方式切替）。
- [ ] HUD（時刻・日付・お金・道具）が読める。時間が進む。
- [ ] 地形・道路・村の建物・看板（宇宙文字）・ロケット・街灯が表示される。ピンクの物がない。
- [ ] Tab でタブレット、M で地図、I で持ち物、R で道具切替、1〜0 で持ち物を持つ。
- [ ] 天候の演出（雨などのパーティクル）が出た時にピンクの四角にならないか。
- [ ] 家・鉱山に入ると屋内の照明に切り替わる。

## 5. 住民と会話
- [ ] 住民に近づいて E で会話ウィンドウが開く。吹き出しに宇宙語が出る。
- [ ] 吹き出しの単語をクリックすると辞書に登録できる。K で聞いた言葉を音声カードに保存できる。
- [ ] G で身振り（主人公は話さない）。住民が表情・身振りで反応する。
- [ ] 会話ウィンドウと吹き出しが重ならないか、単語ボタンが折り返されるか。
- [ ] 住民同士の立ち話の吹き出しが出る。

## 6. 商店（セルフ販売）
- [ ] 主人公の商店（しましまのひさし）に行き、棚で E → 持ち物から並べる（個数・値段）。
- [ ] 値札（数字・★）が読める。営業時間の看板（営業中/準備中）が見える。
- [ ] 営業時間中（初期 9〜18時）に住民が来て品定め → 買う → 反応の発話。お金が増える。
- [ ] マネピ（止まり木）の伝言・タブレットの「お店」アプリで売上が見える。

## 7. 睡眠
- [ ] 自宅の扉で E「家に入る」→ 家の中が表示される（壁の切り取り表示）。
- [ ] ベッドで E →「眠る（朝まで）」→ 確認 → 暗転して翌朝。日付が1日進む。
- [ ] 日付更新の時に Console に例外が出ない（全システムの OnDayEnded / OnDayStarted が走る。鉱石の再配置・作物の成長・住民の予定など）。

## 8. セーブ
- [ ] Esc → メニュー →「セーブする」で「セーブしました」の表示。F5 のクイックセーブも同様。
- [ ] メニュー「宇宙人の星 → セーブフォルダを開く」でファイルができている（`%USERPROFILE%\AppData\LocalLow\DefaultCompany\uchujin-no-hoshi\Saves`）。
- [ ] 「セーブしてタイトルへ」でタイトルに戻る。

## 9. ロード
- [ ] タイトル「続きから」にスロット（星の名前・日数・お金）が出る →「遊ぶ」。
- [ ] 「（日付） を読み込みました」が出て、同じ日付・同じお金・同じ持ち物で再開する。
  （位置はセーブされず、毎回「不時着した場所」（`WorldLayout.PlayerSpawn`）から始まる。今の仕様）
- [ ] 商店の棚、辞書の登録内容、住民辞典、天気が保存前と同じ。
- [ ] 一度再生を止めて、もう一度再生 →「続きから」でも読み込める（ドメインリロード後）。

## 問題を見つけたら
- Console のエラーを右クリック →「Copy」で全文（スタックトレース付き）を控える。
- ピンク・文字化けはスクリーンショットを撮る。
- どの段階で起きたか（上の番号）を添える。
