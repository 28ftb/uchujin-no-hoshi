## 0. 本資料の読み方と前提

### 0.1 記載区分

- **【既存決定】**：ほかの企画・仕様で、すでに明確に採用された方針。
- **【採用方向】**：今回の会話で、目指す方向として選ばれたもの。数値・細部は調整対象。
- **【提案】**：面白さを高めるために検討している要素。勝手に確定仕様として扱わない。
- **【未決定】**：引き続き設計を要する要素。

### 0.2 重要な前提

1. 【既存決定】本作は、**宇宙語が通じない星でかわいい宇宙人たちと暮らし、言葉や住民のことを理解し、お金を稼いでロケットを修理し故郷に帰る生活シミュレーション**である。
2. 【採用方向】**生き物取りに登場する宇宙生物は50種類程度**を目指す。今回は50種類の具体的な仮案を用意する。正式名称・最終的な種数は未確定。
3. 【採用方向】**四季は設けない予定**。生物の出現条件を春夏秋冬に依存させない。出現は場所・時間帯・天候・環境・生態などで変える。
4. 【採用方向】農業で働く宇宙生物10種類を含め、残り40種類にも捕獲・観察・飼育などの楽しみを用意する。
5. 【既存決定】宇宙語の単語・語順・文法は星のシードに応じて変わる。**正しい意味をゲーム側が自動で辞書に記入しない**。
6. 【既存決定】マルチプレイで他プレイヤーの星へ訪問しても、宇宙語辞書は自動配布しない。
7. 【方針】制作効率を理由に、生物の数や面白さを勝手に削らない。一方で未検討の仕様を説明なしに決定扱いしない。

> **対象範囲**：本書の「生き物取り」50種類は、基本的に陸上・空中・地中・浅い水辺などに暮らす捕獲対象生物。**釣り竿で釣る魚は、別の魚釣りシステムの対象**とする。知的な村の住民（宇宙人）とも区別する。

## 1. コンセプト

### 1.1 核となる面白さ【採用方向】

**「見つける → 生態を観察する → 工夫して捕まえる → 一緒に暮らす → さらに発見する」**。

- 森、草原、川辺、村、鉱山などを歩き、かわいい宇宙生物を発見する。
- 生物ごとに行動・好む環境・逃げ方・捕まえ方が異なる。
- 捕まえた生物は、農場の手伝い、ペット、観賞、住民への贈り物、商店販売などに活用できる。
- 生物たちは捕獲後も遊ぶ・食べる・眠る・ほかの生物と交流するなど、生き物らしく振る舞う。
- 図鑑とメモを通じて、生態と宇宙語をプレイヤー自身が理解していく。

**農業に役立つことだけが生物の価値ではない。** 何もしなくてもかわいい生物、観察するだけで面白い生物、珍しい場所でしか出会えない生物も重要。

### 1.2 ゲーム全体とのつながり【既存方向性】

- **農業**：捕獲・育成した宇宙生物が農作業を手伝う。
- **商店**：捕まえた生物や関連商品を棚に陳列し、住民が自動購入する。
- **住民交流**：好みの生物、飼っている生物、会話や依頼から住民の性格を知る。
- **宇宙語**：生物の名前、行動、住民の反応から単語や文法を推測する。
- **鉱山**：地下固有の生物を発見する。
- **釣り**：同じ水辺で魚釣りと生き物取りの両方を楽しめる。
- **住居・農場**：お気に入りの生物と暮らし、住み場所や景観を整える。

## 4. 出現条件：四季なしの世界【採用方向】

**四季を採用せず、春限定・夏限定・秋限定・冬限定という出現制限は設けない。**

生物の出現差は、次の要素で表現する案。

| 要素 | 具体例 |
|---|---|
| 生息場所 | 村・庭・森林・草原・池・海岸・鉱山・高台 |
| 時間帯 | 朝に見つかるツユツユ、夜に光るヒカリムシ・ランプル・ユメボシ |
| 天候 | 雨の日に現れやすいミズガサ、晴れた場所で眠るネムリコ |
| 周囲の植物 | 花畑にハナピカ、果樹付近にタネパタ・モギモギ |
| 物や住み場所 | 箱にハコネ、灯りにランプル、池に水辺生物 |
| 周辺の生物 | 特定の生物と一緒に行動する、ほかの生物を追う |
| 個体・日ごとの変化 | 同じ場所でも見られる個体や数が変わる |

- 【提案】**基本的に一年中探せる**ようにする。時間帯・天候・配置条件など、観察と行動で遭遇機会を作れることを重視。
- 【提案】生き物を見つけるための情報は、周囲の見た目、生物の行動、住民の実演や会話から得られるようにする。
- 【未決定】天候の種類、発生頻度、時間帯区分、希少生物の確率、出現地点数、プレイヤーが同時に見られる個体数。

**既存資料との差分**：農業・農場仕様案 v0.2 にある「春夏秋冬を採用する場合」という季節案は、本書の**四季を設けない方向性**に合わせて再検討する。生物の季節限定出現は前提としない。農業の作物側も別途整合を取る。

## 5. 捕獲システム

### 5.1 基本行動【提案】

1. 生息地へ出かけ、生物の姿や痕跡を見つける。
2. 動き・逃げ方・休む瞬間・好むものを観察する。
3. 網、忍び足、餌、罠、環境の工夫などで捕獲に挑戦する。
4. 捕獲した生物の種類・個体を確認し、飼育・売却・プレゼントなどの使い道を選ぶ。
5. 野生で再び観察したり、飼育によって新しい行動を見つけたりする。

### 5.2 捕獲のタイプ【提案】

| 捕獲タイプ | 遊び方 | 生物の例 |
|---|---|---|
| 通常捕獲 | 網を使って捕まえる | ミズプク、モフピ |
| 忍び寄り | 気づかれずに近づく | ピョコロ、タネパタ |
| タイミング | 着地・休息などの隙を狙う | クルマリ、カワハネ |
| 餌で誘う | 好物を置いて近寄らせる | ホリモグ、ポケットン |
| 発見型 | 擬態や隠れ場所を見抜く | ハッパリ、イワネム |
| 環境誘致 | 好む場所を作り、姿を現したところで捕獲 | ハナピカ、ランプル |

基本の捕獲操作を共有しつつ、**生物ごとの習性を知るほど捕まえやすくなる**ことが狙い。すべての種に個別の難しいミニゲームを作る、という意味ではない。

捕獲失敗時は逃げられる場合があるが、再挑戦できるようにする方向。

### 5.3 道具の候補【提案】

| 道具 | 用途・強化案 |
|---|---|
| 虫取り網 | 基本の捕獲。強化すると振る速度や範囲が向上する案 |
| 捕獲用の餌 | 好む生物を誘い出す |
| 罠 | すばしっこい生物や巣穴の生物を捕まえる |
| 生物探知道具 | 隠れている生物の手掛かりを見つける |
| 捕獲容器 | 捕まえた生物を持ち運ぶ。扱える大きさの違いも候補 |

道具の正確な種類、強化段階、捕獲操作、所持できる個体数などは【未決定】。

### 5.4 生き物取りレベル・名人【提案】

- 捕獲や観察に応じて、経験値や成長を得る仕組み。
- レベルや道具によって、動作速度・捕獲範囲・警戒されにくさなどが改善する案。
- 村の虫取り名人・生物研究家などから、忍び足、網さばき、餌の使い方、観察のコツを教わる案。
- 技術は言葉の意味が分からなくても、**実演・身振りを見て学べる**ようにする方向。

レベル上限、成長の数値、具体的な技の種類、住民との友好度条件は【未決定】。

## 6. 捕獲後の使い道と飼育

### 6.1 用途【採用方向／提案】

| 用途 | 内容 |
|---|---|
| 農業 | 農業お手伝い生物を農場に住まわせ、農作業に協力してもらう |
| ペット | 自宅・庭・農場などで一緒に暮らす |
| 観賞・展示 | 生物に合った飼育ケースや住み場所を用意して眺める |
| 交流・贈り物 | 好きな住民へ生物をプレゼントし、反応を見る |
| クエスト | 指定生物の捕獲・発見・観察に関する依頼 |
| 商店 | 生物を棚に陳列して価格を設定し、住民に自動販売する |
| 育成・繁殖 | 個体を育てたり、条件によって子どもが生まれたりする仕組みの候補 |

すべての種が農業の仕事をするわけではない。一方で、農業生物もペットとして楽しめる。

### 6.2 飼育環境と行動【提案】

- 池、花畑、巣穴、止まり木、箱、暖かい寝床、灯り、岩、水槽など、生物の好みに応じた場所を作る。
- 生物は仕事以外にも、眠る、遊ぶ、餌を食べる、ほかの生物と過ごすなどの行動を取る。
- なでる、好物を与える、近づくと寄ってくるなど、個体との交流も候補。
- 例えばハコネは箱に入り、ネムリコは日なたで眠り、マネピは主人公の仕草を真似する。

飼育が毎日の義務的な操作ばかりになるのではなく、**かわいい生態を観察し、好きな環境を整える楽しさ**を重視する。

### 6.3 個体差・成長・繁殖【提案】

同じ種類でも次のような個性を持つ案。

- **外見**：大きさ、色、模様、希少な色違いなど。
- **行動**：性格、活動量、好きな場所、仕草。
- **能力**：農業の得意分野、作業速度、作業範囲など（該当する生物のみ）。
- **成長**：小さい姿から大きくなる、模様が変化する、一部の能力が増す。
- **繁殖**：一部の種で子どもが生まれ、親と異なる色や模様が現れる可能性。

**育成段階・繁殖条件・個体差の生成方法・寿命・餌やりの必要性・売却時の扱いは未決定**。現時点で一律の数値や制限を設定しない。

## 7. 生物同士の交流【提案】

生物同士が出会ったとき、種類の組み合わせによって固有の行動を見せる案。

| 組み合わせ | 一緒にいるときの行動例 |
|---|---|
| クルマリ ＋ ピョコロ | 転がるクルマリをピョコロが追いかける |
| モフピ ＋ ネムリコ | 丸くなって一緒に眠る |
| ハナピカ ＋ フワタネ | 花畑で一緒に飛び回る |
| ランプル ＋ ヒカリムシ | 夜に交互に光りながら遊ぶ |
| ハコネ ＋ ツミツミ | 集めた小石を箱にしまうような遊びをする |
| ミズプク ＋ アワリン | 水場で一緒に水遊びをする |
| マネピ ＋ トントン | トントンのリズムをマネピが真似する |

このほかにも、群れで移動する、ほかの生物を追う、寄り添う、発光を合わせるなどの生態を用意する案。

**観察する価値**を作ることが目的。何かを組み合わせるたびに必ず能力アップを発生させる必要はない。行動・専用アニメーションだけで楽しい組み合わせもあってよい。

## 8. 農業との連携【既存方向性／提案】

### 8.1 農場の自動化

農場は、序盤の手作業から、かわいい宇宙生物たちの協力によって賑やかに発展していく。

| 生物 | 主な担当 | 仕事の例 |
|---|---|---|
| ミズプク | 水やり | 朝、畑に水をまく |
| ホリモグ | 耕作 | 空いた畑を耕す |
| タネパタ | 種まき | 指定された種を空き畑に植える |
| モギモギ | 収穫 | 実った作物を収穫箱に入れる |
| ツチポン | 土壌 | 土を豊かにして品質向上を補助 |
| ハナピカ | 受粉 | 花に集まり、収量などに影響 |
| ヒカリムシ | 特殊育成 | 光を好む作物の育成を助ける |
| ハコバチ | 運搬 | 収穫箱から倉庫へ運ぶ |
| ポカリス | 保温 | 周囲の温度を調整する |
| タネコロ | 種 | 種の回収・増殖を補助する |

**農業の自動化を生物に担ってもらう**方向は維持する。プレイヤーのクワ・じょうろ等の手作業用道具は併存させる案。

### 8.2 生物同士の協力【提案】

| 組み合わせ | 効果・流れの例 |
|---|---|
| ミズプク＋ツチポン | 水やりと土壌改良が組み合わさる |
| ホリモグ＋タネパタ | 耕してから種をまく作業が続く |
| モギモギ＋ハコバチ | 収穫と倉庫への運搬が続く |
| ハナピカ＋ヒカリムシ | 特殊な受粉・花色の変化が起こることがある |

### 8.3 生物による作物の変化【提案】

- 収穫量が変わる。
- 高品質・大きな作物が育ちやすくなる。
- 一部の作物では、光り方や色が変わった珍しい個体が生まれる。
- 農場の環境を変えることで、別の野生生物を呼び寄せられる。

**重要**：生物が作物を自動収穫しても、収穫物を**勝手に商店へ出品・販売しない**。商店の棚と価格はプレイヤーが管理するという既存の商店方針を守る。

農業用生物の作業半径、速度、成長効果、指示UI、上限数などは【未決定】。詳細は農業・農場仕様書側で検討する。

## 9. 農場・自宅への自然誘致【提案】

野生生物を捕まえるだけでなく、**好みの環境を作ると遊びに来る**仕組みを検討する。

| 農場・自宅に作るもの | 遊びに来る生物の例 |
|---|---|
| 小さな池・水場 | ミズプク、アワリン |
| 花畑 | ハナピカ、フワタネ |
| 果樹・木の実 | タネパタ、モギモギ、タネコロ |
| 箱・物置 | ハコネ |
| 灯り | ランプル、ヒカリムシ |
| 岩・土・巣穴 | ホリモグ、ポケットン |

訪れた生物はそのまま観察することもでき、捕まえたり仲間にしたりすることも可能にする案。

**農場を整えることが生き物探しになる**のが狙い。誘致の条件、出現頻度、帰るタイミング、住み着きの条件は未決定。

## 10. 生き物図鑑・宇宙語辞書・住民辞典

### 10.1 生き物図鑑【採用方向】

50種類の生物について、プレイヤー自身が発見・観察したことを記録できる図鑑を設ける。

**自動記録してよい客観的情報の案**

- 初めて発見・捕獲した記録
- 捕獲した数
- 実際に見つけた場所や時間帯
- 観察した行動の履歴
- 飼育している個体の外見や大きさ

**プレイヤーが自由に書く内容の案**

- 仮の名前・呼び名
- 好物、好きな場所、習性
- 捕獲方法のメモ
- 生物同士の関係や農業での能力についての推測
- 住民から聞いた言葉・気になった場面

自由メモの誤りをゲームが勝手に正解へ書き換えない。図鑑の名前欄・正式名の扱い、観察履歴の自動生成、自由記述欄の構造は未決定。

### 10.2 宇宙語辞書との連携【既存決定／提案】

- 宇宙人が生き物を指さして話す、生物が飛ぶのを見て話す、餌を与えるなど、行動と言葉の対応から意味を推測する。
- 同じ言葉が別の状況でも使われ、仮説を確かめられるようにする。
- 生物図鑑に、宇宙語の単語・会話・住民から聞いた表現のメモを残せる案。
- 正しい訳を自動で教えない。宇宙語の文法・語彙は星のシードごとに変わる。

### 10.3 住民辞典と顔付き付箋【既存方向性／提案】

- どの住民がどの生物を飼っているか、どんな生物を好むかを観察・記録する。
- 生物をプレゼントした反応や、住民が商店で買った履歴を住民辞典へ記録する。
- 住民が残した**顔付き付箋**を、住民辞典や生き物図鑑に保存する案。
- 付箋の宇宙語は元のまま残し、本人の推測を追記できる。

**3つの本の役割**

| 記録するもの | 役割 |
|---|---|
| **宇宙語辞書** | 言葉と文法の意味を推測する |
| **住民辞典** | 住民の好み・性格・関係・思い出を記録する |
| **生き物図鑑** | 生物の習性・生息地・捕まえ方・成長を記録する |

## 11. 住民交流・クエスト・商店

### 11.1 住民交流【提案】

- 生物が好きな住民、飼育が得意な住民、珍獣を集める住民、虫取り名人などがいる。
- 住民が実際に生物を飼い、庭や家で生物と暮らしている。
- 生物を見せたりプレゼントしたりすると、住民ごとの反応が返ってくる。
- 住民との交流によって、生物の行動・好物・捕まえ方についての情報が得られる。
- 親しい住民から生物や卵を譲り受けるイベントも候補。

### 11.2 依頼の例【提案】

- 特定の生物を捕まえてほしい。
- 珍しい色の個体を見せてほしい。
- 住民が飼っている生物のために餌を集めてほしい。
- ある場所に出現する生物を観察してほしい。
- 農場に生物を呼び寄せる環境づくりを手伝ってほしい。

宇宙語が分からなくても、生物の絵・行動・身振りなどを手掛かりに内容を推測できるようにする。クエスト報酬とイベントの固定条件は未決定。

### 11.3 商店での販売と付箋【既存決定／提案】

商店は、**棚に置いた商品を住民が自分で購入するセルフ販売方式**。生物を販売対象にする案も維持する。

| 貼り紙・付箋の内部的な意味 | 状況例 |
|---|---|
| かわいい | 愛らしいペットを見つけた |
| 珍しい | 希少生物を見つけた |
| 高い | 値付けが高いと感じた |
| 大好き | 好みの生物を購入した |
| もっと欲しい | 欲しい生物が売り切れた |

実際の貼り紙に表示するのは星の**宇宙語**。住民の顔と購入・閲覧した状況を手掛かりに、プレイヤーが意味を推測する。

【提案】住民が商店で購入した生物を自宅で飼い始めるなど、**購入後の生活に反映**させると、商店と住民の日常が自然につながる。

## 12. マルチプレイ【既存方向性／提案】

- 友達と一緒に野生生物を探し、捕獲する。
- 捕まえた生物や希少な色の個体を見せ合う。
- 他プレイヤーの星で生物を観察したり、捕まえたりする。
- 生物のプレゼントや交換を可能にする案。
- 訪問先では**その星の宇宙語**が使われ、辞書は自動配布しない。

**未決定**：捕獲の所有権、ゲストが捕まえた生物の持ち帰り、交換UI、同時出現の同期、繁殖・飼育データの保存先など。

**重要**：星のシードごとに生物の種類・出現確率・色・能力まで変えるかは**未決定**。現時点で決まっているシード差は宇宙語の単語・文法である。

## 13. 生き物取りのプレイ体験例【提案】

### 例A：普通の探索から農場が変わる

1. 川辺で水をため込んだミズプクを発見する。
2. 動きを観察して網で捕まえる。
3. 農場の池のそばに住まわせる。
4. 翌朝、ミズプクが畑に水をまいている姿を見る。
5. 図鑑に「水やりしてくれる」と書く。
6. 生物に興味を持った住民が話しかけてくる。宇宙語を聞き、辞書に推測を残す。

### 例B：捕まえない観察にも価値がある

1. 森でピョコロを見つけるが、追いかけると逃げられる。
2. 様子を見ていると、何度か跳ねた後に休憩することに気づく。
3. 生き物図鑑に「跳ねたあと止まる」とメモする。
4. 次に出会ったとき、休む瞬間を狙って捕まえる。

### 例C：村の暮らしとつながる

1. 住民の窓でマルマドを見かける。
2. 住民がマルマドを見て何か話しているが、まだ意味は分からない。
3. 後日、マルマドを自宅でも飼い、同じ行動を観察する。
4. その住民のページに、マルマドとの関係と発言のメモを残す。
5. 商店でマルマドに付いた顔付き付箋を見つけ、辞書・住民辞典・図鑑を行き来して考える。

### 設計上の最重要原則

**生き物を捕まえることが目的の終点ではない。**

50種類のかわいい宇宙生物が、それぞれの場所で自然に暮らしている。プレイヤーは見つけ、観察し、ときには捕まえて一緒に暮らす。農場が賑やかになり、住民との会話や商店での付箋から生態・好み・宇宙語について新しい発見がある。

**「生き物取り」それ自体が面白く、それでいて『宇宙人の星』の生活・住民・言語解読に自然につながること**を優先する。
