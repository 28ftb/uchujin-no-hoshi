# 宇宙人の星 — 住民生活・交流システム仕様案 v0.2

- **作成日**：2026年10月15日
- **位置付け**：住民の生活・交流に関する企画／詳細化のための暫定仕様書
- **対象**：住民の行動、仕事、経済、人間関係、記憶、住居、クエスト、引っ越し、宇宙語との連携、マルチプレイ
- **前提資料**：『宇宙人の星』企画 v0.1、ストーリー v0.2、宇宙語 v0.2、商店 v0.2、農業 v0.2、生き物取り v0.2、クエスト v0.2、タブレット・辞書・住民辞典 v0.3、および本企画のその後の会話

> **重要**：この文書は住民生活の「検討中の設計案」であり、内容すべてを確定した正本として扱わない。既存の決定事項、方向性、今回の提案、未決定事項を区別する。面白さを高める改善案は歓迎するが、未決定事項を勝手に確定しない。

## 0. 仕様の確度と前提

本書では次の区分を用いる。

| 区分 | 意味 |
|---|---|
| **【決定／既存方針】** | これまでの会話で明確に採用された内容、または一貫した方針 |
| **【採用方向】** | 採用する方向で検討しているが、詳細は未確定の内容 |
| **【提案】** | 今回の住民生活設計を具体化するための案。採用は未確定 |
| **【未決定】** | 今後、内容・規模・挙動を検討する事項 |

### 本作の中心コンセプト【決定／既存方針】

- 主人公は別宇宙から見知らぬ星に不時着し、現地の宇宙語が分からない状態で暮らし始める。
- 釣り・農業・鉱山・生き物取り・商店・クエストなどの日常を楽しみながら、住民の言葉と暮らしを理解する。
- お金を集め、宇宙船の修理部品を購入して、故郷に帰ることが大きな目標。
- 単語・文法は星のシードで変わり、同じ星の住民は原則として共通の宇宙語を用いる。
- プレイヤー自身がタブレットの宇宙語辞書・住民辞典に推測や思い出を記録する。ゲームが正答を書き込まない。
- 住民にはかわいい宇宙人の多様なデザインを用い、引っ越しによって村の顔ぶれが変化する。
- **四季は設けない方向**。住民の生活の変化は時間帯、天気、予定、行動、出来事などで表現する。

### 住民システムが目指す体験【採用方向】

**「住民が宇宙語を解読させるために存在する」のではなく、「住民たちがそれぞれの生活を送っているから、解読したくなる会話や出来事が生まれる」。**

- 主人公がいなくても住民同士の暮らしは続く。
- 昨日の出来事が今日の予定・会話・人間関係に影響する。
- 見た目や行動から推測した人物像が、言葉を覚えることで違って見えることもある。
- プレイヤーの商店、農場、プレゼントや行動も村の生活に影響する。
- 住民が引っ越した後も、関係や思い出の記録が残る。

## 1. 住民の基本情報【採用方向／提案】

住民一人ひとりに、見た目だけではない個性と生活情報を持たせる。

| 項目 | 内容 |
|---|---|
| 識別情報 | 同じ住民を継続して認識する内部ID |
| 名前 | 住民自身の名前。プレイヤーには最初から正解を開示しない |
| 種族・外見 | 既存の「かわいい宇宙人デザイン10系統」を活用 |
| 性格 | 社交性、好奇心、のんびり、几帳面、負けず嫌いなど |
| 仕事 | 鍛冶屋、修理屋、農家、釣り人、商人、料理人など |
| 趣味 | 釣り、採掘、園芸、生き物観察、料理、収集など |
| 好き嫌い | 商品、食べ物、魚、生物、色、活動などの好み |
| 住居 | 生活する家と、所有している物・家具 |
| 生活習慣 | 起床、仕事、食事、趣味、睡眠、よく訪れる場所 |
| 人間関係 | 家族、友人、仕事仲間、ライバル、苦手な相手など |
| 目標 | 今日したいこと、数日かけて取り組むこと、将来の夢 |
| 経験・記憶 | プレゼント、約束、喧嘩、助け合い、達成したことなど |

**種族と性格・仕事・趣味は固定して結び付けない。【採用方向】** さまざまな姿の宇宙人が、さまざまな生き方をしている村を目指す。

### 内部データの3層【提案】

1. **基本的な個性**：種族・外見・基礎性格・得意分野・基本的な好み。比較的変化しにくい。
2. **現在の状態**：所持金・持ち物・気分・予定・欲しいもの・現在の目標。日々変化する。
3. **経験・記憶**：誰と何をしたか、買ったもの、約束、引っ越し、過去のイベント。蓄積・更新される。

ゲーム内部にはこれらの情報が存在するが、**プレイヤーが住民辞典で最初から閲覧できるわけではない**。

## 2. 1日の生活【採用方向】

### 基本スケジュール

住民は仕事・食事・睡眠などの生活の基本を持ち、そこに趣味・天候・欲求・他者との約束・最近の出来事が加わって、その日の行動が決まる。

#### 例：鍛冶屋の宇宙人

| 時間帯 | 基本行動の例 |
|---|---|
| 朝 | 起床、食事、工房へ移動 |
| 午前 | 道具制作・修理・強化の仕事 |
| 昼 | 食事、住民との会話、外食することもある |
| 午後 | 工房で仕事、必要素材の買い物 |
| 夕方 | 閉店、広場や商店に立ち寄る |
| 夜 | 家で趣味・食事・睡眠 |

※ 時間帯は挙動の例であり、ゲーム内の実時刻や営業時間を確定するものではない。

### 予定を変える要素【提案】

- 趣味や性格：釣り好きなら川へ、社交的なら友達の家へ行きやすい。
- 天気：雨の日は家で過ごすなど、行動が変わる。
- 欲求：食事、買い物、休息、遊びなど。
- 所持金・在庫：欲しいものが買えるか、どの店へ向かうか。
- 友人関係：親しい相手と会う、喧嘩した相手を避ける。
- 予定・約束：一緒に釣りをする、翌日の作業を手伝う。
- 個別ストーリー：イベント期間中は特別な場所へ行く。
- 引っ越し準備：荷造り、友人への挨拶など。

#### 例：釣り好きの住民の7日間

| 日 | 行動例 |
|---|---|
| 1日目 | 朝から釣りに行く |
| 2日目 | 雨のため、家で釣り道具の手入れをする |
| 3日目 | 商店で釣り具を探す |
| 4日目 | 友達と一緒に釣りへ行く |
| 5日目 | 珍しい魚を釣り、広場で自慢する |
| 6日目 | 釣った魚を料理好きの住民に贈る |
| 7日目 | 家で休んだり趣味を楽しんだりする |

この表はあくまで「状況に応じて行動が変わる」例であり、固定の週間ルーチンではない。

## 3. 住民の短期・中期・長期目標【提案】

住民自身がやりたいことを持ち、それを日常生活の中で進める。

| 目標 | 内容 | 例 |
|---|---|---|
| **短期目標** | その日したいこと | 食事、買い物、散歩、釣り、友人との会話 |
| **中期目標** | 数日以上かけて進めること | 家具の購入、新しい料理、珍しい生物の飼育 |
| **長期目標** | 夢や生き方に関わること | 一流の鍛冶屋になる、自分の店を持つ、引っ越す |

### 鍛冶屋の例

- 短期：今日依頼されたツルハシを作る。
- 中期：珍しい鉱石を使って新しい道具を完成させる。
- 長期：自分だけの最高傑作を作る。

プレイヤーが鉱石を届ければ進行を手伝えるが、手伝わなくても鍛冶屋は別の方法を探す。達成後は次の目標が生まれる場合もある。

**「主人公に助けてもらうまで、住民の人生が停止する」設計にはしない。【採用方向】**

## 4. 仕事と村の経済【提案】

住民は設定上だけでなく、実際に仕事や買い物を行う。

| 仕事 | 実際の生活行動・役割 |
|---|---|
| 鍛冶屋 | ツルハシ・農具などの制作と強化 |
| 修理屋 | 機械や宇宙船を修理する |
| 農家・種屋 | 作物を育てる、種を仕入れ販売する |
| 釣り人 | 魚を釣る、釣り具や餌を購入する |
| 料理人 | 食材を集め、料理を作り、人に振る舞う |
| 商人 | 仕入れ、販売、買い物を行う |
| 採掘師 | 鉱山で鉱石を集める |
| 生物研究家 | 宇宙生物を観察し、飼育する |
| 家具職人 | 素材から家具を制作する |
| 配達員 | 商品やマネピの伝言を届ける |

### 所持金・持ち物・購入【提案】

- 住民には収入・所持金・買い物用の予算がある。
- 欲しいもの、好み、価格、所持金、店の在庫などで購入を判断する。
- 節約家、高級品好き、収集家など、性格や趣味によって購買傾向が変わる。
- 村の店だけでなく、プレイヤーの商店でも買い物をする。
- 欲しい品物が売り切れていたら、別の店を探したり、住民やマネピに要望を伝えたりすることがある。

### 買った物が生活に残る【採用推奨】

| 購入物 | その後の行動例 |
|---|---|
| 食べ物 | 食べる、料理に使う、友人と分ける |
| 花 | 家に飾る、誰かにプレゼントする |
| 家具 | 家の中に設置する |
| 宇宙生物 | ペットとして飼い、世話をする |
| 釣り道具 | 釣りに持っていく |
| 宝石 | 自宅に飾る、贈り物にする |
| 種 | 自分の畑に植える |

#### 例：青い花が村の中を移動する

1. 主人公が青い花を育て、商店に陳列する。
2. 花好きの住民が購入する。
3. 住民が自宅の机に飾る。
4. 後日、友達にプレゼントすることもある。
5. 受け取った住民が自宅に飾ることもある。

「商品が売れた」で処理を終えず、**誰が何を買い、どう使ったかが、プレイヤーに観察できる変化として残る**ことを目指す。

### 引っ越しが商店に影響する【提案】

- 釣り好きの住民が来れば、釣り道具や魚の需要が変わる。
- 料理好きの住民が特定の料理を作り始めると、その材料の購入が増えることがある。
- 収集家が引っ越してくれば、珍しい生物や宝石が売れやすくなる可能性がある。

商店は従来どおり、**商品を並べて価格を決めれば、店番なしで住民が自動購入する方式【決定／既存方針】**。住民の生活システムは、この買い物の理由と購入後の行動を支える。

## 5. 住民同士の人間関係【採用方向／提案】

住民同士には、友達・家族・仕事仲間・ライバル・苦手な相手など、多様な関係を持たせる。

### 関係を構成する要素【提案】

| 要素 | 意味 |
|---|---|
| 親しさ | どれくらい親しいか |
| 信頼 | 約束やお願いを任せられるか |
| 相性 | 性格・趣味・考え方が合うか |
| 最近の出来事 | 助け合い、プレゼント、喧嘩、仲直りなど |
| 関係の種類 | 家族、友人、仕事仲間、ライバルなど |

### 日常に反映される行動例

- 親友：一緒に遊び、家を訪ね、食事を共にする。
- 仕事仲間：材料を融通し合い、共同作業する。
- ライバル：釣りの結果や仕事の出来を競い合う。
- 仲が悪い：会う頻度が減り、距離を置くことがある。
- 家族：一緒に暮らし、食事や家事を助け合う。
- 恋人：デートや贈り物などを行う可能性がある（**恋愛・結婚は未決定**）。

### 関係は変化する【提案】

- 共通の趣味をきっかけに仲良くなる。
- 意見の不一致や出来事で喧嘩する。
- 時間の経過、謝罪、ほかの住民の仲介によって仲直りする。
- 友達が引っ越しても、その人について思い出したり話題にしたりする。

**住民同士の関係を、数値だけでなく行動から観察できるようにする。** いつも一緒だった2人が最近別々に過ごしている、といった変化も宇宙語解読の手掛かりになる。

## 6. 主人公との親交【採用方向】

プレイヤーと住民の間にも、交流によって変化する関係を持たせる。

| 主人公の行動 | 影響例 |
|---|---|
| 挨拶や会話 | 顔を覚えられ、親しみが増す |
| 一緒に釣り・農作業・生き物取り | 共通の思い出ができる |
| 好物を贈る | 喜ぶ、後日使う・飾るなど |
| 困りごとを手伝う | 信頼が深まる |
| 約束を守る | その住民の記憶に残る |
| 好きな商品を売る | 常連として店に通うことがある |
| 祭りや誕生日に参加 | 特別な交流イベントが発生することがある |

### 親交による反応の変化【提案】

- 遠くから手を振る。
- 主人公の家に遊びに来る。
- プレゼントをくれる。
- 釣りや散歩などに誘ってくれる。
- 個人的な悩みや夢を打ち明ける。
- 引っ越しを考えたときに相談してくる。

内部的に関係値を管理する案はあるが、**正確な数値をプレイヤーへ表示するかは未決定**。少なくとも、言葉や仕草、生活の変化から関係を感じられるようにする。

## 7. 主人公が村の話題になる【提案】

住民にとって、主人公は突然空から来た謎の存在。

最初は珍しがられるが、暮らしを続けると「あの釣りが上手な子」「大きな野菜を育てる子」「商店を経営している子」など、実際の行動に応じて話題になる。

| 主人公の行動 | 住民が話す内容の意味の例 |
|---|---|
| 毎日釣りをする | 「いつも川で釣りをしているね」 |
| 巨大な作物を育てる | 「すごく大きな野菜を作ったらしい」 |
| 商店が繁盛する | 「あの店は最近人気だね」 |
| 希少な宇宙生物を捕まえる | 「珍しい生き物を飼っている」 |
| 鉱山の深部へ進む | 「あんなに深い場所へ行ったらしい」 |
| 特定の住民とよく過ごす | 「最近あの2人は仲が良さそう」 |

もちろん、**画面に表示されるのは星の宇宙語**。プレイヤーが言葉を覚えるにつれて、自分のことが話題になっていたと分かる。

## 8. 住民の家・家具・持ち物【提案】

家は住民の性格・趣味・生活の変化が分かる場所とする。

- 釣り好きの部屋：釣り竿、魚の飾りなど。
- 花好きの部屋：花瓶や鉢植えが多い。
- 生物好きの部屋：ペットの住み場所がある。
- 収集家の部屋：集めた物が並ぶ。
- 几帳面／おおらかな住民：家具の並べ方や片付け方にも違いが出る。

### 生活に応じた家の変化

| 出来事 | 家への反映 |
|---|---|
| 家具を購入する | 新しい家具が置かれる |
| 花を購入する | 花瓶などに飾られる |
| 宇宙生物を迎える | ペットが家で生活する |
| 珍しい魚を釣る | 記念に飾る場合がある |
| 主人公から贈り物を受け取る | 大切に飾ったり、使ったりする |
| 趣味が変わる | 趣味に関する物が増える |
| 引っ越しが決まる | 家具が片付き、荷物が箱に詰められる |

**室内の変化自体が、住民の好みや最近の出来事を推測する手掛かり**になる。

## 9. 宇宙生物と住民の生活【採用方向／提案】

既存の生き物取り企画には**約50種類の宇宙生物**がいる方向。住民たちもそれらを飼育・観察・活用する。

- 農家が水やりを手伝うミズプクを飼っている。
- 生物好きの住民がモフピなどのペットをかわいがっている。
- 研究家が珍しい生物の生態を観察している。
- 商店や伝言広場ではマネピが伝言を預かっている。
- 主人公が連れた生物と住民のペットが一緒に遊ぶこともある。

住民も生物を商店で買い、家へ連れて帰り、生活に組み込む。**生物を利用するのが主人公だけではない世界**を目指す。

## 10. 日常イベント・生活変化・固有ストーリー【提案】

住民に起こるイベントは、以下の3層を組み合わせる。

| 種類 | 内容 | 例 |
|---|---|---|
| **日常の小イベント** | 普段の生活から起こる小さな出来事 | 一緒に食事、プレゼント、口喧嘩 |
| **生活変化イベント** | 数日以上続く行動や状態の変化 | ペットを迎える、転職、引っ越しを検討する |
| **固有ストーリー** | 住民それぞれの夢や過去を描く物語 | 鍛冶屋の最高傑作、料理人の夢 |

### 例：料理人になりたい住民

1. 普段から家で料理を練習する。
2. 必要な材料を探し、店で買ったり、ほかの住民に相談したりする。
3. 主人公が材料を提供すれば、料理の完成に役立つ。
4. 主人公が何もしなくても、別の方法で取り組みを続ける。
5. 料理が完成すると、友達へ振る舞ったり、仕事を変えたりする可能性がある。

**イベントを見終わったら元の状態へ戻すのではなく、結果が普段の生活に残る**方向。

### 自発的なお手伝い【既存クエスト案との連携】

住民が荷物を運んで困っている、材料を探しているなど、プレイヤーが「クエスト受注」をしなくても手伝える場面を設ける案。

また、住民を釣りへ誘ったり、趣味の合う2人を引き合わせたりして、プレイヤー自身が交流のきっかけを作ることも検討する。

## 11. 引っ越しシステム【決定／既存方針＋提案】

### 引っ越しの基本

**住民が引っ越してきたり、村を離れたりする仕組みを導入する方向は既存方針。** その具体的な条件・頻度・人数は未決定。

### 新しく引っ越してくる住民【採用方向】

- 空き家などに新しい住民が入居する。
- 引っ越し当日は荷物運びや片付けをしている。
- 新しい住民も仕事・趣味・生活習慣を持っている。
- 日が経つにつれてほかの住民との関係ができる。
- プレイヤーには、新しい住民の名前や性格が自動公開されない。

### 引っ越しを考えるきっかけ【提案】

| きっかけ | 例 |
|---|---|
| 仕事 | 別の村で新しい仕事が見つかる |
| 夢 | 修行や挑戦のために村を出たい |
| 家族 | 家族の近くで暮らしたい |
| 友人関係 | 親しい住民の近くへ移りたい |
| 好奇心 | ほかの土地で生活してみたい |
| 気分転換 | 違う環境で暮らしたい |

### 引っ越しまでの流れ【提案】

1. 引っ越しを考え始める。
2. 友人や主人公へ相談する、ほかの場所について調べる。
3. 引っ越しを決め、家具を片付けて荷物をまとめる。
4. 親しい住民と別れの挨拶をする。
5. 村を出ていき、空き家に別の住民が来る可能性が生まれる。

主人公が身振りなどで応援や引き留める意思を伝え、その後の判断に影響する案もある。ただし、**住民本人の意思も存在する**構造とする。

### 引っ越し後【採用方向／提案】

- 引っ越した住民の情報・思い出は住民辞典に残る。
- マネピ経由で近況の音声伝言が届くことがある。
- 村に遊びに戻ってきたり、再び引っ越してきたりする可能性がある。
- 残った住民が、引っ越した友達について話すことがある。

### 重要な仕事を持つ住民【提案】

鍛冶屋・修理屋などの重要施設は、担当住民の引っ越しによって永久に利用不能にならないよう、後任などの仕組みを検討する。**誰が引き継ぐか、どの職種を常設するかは未決定。**

## 12. 住民の名前・呼び方【採用方向／提案】

主人公は宇宙語を知らないため、**初めて会った宇宙人の名前も分からない**。

- 出会うと住民辞典に顔や識別用の記録ができる。
- プレイヤーは好きな仮名を入力できる。
- 例：「釣りのおじいちゃん」「青い花の子」「ねぼすけ」「鍛冶屋さん」。
- 住民同士が名前を呼び合っているのを観察し、本当の名前を推測できる。
- 名前だと思った言葉が、愛称や職業名の場合もある。
- 後から訂正でき、最後まで仮名で管理してもよい。

ゲーム内部の個体IDと、プレイヤー自身が書いた名前は分離する。

## 13. 宇宙語と住民の生活の整合性【決定／既存方針＋重要な提案】

住民の発言は、星ごとの共通宇宙語で表示する。**主人公が日本語などで通常会話をする仕組みは前提にしない。**

### 発言は実際の状態・出来事に基づく

| 内部的な発言の意味 | 生活上の裏付け |
|---|---|
| 「お腹がすいた」 | 食事を探したり食べたりする状態 |
| 「魚が欲しい」 | 魚を購入・釣り・依頼などで入手しようとする |
| 「明日は休み」 | 翌日の勤務予定が休みになっている |
| 「あの住民と遊びたい」 | 相手を誘ったり訪ねたりする意向がある |
| 「家具が欲しい」 | 買い物に行く・所持金を貯めるなどの目標がある |
| 「引っ越しを考えている」 | 住居や移住の検討が生活状態に反映される |
| 「青い花が好き」 | その花への好みが購入・展示などにも反映される |

予定が変更されること自体は自然だが、**会話と生活が無関係にランダム生成されない**ことが重要。

### 会話の3種類【提案】

1. **日常会話**：挨拶、天気、食べ物、趣味など。
2. **生活連動会話**：昨日の出来事、今日購入したもの、明日の予定、住民同士の出来事など。
3. **固有ストーリー会話**：夢、過去、大切な人間関係、特別なイベントなど。

### 会話生成の考え方【有力な設計案】

`住民の状態・目標・記憶 → 話す内容（意味） → 星の宇宙語へ変換 → 発言`

- 単語だけでなく語順・文法も星ごとの生成ルールに従う。
- 発言内容は住民の個性・現在の行動・記憶を参照する。
- ゲームの都合で主人公に正しい訳を自動提示しない。
- 身振り、表情、現物、行動の変化が意味を推理する手掛かりになる。

## 14. マネピによる伝言【最新の既存方針との連携】

以前の「店の商品に宇宙語の文字付箋を貼る」案は、**マネピによる音声・仕草の伝言へ変更**する方針。

### 住民がマネピを使う場面

- 主人公の商店に欲しい商品がなかったとき、感想や要望を伝える。
- 村の伝言広場で、住民が依頼を残す。
- 留守中の住民へ伝言を届ける。
- 引っ越した住民が、村の友人や主人公へ近況を知らせる。

マネピは、**預かった声・表情・仕草を再現する生物**。村でのあらゆる出来事を自動報告する監視装置ではない。

### タブレット・住民辞典への保存

- プレイヤーはマネピの伝言を音声記録として保存できる。
- 発言した住民、場所、日時、対象商品など、実際に確認できる事実を資料として整理する。
- 宇宙語の意味や住民の意図については、プレイヤーが自由に推測して記録する。
- 同じ音声カードを、宇宙語辞書と住民辞典の両方で参照できる。

主人公は宇宙人の文字も読めないという最新の検討を踏まえ、**書き文字の自動解読・正解提示は行わない**。宇宙語の発音表記・音声表示の詳細は、別途言語／タブレット仕様で詰める。

## 15. 長期的な記憶・出来事の蓄積【提案】

住民は以前経験した出来事を覚えており、後の行動や会話で参照できるようにする。

| 記憶 | 後の反応・行動例 |
|---|---|
| 主人公から魚をもらった | 感謝する、料理に使う、友達に話す |
| 一緒に釣りをした | 再び釣りへ誘う |
| 喧嘩をした | 相手と距離を置く |
| 仲直りした | 一緒に過ごすようになる |
| 新しい家具を買った | 自宅に飾り、別の住民がそれに反応する |
| 大きな目標を達成した | 新しい仕事や目標を考える |
| 友人が引っ越した | 思い出したり、マネピで伝言を送ったりする |

**記憶は内部データであり、プレイヤーのタブレットに全件自動開示しない。** プレイヤー自身が見聞きした出来事のみを保存し、意味を自由に記入できる。

## 19. 住民AIの考え方【有力な設計案】

住民が毎日暮らし、過去の出来事と未来の目標がつながるように、以下の流れを検討する。

1. **状態を参照する**：性格、仕事、持ち物、所持金、人間関係、現在の欲求、目標、記憶。
2. **予定を決める**：基本スケジュール、約束、天候、仕事、自由時間を組み合わせる。
3. **行動を選ぶ**：買い物、仕事、趣味、食事、会話、移動、プレゼントなど。
4. **行動を実行する**：実際の品物の購入・消費・設置、住民との交流など。
5. **結果を反映する**：持ち物・目標進行・人間関係・家の様子などを更新。
6. **出来事を記憶する**：重要な体験を後の行動と会話に利用。
7. **発言を生成する**：現在の状態・予定・記憶から意味を決め、その星の宇宙語で話す。

### 特に避ける設計

- 毎日全住民がまったく同じルート・同じ会話だけを繰り返す。
- 「魚が欲しい」と言うだけで、魚を求める行動を取らない。
- 商店で購入した家具やペットが、生活へ何も反映されない。
- 住民同士が交流しているように見えて、関係が変化しない。
- 主人公がクエストを引き受けるまで、住民の目標が停止する。
- ゲーム内部で判明している住民の本心や関係を、タブレットが勝手に正解として表示する。
- 住民が引っ越した瞬間、それまでの交流や思い出が消える。

この節は**実装方針の提案**であり、AI技術・行動プランナー・データ形式などを確定するものではない。

## 23. この仕様で目指す最終的なプレイ体験

主人公が数日間、釣りや鉱山に夢中になっていたとしても、村の住民たちは毎日の生活を続けている。

久しぶりに村を歩くと、住民の家に新しい花が飾られていたり、いつの間にかペットが増えていたり、友達同士の関係が変わっていたりする。引っ越しを考え始めた住民もいるかもしれない。

最初は何が起きたのか分からない。しかし、マネピの伝言や商店の購入履歴、住民の会話、家の様子を観察することで、少しずつ事情を推測できる。

そして宇宙語が分かるようになると、以前は見えていなかった住民の夢や悩み、友情、感謝の気持ちが理解できるようになる。

> **住民が宇宙語を解読させるために存在するのではなく、住民たちが自分の人生を生きているから、解読したくなる言葉が生まれる。**

この体験を『宇宙人の星』の住民生活システムの中心に据える。

**補足**：本書は仕様を固定しすぎるためのものではない。今後、ゲームとしての面白さを高める新しい案があれば積極的に検討し、採否を明示して更新する。制作負担の軽減だけを理由に、住民の個性や生活の面白さを勝手に削減しない。
