# 宇宙人の星 — タブレット・宇宙語辞書・住民辞典システム仕様案 v0.3

- **更新日**：2026年10月15日
- **対象**：タブレット／宇宙語辞書／住民辞典／資料ボックス／音声伝言生物「マネピ」／関連する記録機能
- **位置付け**：これまでの議論を統合した企画仕様案。実装詳細を確定するための設計書ではない。
- **参照する既存企画**：企画総合 v0.1、宇宙語 v0.2、商店 v0.2、クエスト v0.2、生き物取り v0.2、メインストーリー v0.2
- **重要な変更**：従来の「商店の商品に、宇宙語を文字で書いた顔付き付箋を残す」仕組みは**廃止**。代わりに、宇宙生物が声と仕草を覚えて再現する**音声伝言方式**を中心にする。

## 0. 仕様の扱い

本書では、記述の確定度を次のように分ける。

- **【決定】**：これまでの会話で明確に決まった原則、または明確に否定した内容。
- **【採用方向】**：おおむね採用する方向になっているが、具体的な形は変更可能な内容。
- **【提案】**：面白さを高めるために出した追加案。採用確定ではない。
- **【未決定】**：今後の設計で判断する項目。

**この資料では【提案】を勝手に【決定】へ昇格させない。** 特にタブレットの細かい画面、録音・発音表記、マネピの姿の模倣範囲、データ共有対象は引き続き調整可能とする。

## 1. 本システムの目的

『宇宙人の星』は、別宇宙から不時着した主人公が、言葉の通じない星でかわいい宇宙人たちと暮らし、商店・釣り・農業・採掘・生き物取り・クエストなどを楽しみながら、宇宙船を修理して故郷へ帰る生活シミュレーションゲームである。

宇宙語の**単語だけでなく文法も星のシードごとに異なる**。プレイヤーは住民の行動や実際の出来事を手掛かりに、意味を自分で推測し記録する。

記録システムが実現する楽しさは、大きく次の二つ。

1. **宇宙語辞書**：「この言葉はどういう意味だろう」「この星の文法はどうなっているのだろう」と考える。
2. **住民辞典**：「この子は誰だろう」「何が好きで、誰と仲が良く、何を考えているのだろう」と調べる。

さらに、保存した声や思い出を後から見返すことで、最初は分からなかった言葉や出来事を理解し直せるようにする。

### 全体原則

1. **【決定】正解の自動翻訳をしない。**
2. **【決定】自分の誤訳や思い違いも勝手に修正しない。**
3. **【決定】辞書はプレイヤー自身が書く。**
4. **【決定】訪問者へ辞書を自動配布しない。** 渡すかどうかはプレイヤー次第。
5. **【採用方向】商店の文字付箋をやめ、宇宙生物の音声伝言を使う。**
6. **【採用方向】記録・整理には主人公のタブレットを使う。**
7. **【採用方向】耳で聞いた宇宙語と、宇宙人が使う未知の書き文字は区別する。**
8. **【決定】完全解読はロケット修理・帰還の必須条件にしない。**

## 2. タブレットの世界設定

### 2.1 出自と役割【採用方向】

- 主人公が不時着した宇宙船から持ち出した、故郷側の携帯端末。
- 星に来た当初から利用できる。
- 主人公の使用言語でメニュー、入力、検索、保存を操作できる。
- 宇宙語の意味を知らないため、**翻訳機ではない**。
- 聞いた言葉・見たもの・写真・観察・思い出を記録し、後で調べるための道具。

### 2.2 ホーム画面【採用方向】

| 機能 | 主な用途 |
|---|---|
| **宇宙語辞書** | 単語・文章・語順・否定・疑問などの仮説を記録 |
| **住民辞典** | 住民の顔、仮名、好み、仕事、関係、思い出を記録 |
| **生き物図鑑** | 宇宙生物50種類などの発見・飼育・行動を記録 |
| **依頼帳** | 宇宙語の依頼、実際に提示された手掛かり、進行状態を記録 |
| **資料ボックス** | 会話、音声カード、伝言、写真、依頼記録などの保存元を一元管理 |

「生き物図鑑」と「依頼帳」の詳細内容は各システムの仕様書に準拠し、本書では辞書・住民辞典との連携に重点を置く。

### 2.3 タブレットの位置付け

**情報を保存・検索・比較する操作は便利にする。何を意味するかの判断はプレイヤーに任せる。**

例：マネピの声を再生して聞き比べることはできるが、タブレットが「今の発言は値段が高いという意味です」と判定してはいけない。

## 3. 宇宙人の文字と、聞こえる宇宙語を区別する

### 3.1 変更の理由【採用方向】

主人公は宇宙人の言語を知らず、宇宙人固有の文字も読めない。したがって、商店の商品に宇宙語の文字付箋を貼っても、読み取れる前提で推理させるのは不自然だった。

**商店の文字付箋は廃止し、住民の声・表情・仕草を使って意見を伝える。**

住民が文字を使わないという設定ではない。看板・本・手紙などに宇宙文字が存在してもよいが、主人公はそれを最初から読めるわけではない。

### 3.2 声と表記【提案・詳細未決定】

| 表現 | ゲーム上の扱い |
|---|---|
| **宇宙人の発声** | 星の言語規則に沿って発せられる宇宙語 |
| **ゲーム画面の発音表記** | 聞こえた音をプレイヤーが区別するための字幕・記録表記。宇宙人の正式な文字とは別物 |
| **宇宙人の書き文字** | 未知の文字。見ただけで読みや訳を自動開示しない |
| **タブレットのメニュー** | プレイヤーの選択した日本語・英語など |
| **プレイヤーの記入内容** | 本人が入力した自由メモ。自動で正誤判定しない |

発音表記の方式は、ローマ字ベース／表示言語別の読み方／独自表記などから今後決める。**宇宙文字を撮影しただけで、タブレットがその発音まで自動解析する機能は前提としない。**

また、否定の接辞などを研究できるよう、発音表記には同じ発話で一貫した綴り・分割規則が必要となる。

## 4. 伝言生物「マネピ」

### 4.1 基本設定【採用方向】

- 既存の宇宙生物一覧 **No.033「マネピ」** を発展させた存在。
- 声や動きを真似する性質を持つ、かわいい宇宙生物。
- この星では住民が伝言を残すために活用している、という生活文化を提案する。
- 商店の感想、村の依頼、個人間の伝言などに利用できる。
- 生き物取りの対象にもなり、捕獲・飼育・ふれあいができる。

### 4.2 記憶・再現するもの【採用方向／一部提案】

| 対象 | 扱い |
|---|---|
| 声・言葉 | **意味を勝手に変えず、正確に再現する**【採用方向】 |
| 声色・口調 | 発言した住民の特徴を真似する【提案】 |
| 表情・身振り | 発言時の仕草を再現する【採用方向】 |
| 外見の一部 | 角、触角、腕など発言者の特徴をデフォルメして模倣【提案】 |
| 発言の意味 | **マネピが自動翻訳して教えることはしない**【決定原則】 |

**否定を表す語尾や文法上の音の違いまで正確に再現することが重要。** マネピの真似が不正確すぎると、プレイヤーが文法を誤って学習する仕組みになってしまう。

### 4.3 全会話を自動記録する存在ではない【採用方向】

- 商店では、客がマネピへ伝えた感想・要望を覚える。
- 村の伝言広場では、住民が託した依頼を覚える。
- 個人伝言では、相手に届けたい内容を覚える。
- **その場にいた住民の発言を無制限に盗み聞きして録音する設定にはしない。**

記憶件数、複数伝言の再生順、伝言の消去ルールは未決定。

### 4.4 商店への配置【採用方向】

プレイヤーが商店に張り付く必要はない。商品の陳列・自動販売は従来どおり維持する。

1. プレイヤーが商品を並べ、値段を決める。
2. プレイヤーは釣りや農業など、別の活動へ出かける。
3. 客の宇宙人が来店し、商品を見て買う／買わずに帰る。
4. 感想や要望を伝えたい客がマネピに話しかける。
5. プレイヤーが店に戻り、マネピから伝言を聞く。
6. 気になる伝言をタブレットへ保存し、辞書・住民辞典で考察する。

**すべての客が毎回伝言する必要はない。**

### 4.5 言語解読との相性

例：星リンゴを300Gで陳列。ある住民が「モギラ！」と発言し、買わずに帰る。

翌日100Gに変更したら、同じ住民が「ピルナ！」と話して購入した。

プレイヤーは「モギラ＝高い？」「ピルナ＝安い？」と推理できる。しかし、その住民が買わなかった理由をゲームが自動で確定させるわけではない。商品への好みや所持金なども関係し得る。

※「モギラ」「ピルナ」および価格は説明用の仮例であり、固定の宇宙語・価格ではない。

## 5. 顔付き音声カード（旧・顔付き付箋の代替）

### 5.1 基本コンセプト【採用方向】

マネピが記憶した発話をタブレットに保存すると、**「顔付き音声カード」**として扱える。

従来の「誰が何を言ったかを住民辞典に残す」楽しさを、宇宙文字を読めることに依存せず維持する。

### 5.2 カード内容【提案】

| 項目 | 保存内容 | 種別 |
|---|---|---|
| 音声・発音 | 宇宙語の原音、必要なら発音表記 | 観察・記録 |
| 発言者の情報 | マネピが真似した声・表情・特徴、判別できるなら住民の顔 | 観察・記録 |
| 場所・日時 | 商店、広場など／記録時点 | 観察・記録 |
| 対象物 | どの商品や物を見ていたか、記録できる範囲 | 観察・記録 |
| 商品価格 | 当時の設定価格 | 商店の客観的記録 |
| 購入記録 | その商品を買ったか、何個買ったか | 商店の客観的記録 |
| 仕草・表情 | マネピが再現した演技など | 観察・記録 |
| 推測した意味 | 「高い？」「ほめた？」など | **プレイヤーの記入** |
| 住民に関する推測 | 「値段に厳しい？」など | **プレイヤーの記入** |

発言者の顔が判別できない場合、無理に「誰の発言か」を確定表示しない。マネピの再現を見た本人が記録を整理できる形を検討する。

**注意**：店の売上や商品価格は商店システムが持つ情報であり、マネピの発言だけから推定するわけではない。実際の記録の出典を混同しない。

### 5.3 原本と注釈を分ける【採用方向】

- 伝言の音声・再現内容・日時・対象商品などの**原記録は保持**する。
- プレイヤーが書いた訳や感想は**別の注釈として管理**する。
- 同じカードを宇宙語辞書・住民辞典の両方から参照できる。
- 一方のページから外しても、もう一方の記録まで消えない仕組みを提案する。

この分離により、誤解に気づいた後でも「なぜ当時こう考えたのか」を振り返れる。

## 6. 宇宙語辞書

### 6.1 根本方針【決定】

宇宙語辞書は**自分でつくる辞書**であり、システムが正解を記入する翻訳機ではない。

- 最初から住民の単語・文法が解説された辞書を配布しない。
- プレイヤーが仮説を書く。間違っていても、そのまま表示する。
- 記録を増やしたり、比較したり、自由に修正できる。
- 一つの単語に複数の意味の候補を持たせられる案とする。

### 6.2 記録単位【提案】

| 種類 | 記録したい内容 |
|---|---|
| 単語 | 原音・発音表記・推測訳・関連資料 |
| 文章 | 発話の原文と当時の状況 |
| 文法 | 語順、否定、疑問、時制、希望、格、所有などの仮説 |
| 語の一部 | 接頭辞・接尾辞など、気になった音のまとまり |
| 自由ページ | 文字、図、比較結果、自分なりの考察 |

### 6.3 単語ページ【提案】

- 宇宙語の発音表記（または原音から指定した区間）
- 意味の候補（複数入力可）
- 自分で付ける確信度・印（任意）
- 自由メモ
- 関連する音声カード、会話、依頼、観察記録
- 関連語へのリンク
- 後から自由編集

例：

> **モギラ**
>
> 仮説A：高い？
>
> 仮説B：高価な？
>
> 証拠：300Gのリンゴを見た客が発言／値下げ後は別の語を使った

※すべてプレイヤー自身の判断で記録する。ゲーム側は正誤を示さない。

### 6.4 文法研究【提案】

- 複数の発話を横に並べて比較する。
- 同じ音の部分や変化した語尾を自分で色分け・選択する。
- 語順・否定・疑問などの仮説を自由記述する。
- 各仮説に根拠となる音声カードを関連付ける。
- 星ごとの文法差があっても利用できるよう、単語単位だけでなく部分文字列にも注釈できる。

例：

| 発音表記（仮） | プレイヤーが見た状況 |
|---|---|
| `Mina pol tema` | 魚を欲しがっているようだった |
| `Mina bat tema` | 果実を欲しがっているようだった |
| `Mina pol ne tema` | 魚を受け取らず首を振っていた |

これらは比較用の仮例であり、実際には星のシードによって単語・語順・文法が変わる。

### 6.5 推測訳の補助表示【提案】

プレイヤーが自分で意味を登録した語には、会話や保存済みの文章の横にその推測を添える機能を検討する。

- 原音・発音表記は常に参照可能にする。
- 推測訳の表示・非表示を切り替えられるようにする。
- **誤った訳を入力していた場合、その誤った訳が表示される。**
- 登録していない部分をゲームが自動的に補完しない。
- 接辞・語順などを踏まえた自動作文法解析は行わない（実装範囲は未決定）。

### 6.6 検索【提案】

- 記録した発音表記を検索。
- 自分の自由メモから検索。
- 関連する保存済み音声・カードを検索。
- 発言者、場所、日時、商品などで絞り込み。
- **未解読の宇宙語について内部の正解日本語を使って逆引きしない。**

## 7. 住民辞典

### 7.1 根本方針【採用方向】

**住民一人ひとりを知るための、自分で作る辞典。**

住民の顔・会った記録と、プレイヤーが推測した性格・好み・関係を整理できる。

- 初対面では本名や性格を自動開示しない。
- 顔から住民を判別できるようにする。
- 呼び名は自由に付けて、後から変更できる。
- 好物・性格・仕事・友人関係などは自分で観察して記入する。
- 間違った推測でも、ゲームが勝手に訂正しない。

### 7.2 住民ページ構成【提案】

| 区分 | 記録内容 |
|---|---|
| 顔・識別 | 住民の顔、内部管理用の識別、出会った場所と日時 |
| 名前 | プレイヤーが付けた仮名・推測した名前 |
| 性格・好み | 好物、苦手、趣味、仕事、行動の癖 |
| 日常 | よくいる場所、活動時間、商店での買い物 |
| 人間関係 | 仲がよさそうな相手、家族かもしれない相手 |
| 声の記録 | その住民が残した伝言、話していた内容 |
| 思い出 | 一緒に釣りをした、プレゼントを贈った、引っ越しを見送った等 |
| 写真・自由ページ | 写真、自由記述、配置したカード |

すべての欄を埋める義務はない。自由な書き方を認める。

### 7.3 記録の扱い【採用方向／提案】

- **出会った日、撮影した写真、購入した商品などの客観的な出来事**は自動で記録してもよい。
- **「甘党」「節約家」「親友」「悲しんでいる」といった解釈**はプレイヤー自身が記入する。
- NPC自身の名前や性格などの内部データを、未解読のまま住民辞典に表示しない。
- 発言者を把握する際は実際に見聞きした内容を優先し、知らない住民の正体をカードから自動で断定しない。

### 7.4 写真と自由配置【提案】

- タブレットのカメラで住民・生物・日常を撮影できる。
- 撮った写真を住民のページへ貼る。
- 音声カード、写真、手紙、自由メモをスクラップブックのように並べられる。
- 資料一覧モードと、自由配置ページの両方を用意する案。

### 7.5 人間関係図【提案】

- 住民の顔を線で結ぶ。
- 線には「友達？」「家族？」「仲が悪い？」など自由に記入できる。
- プレイヤーが自分で関係を修正できる。
- 実際の人間関係の正解を自動で表示しない。

### 7.6 引っ越し後の扱い【採用方向】

- 住民が引っ越してもページ・音声カード・写真・思い出は保持する。
- 再会した場合も同じ住民のページへ記録を追加できる。
- 引っ越し後に届いた伝言も同じ住民の記録に関連付けられる。

本作の最終章「最後の引っ越し」に向け、プレイヤー自身の記録が思い出として残っていく。

## 8. 資料ボックスと資料の共通管理

### 8.1 基本方針【提案】

辞書・住民辞典・生き物図鑑・依頼帳には、それぞれ別々に原記録を複製するのではなく、**共通資料ボックスの記録を参照して貼り付ける**方式を提案する。

### 8.2 資料の種類

| 資料 | 主な発生元 |
|---|---|
| 音声カード | マネピが再現した商店の感想や伝言 |
| 会話記録 | 主人公が実際に聞いた住民の発言 |
| 写真 | タブレットで撮影したもの |
| 依頼記録 | 伝言広場、住民からのお願い |
| 行動・観察メモ | プレイヤーが観察して自分で入力した内容 |
| 手紙・看板の画像 | 宇宙文字を含む、撮影した原資料（読解はしない） |

### 8.3 重要な処理ルール

1. 原記録は保持する。
2. プレイヤーの自由メモは原記録とは別に管理する。
3. 同じ資料を複数のノートへ貼り付けられる。
4. ひとつのノートから外しても元資料は消えない。
5. 発言者が判別できない資料は、そのまま未分類で保管できる。
6. 保存・検索は、実際に見聞きした事実と本人の入力内容に基づく。

### 8.4 会話の保存【提案】

- 住民との会話中、ワンボタンで発話を保存。
- 直近の会話履歴から後で保存できる機能も候補。
- 保存対象は実際に聞いた宇宙語と付随する観察情報。
- 会話中に細かなメモを書くことを強制せず、後から整理できるようにする。

**注意：主人公のいない場所の会話を、タブレットが勝手に録音するわけではない。** 不在時の伝言は、住民がマネピに託したものなど、世界設定上の記録経路があるものに限る。

## 9. マネピを使った伝言文化とクエスト

### 9.1 伝言広場【採用方向／提案】

以前の「宇宙語の文章を貼った掲示板」を、マネピが依頼を預かる**伝言広場**へ置き換える案。

1. 住民がマネピに依頼を伝える。
2. 主人公がマネピの伝言を聞く。
3. マネピは声・身振りなどを再現する。
4. 主人公は状況を推測して依頼に挑戦する。
5. 必要に応じて伝言をタブレットの依頼帳へ保存する。

依頼主が実際に絵を見せたり指で数を示した場合には、その様子も手掛かりになる。一方、**見せていないヒントをタブレットが勝手に補完しない。**

### 9.2 個人間の伝言【提案】

- 住民がマネピに伝言を預ける。
- 受け取ったマネピが相手の家などで言葉と仕草を再現する。
- 留守中の伝言や、離れて暮らす住民からの近況報告にも使える。
- 引っ越した住民からの声が住民辞典に残る演出と相性がよい。

### 9.3 住民の直接会話も重要

マネピがいるからといって、住民との通常会話をすべて伝言経由に変えるわけではない。

**直接会って話す機会と、留守中の伝言を聞く機会の両方**を残す。

## 10. 実際の操作フロー

### 10.1 商店での価格研究

1. 星リンゴを300Gで陳列する。
2. 別の活動へ出かける。
3. 帰店すると、マネピがある住民の「モギラ！」という伝言を覚えている。
4. マネピが声や仕草を再現する。購入履歴ではその商品は買われていない。
5. タブレットの資料ボックスに音声カードを保存する。
6. 宇宙語辞書へ「モギラ＝高い？」、住民辞典へ「この住民は値段に厳しい？」と自分で記入する。
7. 別の日に価格を変更し、同じ住民やほかの住民の反応と比較する。
8. 仮説が違うと思ったら、記録を修正する。

### 10.2 文法の研究

1. 同じ住民から二つの似た文章を聞く。
2. 発話を保存する。
3. 比較モードで音・発音表記を並べる。
4. 繰り返し現れる音や語尾に自分で印を付ける。
5. 「否定の語尾かも？」「目的語を示す語かも？」などと書く。
6. 農業や釣りなど別の場面で同じ特徴を確かめる。

### 10.3 住民のことを知る

1. 初対面の宇宙人の顔を住民辞典へ記録。
2. 自分で「釣りのおじいちゃん」など仮の呼び名を付ける。
3. 商店の伝言、釣り場での会話、一緒に遊んだ写真を保存する。
4. 好きな魚や他の住民との関係を推理する。
5. 後で誤解に気づけばメモを書き直す。
6. 引っ越し後も、その住民の記録と声を見返せる。

### 10.4 会話とクエスト

1. 伝言広場でマネピが依頼を再現する。
2. 主人公が理解できた範囲で依頼を引き受ける。
3. 音声・当時見た絵・身振り・自分の推測を依頼帳に保存。
4. クエストを達成しても宇宙語の正解訳は表示されない。
5. 言葉を覚えた後に過去の依頼を読み返して理解を深める。

## 12. マルチプレイ時の辞書・記録共有

### 12.1 必ず守るルール【決定】

- ほかのプレイヤーが星へ来ても、**辞書は自動配布しない**。
- 渡すかどうかは辞書の持ち主が自由に決める。
- 間違った推測や、あえて書いた嘘を含んだ辞書を渡すこともあり得る。

### 12.2 星ごとの管理【採用方向】

- 宇宙語は星のシードごとに異なる。
- 自分の星と、訪問した友達の星の辞書を混ぜない。
- 同じ星へ再訪したとき、以前の調査記録を使えるようにする。
- 住民辞典も、その星の住民と紐付けて扱う案。

### 12.3 手動で共有する対象【提案】

| 対象 | 共有候補 |
|---|---|
| 宇宙語辞書 | 全体、単語の一部、文法メモ |
| 音声カード | 選択した伝言や会話 |
| 住民辞典 | 選択した住民のページや一部の記録 |
| 生き物図鑑 | 選択した記録 |
| 依頼帳 | 一部の資料・メモ |

- 元の辞書が消える強制移動ではなく、**コピーして渡す方式**を有力案とする。
- 受け取った資料と自分の記録を別に保管する案。
- 受け取った時点でゲームが正誤判定や自動修正をすることはない。
- どの範囲まで共有可能にするか、ゲストの記録権限などは未決定。

## 13. 多言語ローカライズと音声

### 13.1 言語の扱い【既存方針】

- 同じ星では、日本語版・英語版などでも原則として**同じ宇宙語**が存在する。
- タブレットUIはプレイヤーの言語でローカライズする。
- プレイヤーの自由入力メモは、勝手に正解訳へ置き換えない。
- 日本語特有の終助詞「ね」「よ」など、解読にほぼ寄与しない細かな違いを必須にしない。
- 星の語彙・語順・文法はシードに従い、一貫して再現する。

### 13.2 発音表記の設計【未決定】

実際に音声を持つことで、次の仕様を今後確定する必要がある。

- 音声をどの程度リアルに生成・収録するか。
- 語彙・文法が変わっても、発音と字幕が同じ文を示す方式。
- 発音表記をローマ字などの共通方式にするか。
- 言語によって音の聞き取りやすさが大きく変わらないようにするか。
- 声・音声再生が利用しにくい人のための字幕・表示方式。

**発音表記は「聞こえた音の提示」であり、宇宙人の書き文字の自動解読ではない**、という線引きを守る。

## 14. 記録システムのデータ上の考え方（技術設計候補）

本項は実装方式の提案であり、実際の保存形式の決定ではない。

### 14.1 原資料とプレイヤー解釈を分離する

- **原資料**：どの星・誰・いつ・どこで・何を発言したか、どんな姿で再現したか、商品価格などの観測事実。
- **個人メモ**：この音は何を意味するか、この住民は何が好きか、といった本人の仮説。
- **参照情報**：ひとつの音声カードを宇宙語辞書や住民辞典などのどこに貼っているか。

### 14.2 連携に必要なIDの例

| ID | 役割 |
|---|---|
| 星ID／言語ID | どの星の言葉や記録か |
| 住民ID | 名前を知らなくても同一人物を識別 |
| 資料ID | 音声カードや写真の原本を識別 |
| 辞書項目ID | 同じ語・仮説と資料を関連付け |
| プレイヤーID | 誰が書いた推測・共有データかを区別 |

### 14.3 整合性

- 元の意味データを辞書の正解として表示しない。
- マネピが再現する声や字幕は、星の言語生成ルールと矛盾しない。
- 星のシードで生成された単語・文法を、セーブ後も同じ状態に保つ。
- 購入履歴と発話記録の結び付けは、実際に対応する出来事がある場合のみ行う。
- プレイヤーが名前を間違って書いても、内部の住民判定に影響しない。
- 住民が引っ越しても、資料・関係付け・音声を参照可能にする。

## 15. 実装時に検証したいこと

## 17. 決定事項・採用方向・未決定事項の整理

### 17.1 決定済みの原則

1. 宇宙語は星のシードによって**単語だけでなく文法も変わる**。
2. プレイヤー自身が辞書へ意味や文法を記入する。
3. 誤った推測をゲームが勝手に修正しない。
4. 宇宙語を自動で正解翻訳しない。
5. 言語を完全に理解しなくても生活・金策・帰還ができる。
6. マルチで訪問した相手へ辞書を自動配布しない。
7. 主人公が普通の日本語等で住民に話す会話システムを追加することは基本にしない。

### 17.2 最新の採用方向

1. 記録は主人公の**タブレット**にまとめる。
2. 宇宙語辞書と住民辞典は別々の機能として持つ。
3. **商店の文字付箋を廃止**し、宇宙生物の伝言に置き換える。
4. 宇宙生物一覧No.033「マネピ」を伝言役として活用する。
5. マネピの声・仕草を手掛かりに宇宙語を推理する。
6. 伝言を**音声カード**としてタブレットや辞典へ保存する。
7. 住民が引っ越した後も、その住民に関する記録を残す。

### 17.3 追加提案・詳細未決定

- マネピがどの程度まで発言者の外見を変形して真似できるか。
- 音声の収録・生成・再生方式。
- 発音表記をどの文字体系で表示するか。
- 音声カードの詳細UI、保存件数、再生操作。
- 住民を識別できない伝言の扱い。
- 自由配置スクラップブック、写真、関係図、比較モードの具体的UI。
- 辞書の推測訳をリアルタイム会話へどう表示するか。
- 伝言広場・個人伝言の配達や保存ルール。
- マネピの捕獲・飼育と伝言能力の関係。
- 住民辞典や生き物図鑑などの共有範囲。
- マルチプレイでの記録・編集権限。
- 多言語向けの音声・字幕・入力方法。

## 18. このシステムで目指すプレイ体験

最初に村へ来たとき、主人公のタブレットにはこの星の情報がない。

商店に商品を並べ、釣りに出かけて戻ってくると、マネピが住民の声を真似して聞かせてくれる。

「モギラ！」という言葉を、怒ったような顔で再現している。何を意味するのか分からない。

その声を保存し、住民辞典には「値段に厳しい？」、宇宙語辞書には「高い？」と書く。

何日か経つと、同じ言葉を鍛冶屋でも聞く。自分の推測が合っているように思えてくる。

さらに暮らしていくと、最初は苦手そうだと思っていた住民が、実は別の理由で困っていたことが分かるかもしれない。昔の音声を聞き返すと、同じ文章の意味が以前とはまったく違って聞こえる。

住民が引っ越した後も、その声、写真、会話、誤解したメモ、考え直した記録が残っている。

最後に故郷へ帰るとき、タブレットにはこの星で暮らした時間が詰まっている。

**宇宙語辞書は、この星の言葉を理解していった記録。住民辞典は、この星の住民を知っていった記録。マネピは、そこにつながる声と仕草を運ぶ存在。**

この三つを、本作の生活と物語を結びつける中心的な仕組みにする。
