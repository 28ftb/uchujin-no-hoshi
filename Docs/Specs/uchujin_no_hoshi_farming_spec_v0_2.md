## 0. 仕様の扱い

本文では、次の区分を用いる。

- **【既存決定】**：別の仕様・会話で明確に決まっている、今回も尊重すべき方針。
- **【採用方向】**：今回の議論で選んだ農業の中心的な方向性。数値や具体的な実装は未確定。
- **【提案】**：会話中に挙がった具体案。面白そうでも、採用が確定したとは扱わない。
- **【未決定】**：今後、設計・検討する部分。

**基本原則**：農業だけでも遊びとして十分面白くする。そのうえで、宇宙生物・生き物取り・住民交流・宇宙語解読・商店経営につなげる。制作負担を理由に内容を勝手に削らない。また、提案を決定事項に昇格させない。

## 1. コンセプトと位置付け

### 1.1 中心コンセプト【採用方向】

**「作物を育てる農業」＋「かわいい宇宙生物たちと一緒に暮らす農場」。**

一般的な農業ゲームのスプリンクラーや自動収穫機に相当する役割を、かわいい宇宙生物に担ってもらう。農場が発展するほど、さまざまな生物が水やり・耕作・種まき・収穫・運搬などを行い、賑やかになる。

- 序盤はプレイヤー自身がクワ・じょうろなどで農作業をする。
- 生き物を発見し、捕まえたり、迎え入れたり、育てたりして農作業の手助けを増やす。
- 生き物には生態・仕草・得意な仕事・好きな環境を持たせ、単なる機械の外見違いにしない。
- 農場の配置や生物の組み合わせを考える楽しさを作る。
- 収穫物は商店で販売し、住民の好みや宇宙語を知るきっかけにする。

### 1.2 ゲーム全体との関係【既存決定／採用方向】

本作の基本は、**言葉の通じない星で宇宙人たちと暮らし、お金を稼いでロケットを修理し、故郷へ帰る生活シミュレーション**。

農業は、釣り・採掘・生き物取り・クエスト・商店と並ぶ主要な活動の一つ。農業に専念するプレイも、ほかの活動と組み合わせるプレイもできる方向を目指す。

**宇宙語が分からないと農業ができない、という設計にはしない。** 生活を続けることで、作物や生物の名前、住民の好み、栽培のコツなどの意味が自然に分かっていくことを目指す。

## 2. 農業の基本的な流れ

### 2.1 手作業での栽培【基本仕様案】

1. 畑を耕す。
2. 種屋などから手に入れた種をまく。
3. 必要に応じて水や肥料を与える。
4. 日数の経過によって作物が育つ。
5. 成熟した作物を収穫する。
6. 収穫物を直接売る、自分の商店に陳列する、加工する、住民へ贈る、依頼に使うなどして活用する。

| 要素 | 仕様案 |
|---|---|
| 畑 | マス単位で耕し、自由に植える |
| 種 | 種屋で購入、収穫物から生成、特別な入手手段など |
| 水やり | 基本は日ごとの水分管理を想定。雨や生物による水やりも利用可能 |
| 生育 | 作物ごとに成長日数・収穫条件が異なる |
| 収穫 | 一度きりの作物と連続収穫できる作物を用意 |
| 品質 | 肥料や育て方などによって品質差が生まれる案 |
| 販売 | 直接売却、商店のセルフ販売を利用 |

具体的な1日の長さ、水やり回数、生育日数、農地面積は【未決定】。

### 2.2 農業の成長ループ【採用方向】

**手作業で育てる → 生物を迎える → 農作業を手伝ってもらう → 農場を広げる → 珍しい作物・生物の組み合わせを楽しむ。**

自動化を進めても、プレイヤーが手作業で農業を楽しめることは維持する。

## 3. 宇宙生物による農作業

### 3.1 基本方針【採用方向】

- スプリンクラーなどの**農作業自動化設備の役割を、宇宙生物に置き換える方向**とする。
- 生物たちは農場で実際に移動・行動し、得意な作業を行う。
- 作業以外にも食事、睡眠、遊び、仲間との交流などの生活行動を持つ。
- 農場が発展すると、生物たちが働きながら暮らす様子そのものが見どころになる。
- クワ・じょうろ・カマなど、**プレイヤーが手に持って使う道具は残す方向**。手作業の強化と、生物による自動化は別の要素とする。

### 3.2 農業を手伝う生物10系統【提案】

※名称・見た目・能力はすべて仮案。**10系統はこれまでに提案した候補を整理したもので、正式採用種族数の上限ではない。**

| 仮名 | 外見・生態のイメージ | 主な役割 |
|---|---|---|
| **ミズプク** | 水をため込む、まんまるな生物 | 水やり |
| **ホリモグ** | 大きな前足を持つモグラ型生物 | 畑を耕す、土を整える |
| **タネパタ** | 羽で飛び回る小鳥型生物 | 種まき |
| **モギモギ** | 長い腕を持つ小型生物 | 成熟した作物の収穫 |
| **ツチポン** | 土を食べて栄養に変える生物 | 土壌改良、品質向上 |
| **ハナピカ** | 花から花へ飛び回る発光生物 | 受粉、収穫量の補助 |
| **ヒカリムシ** | 夜に光る小さな生物 | 光を好む特殊作物の育成補助 |
| **ハコバチ** | 荷物を抱えて飛ぶ生物 | 収穫物の運搬 |
| **ポカリス** | 体がふわふわで温かな生物 | 周辺の温度を調整 |
| **タネコロ** | 丸い実に似た小動物 | 種の採取・増殖補助 |

住民として暮らす知的な宇宙人と、農場などで飼育・捕獲する宇宙生物は、設計上別の存在として区別する方向。

### 3.3 生物が働く具体例【提案】

- **ミズプク**：朝、畑へ向かって体を膨らませ、水を吹きかける。雨の日には水浴びをして遊ぶ。
- **ホリモグ**：収穫後に空いた畑を見つけて、前足で耕す。
- **タネパタ**：指定された種を種箱から取って、空いた畑に運び、植える。
- **モギモギ**：成熟した作物を見つけて収穫し、収穫箱に入れる。
- **ハコバチ**：収穫箱から倉庫へ作物を運ぶ。
- **ツチポン／ハナピカ／ヒカリムシ／ポカリス**：それぞれの能力で生育環境や収量・品質・特殊作物に影響する。

**重要**：収穫した作物が、生物の判断で勝手に商店へ出品・売却される仕様にはしない。商店で何をいくらで売るかはプレイヤーが決めるという既存方針に準拠する。将来的な倉庫から商店への自動補充は別途提案・検討する。

### 3.4 配置と作業範囲【提案】

生物に住み場所を用意したり、農場の一角に配置したりすると、その周辺を中心に働く仕組み。

ミズプクなら、小型個体は狭い範囲、成長した個体は広い範囲を水やりできるようになる例がある。

- 小型：近くの畑に水やり
- 成長した個体：より広い範囲に水やり
- 大型：さらに広範囲へ水やり

**3×3、5×5、7×7マスといった具体的な範囲や成長段階数は仮例であり、確定仕様ではない。**

種の指定、働く時間帯、作業範囲、作業の優先順位などのUI・ルールは【未決定】。

## 4. 宇宙生物を集める・迎える

### 4.1 入手方法【提案】

1. **野生で捕獲**：川辺・草原・花畑・地下などで生き物取り道具を使う。
2. **自然に呼び寄せる**：好きな植物や環境を整えることで農場にやってくる。
3. **住民から譲り受ける**：交流イベントやクエストで迎える。
4. **繁殖させる**：条件が合うと子どもが生まれる。
5. **購入する**：一部の生物は商人・住民から入手できる。

捕獲と自然な誘致を両方用意する案が特に有力。生き物取りが好きなプレイヤーと農場づくりが好きなプレイヤーの、両方に楽しみを持たせる。

### 4.2 生息環境の例【提案】

| 生物 | 発見・誘致しやすい場所の例 |
|---|---|
| ミズプク | 池・川辺・水場 |
| ホリモグ | 土の柔らかい場所・草原 |
| タネパタ | 木々・止まり木周辺 |
| モギモギ | 果樹・畑の近く |
| ツチポン | 栄養のある土 |
| ハナピカ | 花畑 |
| ヒカリムシ | 夜に光る植物の周辺 |
| ハコバチ | 巣箱・荷物のある場所 |
| ポカリス | 暖かな場所 |
| タネコロ | 実のなる植物の近く |

捕獲難度、入手時期、レア度、個体数、住み着く条件などは【未決定】。

## 5. 成長・育成・個体差

### 5.1 生物の成長【提案】

生物は農場で暮らし、働き、交流することで成長する。

| 成長要素 | 変化の例 |
|---|---|
| 外見 | 大きさ、色合い、模様などが変わる |
| 作業範囲 | 水やり・収穫などの対象範囲が広がる |
| 作業速度 | 同じ仕事を早く終えられる |
| 特殊能力 | 種類によって新しい行動を覚える |
| なつき度 | 主人公に寄ってくる、特別な仕草を見せる |

成長が必ず「子ども→成長期→大人」の3段階となるわけではない。種類に合った成長の仕方を検討する。

### 5.2 個体差【提案】

同じ種類でも、水やりが得意、移動が速い、体が大きくなりやすい、見た目が違うなどの個性を持つ案。

- 得意な能力
- 成長傾向
- 色・模様
- 好きな食べ物
- 仕草・行動の個性

具体的な個体差の生成方法・数値幅は【未決定】。

### 5.3 生物のお世話【提案】

- 好きな食べ物を与える、なでる、住み場所を整えるといった交流を楽しめる。
- 生物は仕事以外の時間にも、自分で食事をしたり、休んだり、遊んだりする。
- 毎日全個体への給餌を義務化するより、**飼育を楽しむと成長・なつき・能力などに良い影響がある**方向を提案する。

餌の消費、空腹、疲労、仕事の休止、繁殖、寿命などは【未決定】。これらの有無を勝手に確定しない。

## 6. 生物同士の組み合わせ

### 6.1 複数生物による協力作業【提案】

一匹でも役立つが、複数の種類がいると作業が連続したり、特殊な効果が起きたりする。

| 組み合わせ | 効果の例 |
|---|---|
| **ミズプク＋ツチポン** | 水やりと土壌改良によって品質の高い作物が育ちやすい |
| **ハナピカ＋ヒカリムシ** | 夜間の特別な受粉が起こり、珍しい花色が出ることがある |
| **モギモギ＋ハコバチ** | 収穫した作物を順次倉庫へ運び、農場の作業がつながる |
| **ホリモグ＋タネパタ** | 収穫後の耕作から種まきまでつながる |

特別な組み合わせは、作業効率だけでなく専用アニメーションや見た目の変化があると楽しい。

### 6.2 発見の仕組み【提案】

組み合わせ効果は、プレイヤーが農場で実際に生物の行動を観察して気づけるようにする。住民の農場や宇宙語の会話も手掛かりになる。

組み合わせの総数、効果の重複、発動条件、効果の表示方法は【未決定】。

## 7. 宇宙生物が作物に与える変化

### 7.1 特殊な生育・変異【提案】

宇宙生物の種類や組み合わせによって、収量・品質・色・大きさ・変わった姿などの変化が起こる案。

| 作物（仮） | 関係する生物 | 起こり得る変化の例 |
|---|---|---|
| ホシベリー | ヒカリムシ | 夜に強く光る実・珍しい色の実ができやすい |
| ふわふわトマト | ハナピカ | 収穫個数が増えることがある |
| しましまイモ | ツチポン | 大きな個体が育ちやすい |
| ベルフラワー | ハナピカ＋ヒカリムシ | 特別な花色が現れることがある |
| 寒い時期の宇宙野菜 | ポカリス | 暖かな環境で育ちやすい |

これは「農業を続けるほど、生物の組み合わせを試したくなる」ための追加案。

**すべての作物に複雑な特殊条件を付けることは前提にしない。** 普通に種を植え、育て、収穫する遊びも残す。

### 7.2 作物の品質・サイズ【提案】

- 品質差による販売価格の変化
- まれに生まれる巨大な作物
- 変わった色・模様・光り方の個体
- 生物の効果や肥料による品質・収量の変化

品質の段階数、巨大作物の判定、品種改良・交配との関係は【未決定】。

### 8.1 生物ごとの住み場所【提案】

### 8.2 農場づくりの楽しさ【採用方向／提案】

- 仕事をしていない生物も見える場所で生活する。
- 池、花畑、巣箱、果樹などの配置が農場の景色と機能の両方に影響する。
- 農場が育つほど、かわいい生物たちが各所で働き、遊び、暮らしている光景になる。

農地の広さ、建物配置、柵、通路、土地の購入や拡張方法は【未決定】。

## 9. 作物・季節・栽培要素

### 9.1 作物の分類【基本仕様案】

| 分類 | 特徴 |
|---|---|
| 一度きりの野菜 | 成熟後に収穫して終了 |
| 連続収穫作物 | 一度育つと一定間隔で再収穫できる |
| 果物・果樹 | 育成期間が長いものや繰り返し実がなるものがある |
| 穀物 | まとめて収穫し、加工にも利用しやすい |
| 花 | 観賞、プレゼント、商店販売に使える |
| 特殊作物 | 光る、浮く、色が変わるなど異星らしい性質がある |

### 9.2 宇宙作物の候補【提案】

| 仮名 | 特徴の例 |
|---|---|
| **ふわふわトマト** | 成熟すると実が少し浮く、連続収穫できる |
| **ホシベリー** | 夜になると青く光る果実 |
| **しましまイモ** | 模様・大きさに個体差がある根菜 |
| **ホシピーマン** | 星形の実がなる野菜 |
| **ニジニンジン** | 色によって見た目が異なる根菜 |
| **ベルフラワー** | 風に揺れると音が鳴る花 |

名前、見た目、育成日数、加工品、価値、種類数は【未決定】。

### 9.3 季節と天候【提案／未決定】

春・夏・秋・冬がある場合、季節ごとに育ちやすい作物が変わる。

- 春：花・葉物野菜
- 夏：果実・連続収穫野菜
- 秋：穀物・根菜
- 冬：寒さに適応した宇宙作物

本作は地球ではないため、地球と同じ四季・気候にする必要はない。**季節数・季節の長さ・天候・冬の栽培・温室の扱いは未決定**。

### 9.4 肥料【提案】

品質上昇、成長促進、保水、収穫量増加などの効果を持つ肥料を用意する案。

ツチポンなどの生物の役割と競合・重複する場合の扱いは、今後の調整項目とする。

## 10. プレイヤー自身の農具・農業レベル

### 10.1 農具【提案】

生物による自動化とは別に、プレイヤーが使う農具は強化可能とする案。

| 農具 | 基本機能 | 強化例 |
|---|---|---|
| クワ | 畑を耕す | まとめて複数マスを耕す |
| じょうろ | 水やり | 広範囲へまとめて水やり |
| カマ | 作物・雑草を刈る | 広い範囲を刈り取る |
| オノ | 木を切る | 硬い木を少ない回数で伐採 |

農具を村の鍛冶屋に鉱石とお金を渡して強化してもらう案は、鉱山仕様との自然な連携になる。

**農具強化の段階・素材・範囲は仮案。生物による自動化を採用しても、手作業の楽しさを消さない。**

### 10.2 農業レベル【提案】

収穫や農作業で経験値を得る仕組み。レベル上昇に伴って、スタミナ効率、作業速度、品質、利用できる栽培技術などが変わる案。

農業レベルの有無、上限、成長効果、宇宙生物の成長との関係は【未決定】。

### 10.3 農業名人【提案】

村の農業が得意な住民から、身振り・実演を通じて農業技術を教わる案。

- 連続種まき
- 広範囲の収穫
- 肥料の使い方
- 作物の生育状態を見極める技術
- 特別な栽培技術

これらの具体的な技は候補にとどめる。宇宙語が分からなくても身振りで学べ、理解できれば説明の意味も分かる構成が望ましい。

## 11. 種屋・農業が得意な住民との交流

### 11.1 種屋【提案】

- 住民の一人が種屋を営んでいる。
- 種袋には作物の絵や宇宙語の表記がある。
- 言葉が分からなくても絵を見て種を選び、育てられる。
- 作物名、成長の早さ、季節、味、価格などの宇宙語を、実際の栽培や住民との交流を通して推測できる。

### 11.2 住民の家庭菜園【提案】

住民も自宅の庭で花や野菜を育てている。

- 毎朝花に水をやる住民
- 大きな野菜が好きな住民
- 珍しい植物を集める住民
- 育て方が苦手な住民
- 料理用の作物を育てる住民

住民自身が宇宙生物を飼っていることもあり、プレイヤーがその行動を見て農作業の仕組みを理解する。

### 11.3 住民から生物を教わる【提案】

農業の得意な住民の家にミズプクがいて、住民が水やりをさせている様子を見せてくれる。言葉が分からなくても、何をする生物なのか視覚的に理解できる。

仲良くなると飼い方を教えてくれたり、子どもの生物を譲ってくれたりするイベントも候補。

---

## 12. 宇宙語辞書・住民辞典・生物図鑑

### 12.1 宇宙語の学習【既存決定／提案】

**宇宙語の正解をゲームが自動で教えない**という既存方針を維持する。生物や作物を観察し、住民が使う言葉の意味をプレイヤー自身が推測する。

例：

- ミズプクが水をまいたときに住民が発した言葉を、雨の日にも聞く。
- 種屋が種を指さして言う言葉を、その作物が実ったときにも聞く。
- 特定の作物を喜んで受け取る住民の言葉を、別の好物を受け取ったときにも聞く。

### 12.2 住民辞典との連携【既存方針】

住民ごとの好きな作物・育てている花・飼っている生物・会話などを自由にメモできる。商店の商品に残された住民の顔付き付箋も保存できる。

### 12.3 生物図鑑【提案】

捕まえた宇宙生物の特徴、好きな環境、食べ物、働き方、成長、組み合わせについて、自分で観察して記録できる図鑑を設ける案。

**宇宙語辞書＝言葉の意味／住民辞典＝宇宙人の性格や好み／生物図鑑＝宇宙生物の生態と能力**という役割分担。

ゲーム側が自由メモを正解に書き換えることはしない。

---

## 13. 商店経営との連携

### 13.1 収穫物の販売【既存決定】

商店は、**商品を棚に並べておけば住民が自分で買っていくセルフ販売方式**。店番やレジ操作を強制しない。

農業で得た作物・花・果物・加工品を自分の商店に並べ、価格を設定して販売できる。

### 13.2 宇宙生物が生み出した商品差【提案】

- ハナピカの受粉で収量が増えた作物
- ツチポンの影響で品質が高まった作物
- ヒカリムシによって色や光り方が変わった果実
- 大きな野菜や珍しい品種

こうした特徴によって値段や住民の好みが変わる案。

### 13.3 顔付き付箋【既存方針】

住民は購入時などに、宇宙語の顔付き付箋を残すことがある。

| 住民が抱く感想（内部の意味） | 状況の例 |
|---|---|
| 高い | 高級な果物を見た |
| 安い | お買い得な野菜を見た |
| きれい | 珍しい花を見た |
| 大好き | 好物を購入した |
| もっと欲しい | 欲しい作物が売り切れた |
| 大きい | 巨大な野菜を見つけた |

実際に表示する文字列は星のシードで生成された宇宙語。付箋は宇宙語辞書・住民辞典で保存・参照できる。

### 13.4 加工【提案】

果物からジャム・ジュース、野菜から漬物、穀物からパン、花から花束・香料などの加工品を作り、商店で販売する案。

加工設備の種類・製作方式・販売価格は【未決定】。

## 14. 農業関連のクエスト・イベント

### 14.1 クエスト【提案】

- 指定作物の納品
- 花や作物のプレゼント
- 住民の畑仕事の手伝い
- 珍しい種を受け取って育てる
- 料理人や商店からの大量注文
- 宇宙生物の飼育・発見に関する依頼

言葉が分からなくても、絵・現物・住民の仕草から依頼内容の手掛かりを得られるようにする。

### 14.2 農場に遊びに来る住民【提案】

住民が農場を訪れ、珍しい生物に驚いたり、作物について話したりする。農業に詳しい住民は助言することもある。

### 14.3 農場の小さな出来事【提案】

- ミズプクが集まって水遊びをする。
- ハナピカが一斉に集まり、夜の花畑が光る。
- 生物の赤ちゃんが親の仕事を真似する。
- 珍しい組み合わせで、作物に小さな変化が起きる。

収穫祭・農業大会については過去に案が出ているが【未決定】。

## 15. マルチプレイ

### 15.1 協力して農業を楽しむ【提案】

- 一緒に畑を耕す、種をまく、水をやる、収穫する。
- 友達の星の農場や宇宙生物を見学する。
- 珍しい作物や生物を見せ合う。
- 別の星で種を購入したり、持ち帰ったりする遊びを検討する。

**訪問先の星では、その星の宇宙語を使う**既存方針を維持する。辞書は自動配布しない。

### 15.2 未決定のマルチプレイ仕様

- ゲストの耕作・種まき・収穫権限
- 作物や宇宙生物の所有者と保存先
- 別の星へ種・生物を移動できるか
- 異なる星の作物・生物の互換性
- ホスト不在時の農場進行・生物の成長
- 農場作業の同時操作時の競合処理

## 16. プレイの発展イメージ

### 序盤：小さな畑【提案】

- プレイヤーが手作業で耕し、種を植え、水をやる。
- 初めてミズプクのような農業を助ける生物を見つける。
- 種屋や農業好きの住民と交流し、作物名などの宇宙語に触れる。

### 中盤：宇宙生物と協力【提案】

- ホリモグ・タネパタ・モギモギなどを迎える。
- 生物の住み場所や農具を整え、畑を拡張する。
- 自動的な水やり・耕作・種まき・収穫が一部つながる。
- 収穫した作物を商店に陳列し、住民の反応を見る。

### 後半：賑やかな宇宙農場【提案】

- 水やり・種まき・収穫・運搬を複数の生物が分担する。
- 組み合わせ・個体差・変わった作物の育成を試す。
- 珍しい生物や作物の記録を残し、住民の好みも把握する。

### 長期プレイ【提案】

- 収益重視の農場、珍しい植物の農場、かわいい生物と暮らす農場など、好みに合わせて発展させる。
- ロケットの修理を終えた後の農場継続・再訪については【未決定】。

## 18. 今後の詳細設計で決める項目

現時点では細かな数値や実装を勝手に確定しない。次の項目を別途設計する。

1. **畑の操作感**：マスサイズ、耕作、水やり、収穫の操作方法。
2. **作物の総数と生態**：通常作物・特殊作物・果樹・花などの構成。
3. **宇宙生物の正式な種類と能力**：10案を出発点に、種類数や個性を検討。
4. **捕獲・誘致**：どのように仲間になり、農場で暮らすか。
5. **成長・繁殖・個体差**：段階、発生条件、能力と見た目の変化。
6. **仕事の指定・優先順位**：作業範囲、種の指定、在庫がない場合の行動など。
7. **組み合わせ効果**：生物同士の共同作業、特殊作物との関係。
8. **季節と天候**：季節構成、雨、気温、生育への影響。
9. **農具・農業レベル**：強化段階、獲得経験値、使い分け。
10. **農場の土地と住み場所**：拡張、池、巣箱、倉庫、通路など。
11. **商店・加工・住民との経済連携**：販売、価格、需要、付箋。
12. **生物図鑑・住民辞典・宇宙語辞書**：記録と閲覧の操作感。
13. **マルチプレイ**：農場の権限、保存、所有、異星からの持ち込み。
14. **ロケット帰還後**：農場を継続できるか、再訪できるか。

## 19. 本仕様の核となるイメージ

最初は主人公が一人で畑を耕し、種をまき、水をやっている。

やがてミズプクを迎え、水やりを手伝ってもらう。次にホリモグやタネパタが来て、畑を耕し、種をまくようになる。モギモギが収穫し、ハコバチが倉庫へ運ぶようになる。花畑ではハナピカが飛び、夜にはヒカリムシが輝く。

プレイヤーは珍しい作物を育て、商店で売り、住民の顔付き付箋や会話から少しずつ宇宙語を理解する。生物の生態や組み合わせも観察し、自分の農場を育てていく。

**目指すのは、農作業を機械に任せて終わる農場ではなく、かわいい宇宙生物たちが働きながら暮らしている、見ているだけでも楽しい農場。**

以上は、これまでの会話を反映した **v0.2の企画・仕様案**。採用方向を軸に、今後さらに面白くする余地を残す。
