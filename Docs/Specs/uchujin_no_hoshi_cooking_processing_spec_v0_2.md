8. 【既存方針】住民は主人公と無関係にも日々の仕事、買い物、食事、交友、引っ越しを行う。主人公が売った品物は住民の生活でも使われる。
9. 【既存決定】鉱山の鉱石は日付更新で即時再配置され、目の前で出現・消滅してもよい。「地球では不自然」を理由に異星の仕様を制限しない。
10. 【既存方針】ロケット修理のために、料理の完全習得や調理専用生物の収集を必須にしない。

## 1. 料理・加工の役割【中心方針】

### 1.1 目指す体験

**生き物を見つける → 能力を観察する → 自宅や村の調理場で試す → 新しい料理・加工品を発見する → 食べる・売る・贈る → 住民の反応と宇宙語を知る。**

料理・加工は次の二系統を持つ。

| 系統 | 対象 | 楽しさ |
|---|---|---|
| **料理・食品加工** | 魚、野菜、果実、穀物、食用の特殊素材など | 食べる、味・食感・調理法を発見する、住民の食文化を知る、商売する |
| **非食品の素材加工** | 鉱石、結晶、植物繊維、染色素材、石材・木材など | 家具・装飾・建材・道具・商品へ発展させる |

両者は**宇宙生物の能力を共用する**。例えば「加熱」という能力は焼き魚にも素材加工にも応用できる。ただし、必要な設備や住民職人の技術によって最終的にできる作業は異なる。

### 1.2 料理に独自の面白さを持たせる

- ただ「材料を別アイテムにする」だけでなく、初めてのレシピを発見する楽しみを持つ。
- 同じ素材でも、能力・器具・手順を変えると違う仕上がりになる。
- 調理中の生物の表情や動作が楽しい。放置中は眠ったり遊んだりして暮らしている。
- 一度覚えた料理は再制作・量産しやすくし、発見と日々の販売を両立する。
- 住民の好みを実際の購入、食事、プレゼント時の反応から知る。
- 生活のなかで宇宙語の新しい手掛かりを得る。言葉を解読しないと料理できない仕組みにはしない。

## 2. 宇宙生物と調理器具の3方式【中心方針】

| 方式 | 仕組み | 例 | 狙い |
|---|---|---|---|
| **A：生物と器具の一体化** | 生物が器具の内部・周辺に住み、能力を供給する | ポカリスのかまど、ミズプクの給水台 | 家具や台所設備が生物の住み場所にもなる |
| **B：生物自身が器具** | 生物の身体・動きが直接加工機能になる | 丸まった生物が粉砕、泡を作る生物が泡立て | 異星ならではのユニークな調理動作 |
| **C：複数生物の協力** | 異なる能力を連結して調理する | ミズプクの給水＋ポカリスの加熱 | 発見や組み合わせの幅が広がる |

三方式は排他的ではない。同じ生物が直接調理したり、設備と組んだり、仲間と協力したりしてよい。

### 2.1 最初から料理できる経路【採用推奨】

- 生物をまだ捕まえていない序盤でも、**村の共用調理場や住民が用意した設備**などで基本的な料理に触れられる。
- 自宅に生物・器具を迎えると、好きなときに調理したり、大量生産・特殊加工を楽しんだりできる。
- 「捕獲→飼育→調理」の楽しさは広げるが、料理するために何匹もの生物の捕獲を義務付けない。
- 普通の器具を一切禁止することも確定していない。**中心となる演出・遊びは生物連携**とする。

### 3.2 能力は活動ごとに分断しない【中心方針】

| 共通能力の候補 | 農業 | 料理・食品加工 | 素材加工・家具 |
|---|---|---|---|
| 温める | 温度調整（ポカリス） | 加熱・保温 | 金属・結晶などの加工補助 |
| 水を出す | 水やり（ミズプク） | 給水・蒸す・洗う | 染料・素材洗浄 |
| 光らせる | 特殊作物の育成 | 発光を生かす調理 | 照明・結晶加工の演出 |
| 運ぶ | 収穫物運搬（ハコバチ） | 食材・完成品の搬送 | 建築・装飾素材の搬送 |
| 回転・粉砕 | （生態を活かす応用） | 製粉・粉砕・こね | 鉱石や植物繊維の加工 |
| 泡を出す | 水場での生態 | 泡立て・特殊な食感 | 洗浄・加工液への応用 |
| 積み重ねる | （生態を活かす応用） | 盛り付け・積層 | 小物・装飾の組み立て |

**原則**：「料理用の能力」を別枠で大量に新設するより、生物の特徴を共通の世界ルールとしてさまざまな場面に応用する。ただし、生物固有の得意・不得意も残す。

### 4.2 組み合わせで機能が増える

- **ポカリス＋かまど**：食材を焼く。
- **ミズプク＋ポカリス＋鍋**：水を供給し加熱することでスープや蒸し料理。
- **クルマリ＋製粉台＋ポカリス**：穀物を粉にしてから焼き物を作る。
- **アワリン＋加熱生物**：泡立てた材料を加熱してふわふわの料理にする。
- **冷却向きの生物＋圧搾設備**：冷たい飲み物やデザート。
- **発酵向きの生物＋専用壺**：時間経過で発酵食品を作る。

同じ生物が農場・厨房・加工室のどこで活躍するかは、配置や指示によって変わる方式が候補。【未決定】同一時刻に複数の場所で働けるかは生物の実際の居場所とルールの整合を取る。

### 4.3 生物は機械ではなく生き物

- 調理していないときは休憩・睡眠・遊び・交流を行う。
- ポカリスがかまどで丸まって眠る、ミズプクが水場で遊ぶ、ハコバチが棚の近くで休む等。
- 設備・寝床・家具が、調理の機能だけでなく生物の生活環境にもなる。
- 特定設備へ永久に閉じ込めることを基本にはせず、飼育・家具仕様と整合する設計を検討する。

## 5. レシピの成立と発見【採用推奨】

### 5.1 基本の考え方

**完成品 = 食材・素材 × 加工能力 × 器具・設備 × 加工手順（順番・程度）**。

- **レシピ調理**：すでに発見した料理を記録から再現する。
- **自由調理**：食材・能力・順番を自分で選んで試す。
- **前回と同じ方法で調理**：一度成功した手順を簡単に繰り返す。
- **まとめ調理**：複数食分や商品をまとめて制作する。

すべてを同じ見た目の料理のランダムな名前違いにしない。代表的な料理には個別の外見・食感・調理演出を用意し、食材差・品質差・調理の仕方によるバリエーションを重ねる方向。

### 5.2 同じ魚から異なる商品ができる【説明例】

| 入力 | 使用する能力／工程 | 出力 |
|---|---|---|
| 魚 | 加熱 | 焼き魚 |
| 魚＋水＋野菜 | 給水 → 加熱 | 魚と野菜のスープ |
| 魚 | 乾燥 | 干し魚 |
| 魚 | 粉砕・成形 → 加熱 | すり身焼き |
| 魚 | 加熱＋燻煙【未決定の能力】 | 燻製魚 |
| 魚＋野菜 | 加熱の強弱・順序を変更 | 別の焼き加減や料理になる可能性 |

### 5.3 食品加工の連鎖【説明例】

- **穀物 → 製粉 → 粉 → 水を加えてこねる → 加熱 → パン**。
- **果実 → 圧搾 → ジュース**。または **果実 → 粉砕 → 加熱 → ジャム → パンや菓子の材料**。
- **魚 → 乾燥／燻煙 → 保存食・別の風味の商品**。
- **野菜 → 煮る → すり潰す → ポタージュ状の料理**。
- **食材 → 発酵 → 調味料・特殊食品 → 別の料理の材料**。

工程を重ねる面白さを作る一方、簡単な料理まで必ず長大な加工連鎖を通るようにはしない。

### 5.4 特殊料理の例【提案】

| 料理の仮名 | 想定する工程・能力 | 魅力 |
|---|---|---|
| ふわふわ星パン | 製粉＋泡立て＋加熱 | 空気を含んだ軽い食感 |
| ぷるぷる蒸し魚 | 給水＋加熱 | 柔らかな食感 |
| キラキラ果実ゼリー | 圧搾＋冷却＋発光 | 光るデザート |
| ぐるぐる野菜ロール | 伸ばす・巻く＋加熱 | 渦巻き模様 |
| もくもく燻製魚 | 加熱＋燻煙 | 特徴的な香り |
| にじいろ重ねケーキ | 泡立て＋加熱＋積層 | カラフルな層 |
| 星の発酵ジュース | 圧搾＋発酵 | 泡と光の変化 |
| まるごと野菜スープ | 給水＋加熱＋攪拌 | 濃厚な仕上がり |

※冷却・発酵・圧搾・煙・伸ばす等の担当生物、食材、正式名称、必要時間は未決定。料理の具体例であり、確定レシピ表ではない。

### 5.5 意図と違う結果も発見にする【提案】

- 魚を焼きすぎたら、必ず無価値なゴミになるのではなく、固く香ばしい料理として好む住民がいてもよい。
- 果実を煮詰めすぎた結果、ジャムではなくキャンディ状の食品を発見する例。
- 「失敗」の罰よりも、試行錯誤による新しい結果を重視する。
- どんな入力でも必ず有用な料理になると確定したわけではない。失敗・焦げ・無効な組み合わせの扱いは【未決定】。

## 6. 調理操作・ミニゲーム・自動調理【採用推奨／提案】

### 6.1 初めての料理は自分で触れる

- 生物の動きや調理状態を観察しながら調整する。
- **ポカリス**：加熱の強さ、食材との位置関係、焼き具合を見て操作する案。
- **ミズプク**：水量・給水のタイミングを調整する案。
- **クルマリ**：回転速度や粉砕の細かさを調整する案。
- **アワリン**：泡立ち具合や混ぜ方を調整する案。
- **ツミツミ**：材料の積み重ね方・盛り付けを工夫する案。
- すべての調理を同じゲージ停止ミニゲームにはせず、**生物の能力ごとに違う手触り**を持たせる。

### 6.2 繰り返しは快適に

- 一度作った料理・手順は保存し、**再調理を簡単にする**。
- 慣れた生物に手順を任せる自動調理、まとめ調理が候補。
- 手動調理は品質や食感・仕上げへのこだわり、試作や新発見に価値を残す。
- 自動調理でも日常的に売れる完成品は作れる方向とし、同じミニゲームの繰り返しを強制しない。
- 自動化の解放条件、手動との差、失敗や品質の計算式は【未決定】。

### 6.3 宇宙生物の調理習熟【提案】

- 生物自身が経験を積み、得意な工程を安定して行えるようになる。
- 個体ごとに得意な温度帯や攪拌の仕上がりなど、個性が生じる余地を設ける。
- 連携相手への慣れ、新しい協力動作、調理中の表情・仕草なども成長対象になりうる。
- 全生物の能力を単一の「料理レベル」で序列化する必要はない。
- 成長や個体差の具体的なパラメータは生き物取り・飼育仕様と共同で【未決定】。

## 7. 食べ物の品質・味・食感・利用【提案】

### 7.1 料理を見分ける要素

| 要素 | 例 |
|---|---|
| 基本カテゴリ | 焼き物、スープ、パン、菓子、飲み物、発酵食品など |
| 食材 | 魚・野菜・果実・穀物・調味料など |
| 品質 | 食材の品質、調理の仕上がり、習熟など |
| 味 | 甘味、酸味、塩味、辛味、うま味、香り |
| 食感 | もちもち、ぷるぷる、ふわふわ、カリカリなど |
| 温度・状態 | 温かい、冷たい、発光、泡立ち、発酵度など |
| 見た目 | 色、サイズ、盛り付け、発光など |

**品質が高い料理を、すべての住民が一律に好むわけではない。** 住民の好み・文化・そのときの状況も独立して影響する。

### 7.2 食事としての機能【未決定／提案】

- 日常的な食事、スタミナ回復（スタミナ制がある場合）、一時的な作業補助、釣り餌、生物のおやつ、住民への贈り物など。
- 料理効果を採用する場合も、食べなければ主要コンテンツに参加できない必須条件にはしない。
- 特定の料理で特殊な見た目や一時的な不思議現象を楽しむ案もある。
- **HP・スタミナの正式仕様、バフの有無・効果量、摂食頻度は未決定**。

### 7.3 鮮度・腐敗【未決定】

- 乾燥・燻製・発酵は、保存期間の延長だけでなく、味・香り・食感が変わった独立商品として価値を持つ。
- 食品の腐敗を取り入れるかは未決定。初期案では、釣りや鉱山へ出掛けた間に陳列品が全部無駄になるような強い負担は避ける方向を推奨。
- 鮮度による品質・価格差、保存設備、劣化の有無・処理は後で決める。

## 8. 時間経過・天候・異星の自然現象【採用推奨／提案】

### 8.1 即時調理と時間経過加工

| 工程 | 時間の扱いの例 |
|---|---|
| 切る、搾る、混ぜる、粉砕する | その場または短時間で処理 |
| 焼く、煮る、蒸す | 操作・調理演出のあと完成 |
| 乾燥、燻製 | 一定のゲーム内時間が必要な案 |
| 発酵・熟成 | 数時間〜数日など、長い処理時間を持てる案 |

- 加工開始後、プレイヤーはその場を離れて農業・釣り・採掘などを楽しめる。
- 加工完了後に取りに戻れる。完成直後に回収しないと失敗する仕組みは基本にはしない方向。
- **睡眠しなくてもゲーム内時間は進む**という時間・天候仕様に合わせる。
- マルチではホストの星の時間を基準に進行する案。

### 8.2 天候との関係

| 天候・自然現象 | 料理・加工への影響【提案】 |
|---|---|
| 晴れ | 天日干しに適した環境になる |
| 雨 | 一部の発酵・特殊加工の条件や見た目に影響 |
| 強風 | 屋外乾燥や風を利用する生物の行動が変化 |
| 霧 | 湿度を好む加工・食材に変化が起こる可能性 |
| 光雨 | 特殊な果実・発光する料理の材料や見た目に影響 |
| 星風 | 香り・胞子・特殊素材との関わり |
| 逆雨 | 液体を利用する独特の加工への応用 |

- **四季限定の料理・加工要件は設けない**。
- 基本の料理は通常の環境でも作れ、珍しい天候は追加の発見・見た目・希少な加工品のチャンスになる方向。
- 特殊天候の名称・具体的な調理効果は別の時間・天候仕様でも【提案】であり、本書で採用確定にはしない。

## 9. 非食品の素材加工【採用推奨】

料理で使う能力を、家具・建築・道具・装飾へも応用する。

| 元素材 | 加工工程の例 | 加工品 | 用途 |
|---|---|---|---|
| 穀物 | 製粉 | 粉 | パン・菓子など |
| 果実 | 圧搾 | 果汁 | ジュース、料理 |
| 魚 | 乾燥・燻煙 | 干し魚・燻製魚 | 食品・販売 |
| 鉱石 | 加熱・加工 | 金属素材 | 家具、道具、装飾 |
| 結晶・宝石 | 研磨・特殊加工 | 加工結晶・宝石 | ランプ、展示品、販売 |
| 木材 | 製材 | 板材 | 家具、柵、増築 |
| 植物繊維 | 紡ぐ・織る | 糸・布 | カーテン、家具、装飾 |
| 花・色のある植物 | 抽出・混合 | 染料 | 家具・壁紙・装飾の色変更 |
| 石材 | 切り出し・整形 | 加工石 | 庭、床材、建築 |

- 原料として挙げた木材・石材などの取得経路は【未決定】。記載しただけで新たな伐採・採石コンテンツを確定した意味にはしない。
- **鍛冶屋でツルハシを強化し、鉱山の深部へ進むという既存ループは維持する**。自宅の加工室を追加して鍛冶屋の役割がなくなることは避ける。
- 一般的な素材加工を自宅で、特別な加工・ツルハシ強化を職人へ依頼する役割分担は【提案】。
- 食品加工と素材加工は共通能力を使うが、具体的な完成品・設備・工程はそれぞれ別に設計する。

## 10. 自宅・家具・キッチンとの連携【採用推奨】

### 10.1 キッチンは自由に作れる

- 自宅の一角にかまど・給水台・製粉台・発酵壺・冷却台などを配置する。
- 設備を組み合わせて、パン工房、お菓子工房、ジュース工房、発酵室、燻製場、素材加工室などを作れる。
- **部屋名を固定せず、置いた設備や生物によって用途が決まる**。リビングや屋外へ適した設備を置く遊びも考えられる。
- 家の増築、家具配置、棚・収納・動線、宇宙生物用の寝床と整合させる。
- 設備の数や配置によって同時に調理できる品数が増える案。

### 10.2 生物との暮らし

- かまどに住むポカリス、調理場の水辺で遊ぶミズプク、棚の近くで休むハコバチなど。
- プレイヤーが料理を始めると、生物が実際に動いて作業する。
- ほかの生物がその様子を眺めたり、住民の訪問時に反応したりする。
- 家を整えることが、新しい料理と生物行動を発見する楽しさにつながる。

### 10.3 自宅の食卓と住民訪問

- 作った料理をテーブルに並べ、訪問してきた住民と食事をする。
- 複数人の食事、持ち寄り、家での調理・お菓子作りなども可能な案。
- 住民の食事時の姿・感想・好みを観察することで宇宙語や性格を知る。

## 11. 住民の料理・食文化・生活【採用推奨】

### 11.1 主人公だけの特殊技能にしない

- **住民たちも昔から宇宙生物を使って料理・加工をしている**世界にする方向。
- 料理人の住民が、ポカリスのかまどでパンを焼く。
- 農家が収穫した作物を加工する。
- 釣り好きが魚を焼く・乾燥させる。
- 発酵好きが発酵壺を研究する。
- 家具職人や鍛冶屋が、料理と共通する生物能力を別用途に活かす。
- 住民が購入した食材・料理は、家で食べたり友達に振る舞ったりする。商品購入が単なる消滅処理にならないよう、既存の住民生活仕様と接続する。

### 11.2 食文化は住民ごとに異なる

- 熱い・冷たい、甘い・辛い、ふわふわ・カリカリ・ぷるぷるなどの好み。
- 食材を吸い込む、浮かべて食べる、独特の道具を使う等、宇宙人の身体的な食べ方の違い。
- 種族の外見で好みを一律に決めず、**住民個人の好みや生活習慣**を持たせる。
- 同じ料理でも高品質だから全員が喜ぶわけではない。
- 住民が互いに料理を教えたり、覚えた料理を日常で使うようになる展開も【提案】。

### 11.3 料理に関するイベント【提案】

| イベント | 内容 |
|---|---|
| 住民の料理を手伝う | 住民が扱う生物や手順を観察し、一緒に調理する |
| 食事への招待 | 住民の家でその人の料理を味わう |
| 食事の持ち寄り | 村人たちが料理を持ち寄り、互いに食べる |
| 誕生日・お祝い | 好きな料理を渡す／住民が手料理を用意する |
| 特別な食材探し | 新しい料理のために食材を集める |
| 料理の再現 | 引っ越した住民が残した味を手掛かりから再現する |

住民の個人ストーリーを深くする要素であり、主目的の宇宙船修理を料理習得で強制的に止めない。

## 12. 宇宙語・マネピ・料理記録【既存決定との連携／採用推奨】

### 12.1 レシピを発見する手段

1. **自分で試す**：食材・能力・手順を変えて結果を確認する。
2. **住民を観察する**：料理人や家族が宇宙生物と調理する姿を観察する。
3. **料理を食べる**：見た目・味・食感や住民の反応を手掛かりにする。
4. **一緒に調理する**：住民が使った生物や調理工程を実際に見る。
5. **マネピの再現を使う**：料理人が預けた実演・説明や声・仕草を見聞きし直す。
6. **料理に関する依頼・行事**：完成品の見本や材料、住民の行動から手順を推測する。

> **マネピは住民の声・表情・仕草を再現する生物**。勝手に未知の言葉を日本語へ翻訳したり、必要な調理手順を自動正解として開示したりしない。調理行動の再現がどこまで正確かは、生物仕様と併せて決める。

### 12.2 タブレットの料理・加工記録【提案】

| 記録項目 | 扱い |
|---|---|
| 料理・加工品の写真／外観 | 実際に作った・見たものを記録 |
| 使用食材・材料 | 自分で使ったもの、観察して分かったものを記録 |
| 使用生物・設備・工程 | 自分で行った手順や確認した情報を記録 |
| 調理の結果・品質・食感 | 自分が実際に確認できた範囲を記録 |
| 自分で付けた料理名 | 自由入力。正式な宇宙語名と混同しない |
| 宇宙語音声カード | 住民の声・マネピから得た資料を関連付け |
| 住民の好みについての予想 | プレイヤーが自由に記入・修正 |
| 再調理 | **実際に自分で成功したレシピ・手順を再現**する補助 |

- **料理の作り方を実際に記録することと、宇宙語の正しい意味を知ることは別**。成功した手順の自動保存は、言語解読の自動正解開示ではない。
- 料理の本当の宇宙語名、住民の本心、未観察の材料や手順は勝手に埋めない。
- 宇宙語辞書・住民辞典・生き物図鑑・料理記録は相互に参照できる方向。
- 住民の料理人が使う命令語（「温める」「水を入れる」等）を、その後の生物の動作から推測できる。

### 12.3 記録例（仮）

- **自分の名前**：赤い魚のスープ
- **自分で使ったもの**：赤い魚1匹、赤い野菜2個、水
- **観察した工程**：ミズプクの給水 → ポカリスで加熱
- **見た目**：赤い湯気の立つスープ
- **住民へのメモ**：「丸い宇宙人が喜んでいた。熱い料理が好きかも」
- **音声カード**：マネピが再現した、食後の住民の声
- **宇宙語の意味**：未確認。ユーザーが自由に仮説を記入

## 13. 商店・経済との接続【既存決定との連携】

### 13.1 セルフ販売を維持

- 主人公は生魚、焼き魚、ジュース、ジャム、パン、燻製、発酵食品、加工素材などを商品棚に並べる。
- **価格は主人公が設定**。住民が自分の予算、好み、食事予定等に応じて購入する。
- 主人公の接客・レジ作業は不要。
- **加工品が必ず原材料より高値で売れるわけではない**。住民によって加工法・食感・料理への需要が異なる。
- ハコバチの搬送と、主人公に断りなく商品を自動補充・自動出品・自動販売することは区別する。**売る品と価格の意思決定は主人公**。

### 13.2 具体的な商売の例

1. 農場で果実を収穫する。
2. 生果実、一部はジュース、一部はジャムに加工する。
3. ジャムの一部をさらにパン・菓子の材料にする。
4. 商品ごとに価格を決め、商店に陳列する。
5. 自分は釣りや鉱山へ出掛ける。
6. 住民が買い、実際の食事・プレゼントなどに利用する。
7. 住民の反応やマネピの音声を確認し、好みや宇宙語を推測する。

### 13.3 後半の発展【提案】

- 自宅の大きな厨房や加工室、複数の生物・設備を揃えて加工ラインを作る。
- 特別な食材、手の込んだ料理、個性的な加工品、高級な盛り付けや家具を研究する。
- 家の増築・家具収集・飼育の設備など、お金を使う側の遊びにもつなげる。
- ロケット修理を急ぐ人にも、料理・商店経営を続けたい人にも、異なる楽しみ方を用意する。

## 14. ワールドシードによる食文化の違い【提案】

本作では宇宙語・地形・気候・初期住民がシードによって変わる方針。食文化も、次のような範囲で星ごとの違いを持たせる案がある。

| 要素 | 方針案 |
|---|---|
| 基本調理能力 | 星をまたいでも共通の考え方を維持 |
| 代表的なレシピ | 大筋を共通とし、試行錯誤の蓄積を活かしやすくする案 |
| 食材の入手環境 | 地形・生息環境・天候によって入手しやすさが違う |
| 住民の好み・人気料理 | 初期住民や生活習慣によって変化 |
| 郷土料理 | 星ごとに好まれる食材の組み合わせや料理文化を持たせる案 |
| 料理名・調理時の言葉 | **星の宇宙語**に従って変化。主人公は自分で解読 |
| 店頭の品揃え | 住民・職人・その星の需要で変化 |

- すべてのレシピをシードで完全に作り替えることは**現時点では採用確定していない**。
- 「気候が違う → 食材・住民の暮らし・人気料理が違う」という連携を優先する提案。
- マルチで別の星へ行ったとき、その星の料理や食習慣を発見する楽しみにつなげる。

## 15. マルチプレイ【提案／既存方針と連携】

| 要素 | 仕様案 |
|---|---|
| 星の時間・天候 | ホストの星の状態を共有 |
| 食材・完成品の受け渡し | プレイヤー同士で交換・プレゼントが可能 |
| 調理器具・生物の利用 | 所有者やホストが利用権限を決める |
| 共同調理 | 一人が加熱、一人が給水、別の人が盛り付ける等、工程分担を楽しめる |
| ソロ調理 | **一人でも一通りの料理・加工を楽しめる**ことが前提 |
| 時間経過加工 | ホストのゲーム内時間で進行する方向 |
| 家具・設備の編集 | 家主の許可が必要 |
| 宇宙語辞書 | 訪問先で**自動配布しない**。任意の共有・贈与は別機能 |
| 料理記録 | 各プレイヤーが自分の発見・仮説を管理する案 |
| 商品の販売 | ホスト側の商店・権限ルールに従う |

調理中に複数人が同じ食材や器具を操作した場合の競合処理、共同料理の品質決定、離脱時の加工状態などは【未決定】。

## 16. システム連携の典型的なプレイ例

### 例A：農業 → 料理 → 商店 → 言語解読

1. 農場で赤い果実を収穫する。
2. 圧搾向きの生物・設備を使ってジュースを作る。
3. ジュースを商店に並べて値付けし、主人公は別の活動へ出掛ける。
4. 宇宙人が購入し、マネピに感想の声や表情が残る。
5. 住民辞典に「赤いジュースが好きそう」と自分で記録する。
6. 次は加熱してジャムにし、さらにパンや菓子にして販売する。
7. 同じ住民の違う反応・宇宙語を比較する。

### 例B：生き物取り → 新しい調理能力 → 新料理

1. 水辺でアワリンを見つけ、その泡を観察する。
2. 自宅の調理器具と組み合わせ、泡立てに使えるか試す。
3. ポカリスの加熱と組み合わせて、ふわふわした料理を発見する。
4. 実際に作った手順をレシピ帳に保存する。
5. お菓子好きの住民に贈り、食べ方や好みを観察する。

※アワリンの料理能力は【提案】であり、元の50種の確定能力ではない。

### 例C：採掘 → 素材加工 → 家具

1. 鉱山で結晶・鉱石を集める。
2. 加熱や研磨の能力を使って素材へ加工する。
3. 家具職人へ渡し、特殊な結晶ランプを制作してもらう。
4. 自宅の食卓や加工室を飾る。
5. 訪問した住民が家具に反応し、音声・思い出が残る。

### 例D：住民の調理を観察 → 再現

1. 料理人の家で、見知らぬ宇宙生物が食材を冷却する様子を見る。
2. 料理人の言葉と生物の動作を観察・音声記録する。
3. 自宅または村の調理場で、確認した工程を再現する。
4. 言葉の意味が未解読でも、料理を作ることはできる。
5. 後から宇宙語が分かり、当時の発言を解釈し直せる。

## 19. 目指す最終的な体験

**捕まえた宇宙生物が、畑で働く。自宅に帰ると同じ生物が料理を手伝う。作った料理を商店へ並べると宇宙人が買い、家で食べる。喜ぶ声をマネピが再現し、プレイヤーは宇宙語の意味や、その住民の好みを少しずつ理解する。**

さらに、鉱石や植物を加工して家具を作れば、家に遊びに来た住民や宇宙生物の暮らしも変わる。

料理・加工は他の主要コンテンツから独立した別ゲームにはせず、**「この星の生き物と暮らすことそのものが、仕事・料理・ものづくりにつながる」**という体験の核に据える。
