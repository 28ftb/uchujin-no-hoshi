# 『宇宙人の星』基本仕様・追加決定事項 v0.1

- **作成日**：2026年10月15日
- **位置づけ**：既存の個別仕様書に対する追加・上書き事項。ゲーム全体の新しい詳細仕様を勝手に確定するものではない。
- **優先順位**：本書の「確定」が古い仕様書の記述と矛盾する場合は、本書を優先する。

## 1. 今回確定した事項（要約）

| 項目 | 決定内容 | 状態 |
|---|---|---|
| グラフィック | **3Dゲームとする** | 確定 |
| 主人公 | **キャラクターメイクを用意する** | 確定 |
| スタミナ | **スタミナ制を採用しない** | 確定 |
| クリア後 | **ロケットの出発直前（ロケット前）に戻って生活を続ける**、または **次の星へ進む** | 確定 |

> 注意：本書で「確定」としているのは上記の方針そのもの。詳細が明記されていない点は提案・未決定として扱い、勝手に仕様を固定しない。

## 2. グラフィック：3D

### 確定

- ゲーム全体の表現は **3D** とする。
- プレイヤー、宇宙人の住民、宇宙生物、村、自然環境、建物、家具、ロケットなどを、3D空間で表現する方向とする。
- ワールドシードによって変わる村の地形・道路・建物配置も、3D空間上に生成する。
- 家・家具・装飾仕様の自由配置や、住民／宇宙生物が家具を利用する仕組みと整合させる。

### 未決定（制作しながら決める）

- カメラの具体的な方式（見下ろし、斜め見下ろし、三人称など）と視点切り替え。
- グラフィックのテイスト、デフォルメ度、ライティング、表情・アニメーションの詳細。
- 家の内外のカメラ・画面遷移、建物内部の表示方法。
- 3D地形や建物の生成単位・具体的な技術方式。

## 3. 主人公：キャラクターメイクあり

### 確定

- ゲーム開始時などに、**主人公を自分好みに作るキャラクターメイク機能**を用意する。
- 作成したキャラクターで、ソロ・マルチプレイの生活を楽しめるようにする。
- 3Dの見た目と、各種生活モーション・住民交流などが破綻しないように設計する。

### 未決定（制作しながら決める）

- 顔、髪型、体型、肌の色、服、アクセサリーなど、具体的な編集項目と選択肢の数。
- 作成後の見た目の変更方法や範囲。
- 衣装の入手、着せ替え、住民の反応との連携。
- マルチプレイで別の星へ移動した際のキャラクター情報の扱い。

## 4. スタミナ：なし

### 確定

- **行動によって減少するスタミナゲージを設けない**。
- 釣り、農業、採掘、生き物取り、料理・加工などを、スタミナ切れによって中断させない。
- スタミナがなくなったことを理由とする、強制帰宅・気絶・作業不能を設けない。
- 活動時間はプレイヤーが選び、夜間の釣りや採掘も続けられる。

### 関連仕様の修正

- 旧「時間・天候」仕様書で提案されていた **睡眠によるスタミナ回復** は採用しない。
- 旧「料理・加工」仕様書で提案されていた **料理によるスタミナ回復** は採用しない。
- 道具強化や経験による成長は引き続き採用候補だが、スタミナ軽減を成長報酬にはしない。
- 睡眠による翌朝への時間送り、時間の経過そのものは、スタミナ廃止とは独立して扱う。

### 未決定（制作しながら決める）

- 食事の用途（能力補助、住民交流、販売、コレクションなど）の具体的な仕様。
- 睡眠に時間送り以外の効果を持たせるか。
- 体力・HPなど、スタミナ以外の状態パラメータを採用するか。

## 5. クリア後：2つの選択肢

### 確定

ロケット修理が完了して帰還を選び、エンディングを見た後、以下の2つの遊び方を用意する。

1. **ロケット前へ戻り、その星で生活を続ける**
2. **次の星へ進む**

### A. ロケット前に戻って生活を続ける

- エンディング後にロケットの出発直前の状態・場所へ戻り、同じ星で引き続き生活できる。
- その星で作った農場、家、家具、商店、住民との関係、辞書・図鑑など、生活の成果を活かして遊び続けることを基本とする。
- 釣り、採掘、農業、宇宙生物の収集、料理、住民交流、宇宙語の解読など、未完了の内容を続けられる。
- **ロケットを修理し終わったからといって、強制的にプレイを終了させない**。

※エンディング再鑑賞方法や、出発直前への復帰時にどのフラグを保持するかなどの細部は未決定。

### B. 次の星へ進む

- エンディング後、**新しい星で新たな生活を始める選択肢**を用意する。
- これまでのワールドシード仕様を活かし、次の星では地形・村・住民構成・宇宙語・気候などが異なる世界になる方向とする。
- 新しい宇宙語、住民、地形、生態系の違いを楽しめるようにする。

### 特に未決定の点

| 項目 | 状態 |
|---|---|
| 次の星への移動を物語上どう説明するか | 未決定 |
| 次の星にキャラクターの見た目を引き継ぐか | 未決定 |
| 持ち物・お金・道具・宇宙生物・家具をどこまで引き継ぐか | 未決定 |
| 辞書・地図・住民辞典をどのように保存・切り替えるか | 未決定。ただし星ごとの宇宙語を混同しない |
| 元の星へ再び戻れるか、複数のセーブ・星をどう管理するか | 未決定 |
| 次の星でのロケット修理・物語の始まり方 | 未決定 |
| 「次の星へ進む」とマルチプレイの星訪問の関係 | 未決定 |

> **「次の星」はクリア後の選択肢として確定**。持ち物の全引き継ぎ／リセットなどは決めていないため、現段階で固定しない。

## 6. 既存の主要仕様と維持事項

今回の決定によって、以下の基本方針は変更しない。

- **大目標**：壊れた宇宙船を修理し、故郷へ帰還する。
- **宇宙語**：星のシードに応じて語彙・文法が変わり、プレイヤーが自分で意味を推測する。自動的な正解翻訳は行わない。
- **住民**：宇宙人は自主的に生活し、買い物・交流・引っ越しを行う。
- **6つの基本活動**：釣り、農業、鉱山、生き物取り、クエスト、セルフ販売の商店。
- **宇宙生物**：約50種類。農業・料理・加工・家具などとも連携する。
- **鉱山**：約10階層。日付更新時にはプレイヤーの目の前でも鉱石が出現・消失・再配置される。
- **季節**：四季は設けない。昼夜や天候・異星独自の自然現象を活用する。
- **ロケット修理**：お金だけでなく、釣り・農業・鉱山・生き物取りに由来する特殊素材や能力を使う方向。
- **マルチプレイ**：他プレイヤーの星への訪問、共同生活、宇宙語辞書の任意共有などを検討する。辞書の自動配布はしない。

## 7. 以後の開発方針

- 大枠として決まった内容は維持し、**残る詳細は実際にゲームを制作・動作検証しながら判断する**。
- すべての未決定事項を開発前に細かく固定することは求めない。
- 必要に応じて仕様を変更・追加し、その際に関連する既存仕様書との矛盾を解消する。
- 実装上の都合だけを理由に、ゲームの面白さや宇宙ならではの要素を勝手に削らない。
- 試行錯誤を通じて、見た目・操作感・住民の反応・コンテンツ間の連携を改善していく。
