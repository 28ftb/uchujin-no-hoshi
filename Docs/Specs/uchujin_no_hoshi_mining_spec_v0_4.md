# 宇宙人の星 — 鉱山・採掘システム仕様案 v0.4

- **作成日**：2026年10月15日
- **位置付け**：鉱山関係の議論を整理した独立仕様案。元の企画書・商店仕様書・釣り仕様書を置き換えるものではない。
- **前提**：本作は、言葉の通じない星でかわいい宇宙人たちと暮らし、生活を通して言語と住民を理解しながら、お金を稼いでロケットを修理し故郷に帰る生活シミュレーションゲーム。

> **区分について**
> - **【採用方針】**：これまでの会話でユーザーが示した、鉱山設計の中核方針。
> - **【提案】**：会話中に出た追加案。採用確定ではない。

## 1. コンセプトと設計原則

### 1.1 基本コンセプト【採用方針】

**「今日は鉱山で鉱石を集めよう」「鍛冶屋にツルハシを強化してもらおう」「深い階層で高価な鉱石を探そう」**という、分かりやすい採掘体験を目指す。

- 鉱山は**10階層程度**。
- **深い階層ほど、良質・高価・希少な鉱石**が見つかる。
- 鉱石には硬さがあり、**ツルハシを強化すると掘れる鉱石が増える**。
- ツルハシの強化は、**採掘した鉱石を使い、村の鍛冶屋の宇宙人に依頼**する。
- 鉱石は地球とは異なる星の不思議な性質で、**毎日ランダムな場所に再出現**する。
- 長期的に鉱石が枯渇せず、何年でも採掘による金策や素材集めを楽しめる。
- 鉱山は本作の生活コンテンツの一つ。複雑な採掘専門ゲームにはしない。

### 1.2 本作全体とのつながり【採用方針／提案】

鉱山単体でも採掘と成長が楽しく、採掘結果が村での生活につながることを重視する。

1. 鉱石を採掘する。
2. 鍛冶屋の住民に道具を強化してもらう。
3. より深い階層の鉱石を掘れるようになる。
4. 集めた鉱石・宝石を商店で売る、依頼に使う、プレゼントする。
5. 住民の反応や宇宙語に触れ、辞書・住民辞典を充実させる。
6. 稼いだお金はロケット修理や日々の生活にも使う。

鉱山攻略は、ロケット帰還に必要な**唯一の金策**にはしない。釣り、農業、商店など、好きな活動を中心に生活できる全体方針を尊重する。

## 2. 鉱山の階層構成

### 2.1 全10階層程度【採用方針】

階層が深くなるほど、より価値の高い鉱石が主に出現する。以下の**鉱石名・階層割り当て・ツルハシ名は仮案**であり、確定値ではない。

| 階層 | 主な鉱石（仮） | 採掘に必要なツルハシ（仮） |
|---|---|---|
| 1〜2階 | 石・銅鉱石 | 初期ツルハシ |
| 3〜4階 | 鉄鉱石 | 銅のツルハシ |
| 5〜6階 | 銀鉱石 | 鉄のツルハシ |
| 7〜8階 | 金鉱石 | 銀のツルハシ |
| 9〜10階 | 星鉱石・希少鉱石 | 金のツルハシ |

**階層への移動可否と、鉱石を掘れるかどうかは区別する。** 深い場所に到達しても、その場にある硬い鉱石はツルハシの強化後に採掘する遊びが想定される。

### 2.2 昇降機と到達記録【提案】

- 一度到達した階層を記録する。
- 鉱山入口の昇降機から、到達済みの階層へ直接移動できる。
- 日常的に気軽に採掘へ出かけられるようにする。

階段・昇降機の見た目や、階層の解放条件、鉱山の広さは【未決定】。

## 3. 鉱石の毎日再出現

### 3.1 基本ルール【採用方針】

この星の鉱山では、鉱石が不思議な性質によって**毎日自然に再出現**する。住民にとっては当たり前の現象。

- ゲーム内で日付が変わると、鉱石がランダムな場所に再配置される。
- 出現する鉱石の**位置・種類・数量は日によって変動**する。
- 階層ごとに出現しやすい鉱石の傾向が異なり、基本的に深いほど希少な鉱石を入手しやすい。
- ある日は特定の鉱石が多く、別の日には珍しい宝石が複数見つかることもある。
- 採掘を続けても、鉱山の資源が長期的に枯渇しない。

### 3.2 日替わりの変化

昨日掘り尽くした鉱山でも、翌日には別の場所に新しい鉱石が出現する。これにより、一度攻略した階層にも再訪する理由が残る。

### 3.3 不要な制約を加えない【採用方針】

- **「強化に必要な鉱石を毎日最低何個保証する」といった条件は設けない方針。**
- 鉱石の種類と数量は通常の出現確率に従って変動させる。
- 「何十日も必要鉱石が出ないはず」といった根拠のない極端な想定から仕様を増やさない。

具体的な確率や出現数は【未決定】。通常のゲームバランスとして調整する。

### 3.4 地形と再配置【提案】

- 鉱山の基本的な地形は維持する。
- 日替わりで鉱石の配置を更新する。
- プレイヤーの所持品や商店に持ち帰った鉱石には影響しない。

鉱石の厳密な再配置タイミングや、鉱山内にプレイヤーがいるまま日付が変わった場合の処理は【未決定】。

## 4. ツルハシと鍛冶屋での強化

### 4.1 強化の基本【採用方針】

- ツルハシは**鍛冶屋の住民に依頼して強化**する。
- 強化には採掘で集めた鉱石を使う。
- 強化により、それまで硬くて掘れなかった鉱石が掘れるようになる。
- 強化後は、以前の弱い鉱石や岩をより少ない回数で壊せるようになる。

費用として**鉱石に加えてお金を支払う方式**も、これまでの案で示されている。必要額・加工時間などの詳細は【未決定】。

### 4.2 強化段階（仮案）【提案】

| ツルハシ | 主な素材（仮） | 主な新能力（仮） |
|---|---|---|
| 初期 | 初期装備 | 石・銅鉱石を掘れる |
| 銅 | 銅鉱石 | 鉄鉱石を掘れる |
| 鉄 | 鉄鉱石 | 銀鉱石を掘れる |
| 銀 | 銀鉱石 | 金鉱石を掘れる |
| 金 | 金鉱石 | 星鉱石を掘れる |

**成長の実感**：初期は何度も叩く必要があった鉱石も、強化が進めば短時間で採掘できる。上位ツルハシによる採掘の爽快感を重視する。

### 4.3 鍛冶屋は一人の住民【提案／既存の住民設計との接続】

- 鍛冶屋も村で生活するかわいい宇宙人であり、単なる強化メニューではない。
- 普段は仕事・休息・ほかの住民との交流などをしている。
- 鉱石を見せながら説明したり、ツルハシを実際に作る様子を見せたりする。
- 友好関係によって個別エピソードや依頼が生まれる。
- 鍛冶屋が引っ越しをする住民システムと、設備としての強化サービスをどう両立するかは【未決定】。引っ越しのせいで機能が恒久的に失われる設計は避ける方向が提案されている。

## 5. 採掘レベル【提案】

ツルハシの強化とは別に、採掘を続けることで経験値を獲得するレベル制も候補とする。

| 成長内容 | 効果の例 |
|---|---|
| 採掘速度 | ツルハシを振る速度が上がる |
| スタミナ効率 | 採掘時の消費スタミナが減る |
| 採掘効率 | 岩を効率よく壊せるようになる |
| 熟練度 | 操作の快適さが上がる |

**役割分担の案**：ツルハシの段階は「何を掘れるか」、レベルは「どれほど効率よく掘れるか」。

採掘レベルを正式採用するか、レベル上限、具体的な補正値、スタミナの有無は【未決定】。

## 6. 鉱石以外の発見物【提案】

採掘では、ツルハシ強化素材以外にも予想外の発見があると楽しい。

| 発見物 | 用途・特徴 |
|---|---|
| 宝石 | 販売、プレゼント、コレクションなど |
| 化石 | 研究好きの住民との交流、依頼など |
| 古代の遺物 | この星の過去を感じられる品物。イベントや収集にも使える |
| 希少な結晶 | 深層で見つかる高価な鉱物 |

### 6.1 宝石の個体差【提案】

- 同じ宝石でも**品質・大きさ**が異なる場合がある。
- 高品質・大型の宝石はより価値が高い。
- 珍しい宝石を掘り当てた瞬間の驚きや喜びを重視する。
- 宝石の採掘ごとに複雑な精密採掘ミニゲームを課す設計にはしない。

宝石の種類や総数、個体差の生成方法は【未決定】。

## 7. 地下生物と戦闘【提案／未決定】

鉱山には、この星ならではのかわいい地下生物が生息していてもよい。

| 仮称 | 特徴の例 |
|---|---|
| イワコロ | 岩に擬態する丸い生き物 |
| キラキラムシ | 宝石の近くで光る小型生物 |
| モグリン | 地中を移動する小動物 |
| イシクイ | 鉱石を食べる生き物 |
| ドシンコ | 大きな体でのんびり動く地下生物 |

- 生き物取りの網などで捕獲できる種類がいてもよい。
- **本格的な戦闘システム、武器、防具、ボス戦を導入するかは未決定。**
- 地下生物をすべて戦闘用の敵にする必要はない。

**重要**：過去の「20階ごとにボス」「120階の戦闘ダンジョン」という旧案は本書の採用仕様ではない。

## 8. 宇宙語・住民交流との連携

### 8.1 宇宙語の扱い【既存の基本方針】

プレイヤーは宇宙語を最初から理解できない。鉱山を通じて会話や仕草を観察し、単語・文法を推測して自分で辞書に書き込む。

- 鍛冶屋が鉱石やツルハシを指して説明する。
- 採掘師が深い階層を指さしながら話す。
- 住民が硬い岩を叩いたり、珍しい宝石を見て喜んだりする。
- 同じ語がほかの生活場面にも登場し、推測を確かめられる。

例として推測できそうな概念は「硬い」「深い」「きれい」「珍しい」「多い」「欲しい」など。

**宇宙語を完全に理解していなくても採掘・強化・依頼に参加できる**ようにする。必要な鉱石の絵、個数、身振りなどが状況の手掛かりになる。星ごとの宇宙語の単語・文法はシードに従って変化する。

### 8.2 住民辞典との連携【既存方針／提案】

- 鍛冶屋や採掘師との会話・出来事を住民辞典に自由にメモできる。
- 鉱石や宝石への住民の反応を記録する。
- 住民が引っ越しても、自分で残した記録は思い出として残せる。
- 正解の性格や翻訳をゲーム側が勝手に書き込まない。

## 9. クエストとの連携【提案】

鉱山は住民の依頼をこなすための採集場所にもなる。

| 依頼主の例 | 依頼の例 |
|---|---|
| 鍛冶屋 | 鉄鉱石を持ってきてほしい |
| 宝石好きの住民 | 特定の色の宝石を探してほしい |
| 研究者 | 化石を見つけてほしい |
| 家具職人 | 石材を集めてほしい |
| 料理好きの住民 | 洞窟に生えるキノコを探してほしい |

依頼内容を宇宙語で表現しながらも、アイテムの絵や住民の行動から推測できるようにする。日常依頼と住民個別ストーリーの双方に利用できる。

## 10. 商店との連携

### 10.1 販売【既存の商店方針】

- 鉱山で得た鉱石・宝石・化石・希少品などを商店の商品として陳列できる案。
- 商店では**並べた商品を住民が自分で購入し、売上が自動で発生**する。
- プレイヤーは販売価格を設定できる方向。
- 鉱石をツルハシ強化に使うか、売ってお金にするか選択できる。

### 10.2 顔付き付箋【既存の商店案】

商品を見た宇宙人が顔付きの付箋を残すことがある。

- 「高い」「きれい」「欲しい」「珍しい」などの意味を持つ宇宙語が書かれる。
- 住民の顔と、どの商品に対する感想なのかを確認できる。
- プレイヤーは付箋を宇宙語辞書と住民辞典に保存できる。
- 宇宙語の正しい意味をゲームが自動で教えたり、メモを勝手に修正したりしない。

鉱山での発見が、商売・住民理解・言語解読へとつながる。

## 11. お金と鉱山の進行

### 11.1 基本の成長ループ【採用方針】

1. 現在のツルハシで採掘できる鉱石を集める。
2. 鍛冶屋に強化を依頼する。
3. 強くなったツルハシで新しい種類の鉱石を採掘する。
4. 深い階層ほど良い鉱石・宝石が見つかる。
5. 売却・商店・クエストなどでお金を稼ぐ。
6. 必要に応じてさらに道具を強化し、繰り返し採掘する。

鉱山で得たお金は、ツルハシ強化だけでなく、生活やロケット修理にも使える。

### 11.2 直接売却【提案】

すぐに換金できる買い取り方法と、自分の商店での自動販売を選択できる案がある。具体的な価格差や需要は【未決定】。

## 12. 鉱山の到達目標と継続プレイ

- **最深の10階前後に到達**することを、鉱山の分かりやすい到達目標とする。【採用方針】
- 10階には希少な鉱石や宝石を用意する。【提案】
- 最深部に巨大な星の結晶が広がる美しい空間や、初到達時の短いイベントを置く案。【提案】
- 最深部に到達しても鉱石は毎日再出現するため、その後も採掘・金策・依頼のために通える。【採用方針】

## 13. マルチプレイ【提案／未決定】

- 友達と同じ鉱山に入って採掘できる案。
- 役割分担しながら異なる階層の鉱石を集めてもよい。
- 鉱石は星の共有資源として、誰かが採掘したらその日の配置から消える方式を提案する。
- 翌日には新しい鉱石が再配置される。

**未決定**：参加人数、ホスト／ゲストの到達階層の共有、ツルハシ強化状態、採掘物の所有権、日付変更の同期など。

## 15. 過去案からの変更・除外

- **旧案の「Stardew Valleyと同じ120階・5階ごとエレベーター・20階ごとボス」は引き継がない。**
- **自由坑道の永久開拓、複雑な地層解析、探査杭、精密採掘ミニゲーム、大規模坑道設備建設を鉱山の中心仕様にはしない。**
- 鉱石の出現に根拠のない極端な前提を設け、対策機能を増やすことはしない。
- 「制作が大変だから」を理由に面白さを削る設計ではなく、**本作が何のゲームか**に基づいて要素を選ぶ。

## 16. まとめ

鉱山の核は、**「採掘 → 鍛冶屋でツルハシ強化 → より深い階層・高価な鉱石 → 売却や住民交流」**という分かりやすい循環。

毎日ランダムに鉱石が出現するため、攻略後も繰り返し遊べる。鉱山での活動は、商店の商品、住民からの依頼、鍛冶屋との交流、宇宙語の辞書と住民辞典に自然につながっていく。

**本作は採掘専門ゲームではなく、かわいい宇宙人たちと暮らしながら言葉や生活を理解していくゲームである**という前提を保つ。
