## 1. 魚釣りのコンセプト

**【採用方向】** 魚釣りは単なる素材収集ではなく、釣りそのものを繰り返し遊びたくなる独立したコンテンツとして作る。『Stardew Valley』のように、釣りの腕前・道具・経験による成長を実感できることを重視する。

面白さの柱は以下の3つ。

1. **釣るのが楽しい**：魚ごとに異なる動き・抵抗への対応と、技術を習得する達成感。
2. **探すのが楽しい**：釣り場、時間帯、天候、餌・仕掛けなどを試して魚を発見する楽しさ。
3. **釣った後も楽しい**：商店販売、住民へのプレゼント、クエスト、釣果記録などにつながる。

**【基本方針】** 宇宙語の解読を魚釣りの必須条件にはしない。言葉を知らなくても釣りを楽しめる一方、住民の発言を理解すると魚の生態や釣り場についての情報が分かり、遊びが豊かになるようにする。

---

## 2. 基本プレイループ

**【提案】**

1. 釣り場を訪れ、場所・時間・天候・魚影などを観察する。
2. 釣り竿、仕掛け、餌・ルアーを選ぶ。
3. 狙った場所へキャストする。
4. 魚が食いついたら釣りミニゲームを始める。
5. 魚の動きに対応し、うまく釣り上げる。
6. 魚の種類・サイズ・重量・品質などを確認し、記録する。
7. 商店で売る、直接売却する、住民に贈る、依頼を達成する、コレクションとして保管するなど自由に活用する。

釣りだけを続けても、ほかの生活要素へ戻っても成立するサイクルにする。

## 3. 釣りミニゲーム

### 3.1 方式

**【提案：有力候補】ライン操作・魚との駆け引き型**

- 魚の動きや抵抗に応じて、リールを巻く・糸を緩める・竿の角度を調整する。
- 無理に巻くと糸の張力が高まり、糸が切れる危険がある。
- 魚が落ち着いた隙を狙えば効率よく引き寄せられる。
- 魚の体力や距離、糸の張力を読みながら釣り上げる。
- 小型魚は初心者でも比較的釣りやすく、大型魚・希少魚は工夫が必要になる。

**【未決定】** 実際の操作ボタン、張力や体力の具体的な数式、画面UI、タイミングの難度、成功・失敗条件。『Stardew Valley』風のゲージ追従型も比較候補とし、現時点でライン操作型への確定はしない。

### 3.2 魚の行動タイプ

| 行動タイプ | 主な動き | プレイヤーに求められる対応 |
|---|---|---|
| おとなしい | あまり暴れない | 基本操作を覚える |
| 暴走型 | 突然高速で泳ぐ | 強引に巻かず糸を緩める |
| 潜行型 | 水底へ潜る | 竿の角度などで誘導する |
| 跳躍型 | 水面から飛び跳ねる | ジャンプに応じて張力を調整する |
| 反転型 | 急に泳ぐ方向を変える | 魚の動きを予測する |
| 持久型 | なかなか疲れない | 長期戦を見越して操作する |
| 変則型 | 複数の行動を組み合わせる | 習得した技術を使い分ける |

**【採用方向】** 難しい魚を単純に高体力にするのではなく、行動の違いで攻略体験を変える。

## 4. 釣りの成長：道具・レベル・テクニック

**【採用方向／重要】** 釣りには次の3種類の成長を設ける。

| 成長軸 | 概要 | 目指す面白さ |
|---|---|---|
| **釣り竿・装備** | 良い道具を手に入れるほど操作が楽になり、魚を引き寄せやすくなる | 装備を更新する達成感 |
| **釣りレベル** | 経験を積むほど以前は難しかった魚を簡単に釣れるようになる | 継続プレイによる成長実感 |
| **釣り名人のテクニック** | 住民から新しい技を教わり、使える釣り方が増える | 交流を通じた技術習得と攻略の幅 |

**基本的な考え方**：道具とレベルは同じ魚を釣る際の負担を軽くする。テクニックは、単に数値が増えるだけでなく、操作・戦術の選択肢を増やす。

### 4.1 釣り道具

**【提案】**

| 道具・装備 | 役割の例 |
|---|---|
| 初期の釣り竿 | 基本的な釣りが可能 |
| 強化釣り竿 | 魚の強い引きに対応しやすい |
| 高性能リール | 巻き速度や制御性能が上がる |
| 強化ライン | 糸が切れにくくなる |
| 浮き | 食いつきを判断しやすくする |
| 重り | 深場を狙いやすくする |
| 餌・ルアー | 特定の魚の食いつき・出現傾向に影響する |
| 特殊な仕掛け | 特殊な生態の魚を狙う新しい方法が使える |

### 4.2 釣りレベル

**【採用方向】** 釣りを続けるほど釣りレベルが上がり、魚釣りが分かりやすく簡単になる。例えば、糸の張力管理が楽になる、魚が疲れやすくなる、釣り上げ速度が上がる、といった補正が考えられる。

- 同じ魚に再挑戦したとき、成長を明確に感じられるようにする。
- 装備とレベルが上がれば、序盤の魚は短時間で安定して釣れる。
- 一方で、上級者にも歯応えのある希少魚・伝説の魚を残す。
- **レベル上限、経験値テーブル、難易度補正は未決定。** 過去の「レベル1・10・30・50」「難易度85％・55％・25％・8％」などは説明用のイメージで、正式な数値仕様ではない。

### 4.3 釣り名人から教わる技

**【採用方向】** 村や各釣り場に暮らす釣り名人と交流することで、テクニックを教えてもらえる。

**【提案：技の候補】**

| 技名（仮） | 効果・役割の例 |
|---|---|
| 糸さばき | 魚が暴れたとき素早く張力を調整する |
| ため巻き | 魚が疲れた瞬間に効率よく引き寄せる |
| 魚の誘導 | 竿の角度を使って魚の進行方向を変える |
| 精密キャスト | 狙った場所へ正確に投げる |
| 誘い釣り | ルアーの操作で食いつきを誘う |
| 魚の見極め | 魚の動きから次の行動を予測しやすくする |
| 名人の極意 | 釣り上げる直前の抵抗を抑える技 |

> **注意：** 技名・技の総数・効果は仮案。採用するミニゲーム方式に合わせて、無理なく本当に使い分けが面白い技へ調整する。

## 5. 釣り名人と住民交流

### 5.1 教わる体験

**【採用方向】** 名人は単なるスキル購入窓口ではなく、性格・生活・夢を持つ一人の宇宙人として描く。

**【提案：イベント例】**

1. 毎朝川で釣りをしている年配の宇宙人と出会う。
2. 名人は宇宙語で何かを話すが、プレイヤーには意味が分からない。
3. 名人が大きな魚を釣り、特徴的な竿操作を実演する。
4. 身振りと実演を頼りにプレイヤーが同じ動きを試す。
5. 成功すると、技を習得する。
6. 宇宙語を解読していれば、名人の会話から追加の意味や背景も読み取れる。

**【基本方針】** 技の習得に宇宙語の完全解読を必須としない。行動・実演・状況が手がかりになる。

### 5.2 名人のタイプ

**【提案】**

- **川釣り名人**：魚の動きの読み方を教える。
- **海釣り名人**：大型魚への対処を教える。
- **ルアー職人**：仕掛けの工夫と誘い方を教える。
- **伝説の釣り人**：珍しい釣り場などに現れ、特別な技を持つ。

名人同士が張り合う、釣果を見せ合う、主人公を釣りに誘うなど、個別エピソードにもつなげる。

### 5.3 引っ越しとの関係

**【提案】** 名人も村へ引っ越してきたり、別の土地へ移ったりする。

- 引っ越してきた名人に出会うことで新しい習得イベントが生じる。
- 一度習得した技は、名人が引っ越しても失われない。
- 名人との思い出や会話は住民辞典に残せる。
- 出会えなかったから永久に技が習得不能、ということは避け、再会や別の習得手段を設ける方向。

**【未決定】** 名人の人数、登場の保証方法、技の前提条件、交流度の影響、再会方法。

## 6. 釣り場と魚の出現条件

**【提案】**

| 釣り場 | 特徴の例 |
|---|---|
| 村の川 | 初心者向けの魚が多い。住民がよく訪れる |
| 森の池 | 特定の植物や餌を好む魚がいる |
| 海岸・桟橋 | 大型魚・群れで泳ぐ魚・潮流の影響 |
| 鉱山の地下湖 | 地上では見られない魚、発光・洞窟性の魚 |
| 特殊な水場 | 滝の裏など、発見条件が独特な場所 |

魚の出現に影響する候補は、**水域・時間帯・天候・季節・餌・仕掛け・特定の環境条件**など。

広大な惑星探索を必須にするのではなく、村と周辺地域の中に釣り場ごとの特徴を持たせる方向を維持する。

## 7. 宇宙魚の種類と個性

**【採用方向】** 本作に登場する魚は、宇宙ならではのかわいさ・不思議な生態を持つ。外見だけでなく、釣り中の動きも特徴づける。

**【提案：サンプル魚種。正式名称・総数は未決定】**

| 仮称 | 外見・生態 | 釣りでの特徴 |
|---|---|---|
| ヒカリウオ | 夜に発光し群れで泳ぐ | 夜間に探しやすい、群れで出現 |
| クルクルウオ | 円を描いて泳ぐ | 独特の方向転換を繰り返す |
| ハネウオ | 水面からよく跳ぶ | ジャンプに合わせた操作が必要 |
| プクフグ | 驚くと体が膨らむ | 途中で急に抵抗が強くなる |
| クリスタルフィッシュ | 半透明で鉱石のように光る | 鉱山の地下湖などに生息 |
| リボンウオ | 長いひれを持つ美しい魚 | 素早い方向転換が得意 |

通常の魚、珍しい魚、季節魚、巨大個体、伝説の魚など、収集・攻略の両面で幅を持たせる。

**【基本方針】** 住民が話す魚の名前は星ごとの宇宙語に従う。上表の日本語名は開発・説明用であり、星のシードごとに変わる言語体系を壊さない。

## 8. サイズ・品質・釣果記録

**【提案】** 同種の魚にも個体差を設ける。

- **サイズ・重量**：同じ魚でも大きな個体を狙える。
- **品質**：釣り方や魚の状態などと関連づける候補。
- **希少性**：出現条件や生息数で違いがある。
- **特殊個体**：珍しい色・模様・大きさなどがある。
- **個人記録**：最大サイズ・最大重量などを残す。
- **釣果帳**：釣った種類や自己記録をいつでも確認する。

釣果帳は実際の捕獲情報を記録するもので、**宇宙語辞書の正答集にはしない**。

**【提案】** サイズ・重量を競う釣り大会も考えられるが、採用と実施頻度は未決定。

## 9. 珍しい魚・伝説の魚

**【提案】** 特別な条件と独自の行動を持つ上級者向けの魚を用意する。

| 種類の例 | 条件の例 |
|---|---|
| 雨を好む魚 | 雨天時 |
| 夜光魚 | 夜間 |
| 深場の巨大魚 | 特定の深い水域 |
| 洞窟の希少魚 | 鉱山の深い階層 |
| 季節回遊魚 | 特定の季節 |
| 伝説の巨大魚 | 特殊な場所・環境条件 |

**【採用方向】** 伝説の魚は単なる高体力ではなく、固有の行動で釣り方の研究が必要になるようにする。宇宙語の解読がヒントになることはあっても、毎回必須の謎解きにはしない。

**【未決定】** 伝説の魚の数、再捕獲可否、個別イベント、報酬。

## 10. 宇宙語の解読との連携

**【基本方針】** 宇宙語は星ごとのシードにより語彙・語順・文法が変わる。プレイヤー自身が会話や状況から意味を推測し、辞書へメモする。ゲームが自動的に正解を教えない。

**【提案：釣り場での解読体験】**

- 住民が大きな魚影を指して何かを話す。別の場面で同じ語を聞いて「大きい」を推測する。
- 釣り好きの住民が魚の名前を繰り返す。目の前の釣果と結びつけて意味を考える。
- 名人が釣りの動作を実演する。言葉と仕草を照らし合わせる。
- 珍しい魚がいる時間帯や場所を住民が教える。理解すれば探索のヒントとして使える。

魚釣りへの参加・上達・クリアを、宇宙語の理解度で不必要に制限しない。

## 11. 住民交流・住民辞典との連携

**【採用方向】** 住民も実際に釣りを行い、釣り場を交流の場にする。

**【提案】**

- 住民ごとに釣りの好き嫌い、腕前、得意な釣り場、好みの魚を持つ。
- 隣同士で釣りをしたり、釣果を見せ合ったりする。
- 主人公が大物を釣ると驚き、住民が釣った魚を見せてくることもある。
- 釣り好きの住民と親しくなると、一緒に釣るイベントが起きる。
- 魚をプレゼントすると好みに応じた反応が返る。
- 名人に教わった技、その場で聞いた宇宙語、住民との思い出を住民辞典にメモできる。

住民辞典はプレイヤーが住民の性格・好み・行動・関係性を自由記録するもの。正しい解釈を自動確定しない。

## 12. 商店・クエスト・ほかの生活要素との連携

### 12.1 商店

**【基本方針】** 商店は**商品を棚に陳列しておけば、住民が自分で購入し、自動的に売れていくセルフ販売方式**。店番やレジ操作を前提にしない。

**【提案】**

- 魚を商店に並べて価格を設定する。
- 住民の好みや魚の希少性により、売れ方が変わる。
- 店を離れて釣りをしている間にも売上が発生する。
- 売れ残った魚や大物・珍魚について、住民が**顔付きの宇宙語付箋**を残すことがある。
- 付箋を宇宙語辞書と住民辞典の両方に保存し、魚の種類・価格・購入状況などの文脈と一緒に振り返れる。
- 付箋の意味が「高い」「珍しい」「好き」などのどれかは、プレイヤーが推理する。

### 12.2 クエスト

**【提案】**

- 特定の魚を釣ってほしいという依頼。
- 一定以上のサイズの魚を納品する依頼。
- 住民の好物や研究対象となる魚を探す依頼。
- 名人や釣り好き住民との連続エピソード。

### 12.3 採掘・農業・生き物取り

**【提案】**

- 鉱山の地下湖でも釣りができ、採掘の合間に新しい魚を探せる。
- 餌や仕掛けの入手に、農業・採集・制作などが関わる余地を持たせる。
- 釣った魚の売却・贈答・保存などで、ほかの活動と自然につながる。

---

## 13. マルチプレイでの釣り

**【提案】**

- 同じ釣り場で複数プレイヤーが並んで釣れる。
- お互いの大物や珍魚の釣果を見られる。
- サイズ競争、釣果を見せ合う遊び、協力して魚を探す遊びができる。
- 訪問先ではその星の宇宙語が使われる。
- 訪問しただけで辞書が自動共有されることはない。辞書を渡すかはプレイヤーの自由。

**【未決定】** マルチの人数、釣り判定の同期、魚の出現共有・個別化、記録の扱い、釣り大会のルール。

## 15. 今後の重点検討項目

1. **釣りミニゲーム方式**：ライン操作型、ゲージ追従型、または独自方式のうち、操作していて最も面白い形式を選ぶ。
2. **道具・レベル・技の効果分担**：3つの成長軸が重複しすぎず、明確に上達を感じられる形を作る。
3. **魚種ごとの行動設計**：魚ごとに固有の釣り心地を生み、伝説魚にも攻略の個性を持たせる。
4. **釣り名人の個別ストーリー**：住民としての性格や生活、習得イベント、引っ越しとの関係を深める。
5. **釣果と商店経済**：魚の希少性・大きさ・品質・価格・住民の好みの関係を決める。
6. **魚種・釣り場・大会等の全体規模**：具体的な数やコンテンツ密度を面白さの観点で決める。制作負担だけを理由に減らさない。
7. **マルチ同期**：複数プレイヤーでの釣り、住民との交流、釣果記録をどう扱うか。

## 16. 本作らしさのまとめ

> **釣りが上手になるほど釣ること自体が楽しくなり、住民と釣りをするほど彼らとの思い出が増え、宇宙語も少しずつ理解できるようになる。**
>
> 道具・レベルで確実に成長し、名人から学んだ技で腕を磨く。釣った魚は自分の商店へ並べられ、宇宙人が残した顔付き付箋が次の発見につながる。

この方針を、今後の魚釣り詳細設計の出発点とする。
