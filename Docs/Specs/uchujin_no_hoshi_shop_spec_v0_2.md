- **作成日**：2026年10月14日
- **対象企画**：『宇宙人の星』（仮）
- **資料の位置付け**：商店経営に関する議論・提案の整理。実装の最終確定仕様ではない。

## 0. 仕様の扱い

本資料では、次の区分を使う。

- **【決定】**：会話で明確に決めた方針。
- **【方向性】**：概ね合意しているが詳細をまだ詰めていないもの。
- **【提案】**：面白さを高めるための追加アイデア。自動的に確定仕様とはしない。
- **【未決定】**：これから検討すべき詳細。

**設計の優先順位は、ゲームの面白さ → 必要な要素の設計 → 実現方法。制作負担だけを理由に、面白さにつながる要素を勝手に削らない。**

## 1. 商店のコンセプト

**【決定】** 店番・個別注文・レジ操作を強制しない、**商品陳列型のセルフ販売・自動売上方式**を基本とする。

プレイヤーが商品を並べておけば、宇宙人の住民たちが店に来て、自分で商品を選び、購入していく。プレイヤーが釣り、農業、採掘、クエスト、生き物取りを楽しんでいる間にも店が動く。

商店の面白さは、単なる放置収益ではなく、**品揃え・価格・在庫の調整と、住民の反応の観察**にある。買い物中に住民が残す顔付きの宇宙語の付箋を手掛かりに、宇宙語と住民の好みを理解できるようにする。

### 1.1 基本ループ

1. 商品を釣る・採る・育てる・掘る・仕入れるなどして用意する。
2. 店の棚に商品を並べ、販売価格を設定する。
3. 住民が来店し、好みや価格などに応じて購入する。
4. 留守中も在庫・売上が変動し、ときどき顔付き付箋が残される。
5. 店へ戻り、売上・在庫・付箋・来店履歴を確認する。
6. 必要なら宇宙語辞書・住民辞典に記録し、品揃えや価格を調整する。
7. 利益を生活や店舗拡張、ロケット修理に使う。

**【方向性】** プレイヤーが店に常駐しなくても経営できる。来店を眺める楽しさと、外出中の自動販売を両立させる。

## 2. 商品と仕入れ

**【方向性】** 他の生活コンテンツと連動し、自己調達だけでなく仕入れ販売もできる。

| 商品分類 | 主な入手方法 | 商店での特徴（案） |
|---|---|---|
| 農作物 | 農業 | 日常的な需要・収穫量の多さ |
| 魚 | 釣り | 種類・大きさ・品質による価値の差 |
| 宇宙生物 | 生き物取り | 珍しい生物への関心・収集需要 |
| 鉱石・宝石 | 採掘 | 高価な商品・装飾や収集需要 |
| 食料品 | 仕入れ・加工 | 日常的に購入される商品 |
| 雑貨 | 仕入れ・制作 | 住民の趣味・好みの影響が大きい |
| 家具・装飾品 | 仕入れ・制作 | 高価格帯の商品も扱える |
| 珍品 | 特別な入手手段 | 一部の住民・来訪者が強く欲しがる |

**【提案】** 自分で採集をしなくても、仕入れ中心の経営が成立する。また、商店に並べず買い取り店などで直接売る選択肢も持たせる。直接売却は即金性、商店販売は値付けの自由と売れ残りリスクで区別する。

**【未決定】** 初期の商品種類、調達費用、品質・鮮度の詳細、加工・制作の範囲、買い取り店の具体仕様。

## 3. 価格設定と購買行動

### 3.1 値付け

**【方向性】** プレイヤーが商品ごとに価格を決める。

- 高額設定は1個当たりの利益を上げられる可能性があるが、購入されにくくなる。
- 低額設定は売れやすくなるが、利益が小さくなる。
- 「適正価格を超えたら全住民が絶対に買わない」という単純な仕組みにはしない。
- 価格の感じ方は、商品の価値だけでなく、住民の好みや経済状況にも左右される。

### 3.2 住民の購買傾向

**【提案】** 住民ごとに買い物の好み・所持金・買い物頻度を持たせる。

| 住民の傾向 | 購買行動の例 |
|---|---|
| 節約家 | 安い商品、割引品を好む |
| お金持ち | 高価な商品も購入しやすい |
| 食いしん坊 | 食料品をよく購入する |
| 収集家 | 珍品なら高価でも購入しやすい |
| 流行好き | 人気商品・新商品に反応する |
| こだわり派 | 特定ジャンル・好物を優先する |
| 気まぐれ | 日によって購入傾向が変わる |

同じ商品・同じ値段でも、ある住民には「高い」、別の住民には「お買い得」と感じられる。

**重要**：付箋に書かれる宇宙語の意味は一貫している。一方、住民が何を「高い」と思うかは主観的でよい。

**【未決定】** 商品価格の基準、需要計算、購入頻度、住民の財布・収入の扱い、客数や販売量のバランス。

## 4. 顔付き付箋システム

### 4.1 概要

**【方向性】** 住民が商品を見たり購入したりした際、ときどき感想や要望を**宇宙語の付箋**として残す。

- 付箋には**書いた住民の顔**を付け、誰の反応か分かるようにする。
- 付箋には宇宙語で「高い」「安い」「欲しい」などの内容が記される。
- すべての買い物で必ず付箋が出るわけではない。印象が強かった場面などで残す。
- プレイヤーは付箋を集め、解釈を考え、辞書や住民辞典の記録に使える。
- **ゲーム側が付箋の正しい翻訳を自動的に表示しない。**

付箋を残す行為には、例えば「商品に感想を書き残す習慣がある」という住民文化の設定を与えられる。

### 4.2 付箋の内容候補

| 分類 | 内部的な意味の例 |
|---|---|
| 値段 | 高い、安い、お買い得 |
| 品質・感想 | おいしい、きれい、すごい |
| 好き嫌い | 好き、嫌い、欲しい |
| 比較 | こっちがいい、前のほうがよかった |
| 要望 | もっと欲しい、別の商品が欲しい |
| 希少性 | 珍しい、初めて見た |
| 感謝 | ありがとう、助かった |

※表の日本語は設計者が理解するための**内部の意味**。実際の画面では、その星のシードに応じた宇宙語が表示される。

### 4.3 付箋と状況が結び付くこと

付箋はランダムな文章表示ではなく、**その住民が実際に感じた内容**に対応させる。たとえば、ある価格を高いと感じて商品を見送った住民が、それに相当する宇宙語を残す。値下げ後に買うようになれば、別の感想が出る場合もある。

### 4.4 値段を使った言語解読の例（説明用）

1. 星リンゴを300Gで売る。ほとんど売れず、「モギラ！」という付箋が複数残る。
2. 200Gに下げる。売れ始め、別の「ピルナ！」という付箋が現れる。
3. 100Gに下げる。よく売れ、「ピルナ！」が増える。
4. プレイヤーは「モギラ＝高い？」「ピルナ＝安い？」という仮説を立てる。
5. 辞書に自分で書き込み、ほかの買い物や住民の会話で確かめる。

**「モギラ」「ピルナ」や300G等の数値は例示であり、決定された単語・価格ではない。** 実際には語彙・語順・文法が星のシードごとに変わる。

**【未決定】** 付箋の出現頻度、1商品あたりの表示枚数、保管容量、古い付箋の扱い、複文・質問文の範囲。

## 5. 宇宙語辞書との連携

**【決定済みの基本原則】** 宇宙語の正解は自動解放しない。プレイヤーが単語や文法を自分で推測・記録する。

**【方向性】** 商店の付箋は、単語の意味を考えるための**証拠**になる。

- 商品や価格、前後の売れ行きが推理の手掛かりになる。
- 付箋の原文を宇宙語辞書へ引用・保存できる。
- プレイヤーが自由に「高い？」「誉め言葉かも」など仮説を書ける。
- 同じ表現が住民の会話など他の状況にも登場するため、商店だけで言語学習が閉じない。
- プレイヤーの誤解をゲームが自動訂正しない。

**【未決定】** 辞書側の引用UI、付箋と辞書項目の紐付け、自由入力・検索の仕様。

---

## 6. 住民辞典との連携

### 6.1 基本

**【方向性】** 宇宙語辞書とは別に、住民ごとのページを持つ**住民辞典**を用意する。プレイヤーは、その住民について自由にメモできる。

- 名前や呼び名、性格、好物、行動時間、仕事、他の住民との関係などを書き留める。
- 商店で見つけた**顔付き付箋を該当住民のページに貼る**。
- 付箋に自分の解釈や観察結果を追記する。
- **同じ付箋を宇宙語辞書と住民辞典の両方に保存できる**案。
- 「節約家」「甘党」などを自動的に正解判定せず、プレイヤーが判断する。
- 引っ越した住民のページや思い出の付箋も残す。

### 6.2 保存したい付箋の情報（提案）

- 付箋の**宇宙語原文**
- 書いた**住民の顔・識別情報**
- 対象となった**商品**
- そのときの**価格**
- 住民が**購入したか、見送ったか**
- 発見した日や場面
- プレイヤーの自由メモ

古い付箋に当時の値段を残せば、値付けを変えた後にも比較できる。

### 6.3 住民を誤解する面白さ

同じ表現を繰り返す住民について「いつも文句を言う」と書いていたが、別の場面から実は褒めていたと気づく――といった体験を目指す。**誤った推測も思い出として残り、自分で修正できる**のが重要。

**【未決定】** 辞典のUI、付箋の貼り方と複製、購入履歴の自動表示範囲、転居後の閲覧・再会時の扱い。

## 7. 要望付箋と店の要望ボード

**【提案】** 商品への感想のほか、「売り切れた商品が欲しい」「特定の商品を入荷してほしい」といった要望も宇宙語の付箋として残せる。

- 空の棚に「もっと欲しい」と書く。
- 要望ボードへ**商品の絵と宇宙語**を残す。
- プレイヤーは図や状況から言葉を推測する。
- 要望に合わせて釣り・農業・採掘・仕入れに出かける。
- 入荷後、要望した住民が購入することもある。

これにより、**住民の需要がほかの生活活動へ向かう動機になる**。

**【未決定】** 要望ボードの設置条件、要望を叶えた際の反応・報酬、商品画像の提示方法。

## 8. 店舗拡張・レイアウト

**【提案】** 稼いだお金で商店の規模や設備を拡張する。

| 拡張要素 | 役割の例 |
|---|---|
| 商品棚の追加 | 陳列できる種類・数量を増やす |
| 倉庫拡張 | 保管量を増やす |
| 自動補充設備 | 倉庫から棚へ補充する |
| 冷蔵・保存設備 | 魚や農作物などを長持ちさせる |
| 店舗面積の拡張 | 大きな商品・家具も扱える |
| 内装・装飾 | 店の雰囲気を自由に作る |
| 看板・広告 | 来店客や商品の注目度を高める |
| 特売コーナー | 値引き商品を目立たせる |

**【提案】** 店内配置にも意味を持たせる。入口付近の商品は目につきやすい、関連商品を並べるとまとめ買いにつながる、といった効果を検討する。

住民は多彩な体型（まんまる、浮遊型、多腕型など）で来店し、各自らしい動きで買い物をする。**通常の棚は種族を問わず利用できる**ようにし、体型差だけで不当に購入不能にしない。

**【未決定】** 店の初期規模、家具・棚の配置自由度、拡張段階、設備費用、レイアウト効果の計算。

## 9. 売上レポート・来店履歴

**【方向性】** 帰宅・帰店後に、その間のお店の動きが分かるようにする。

表示する項目の案：

- 売上金額・販売個数
- 商品別の販売実績
- 在庫・売れ残り・売り切れ
- 新しく残された付箋
- 商品ごとの販売推移
- 誰が何を買ったかという来店・購入履歴

### 9.1 レポート例（数値は仮）

| 項目 | 表示例 |
|---|---:|
| 本日の売上 | 2,450G |
| 販売個数 | 18個 |
| 新しい付箋 | 4枚 |

| 商品 | 販売数 | 売上 |
|---|---:|---:|
| 星リンゴ | 8個 | 1,200G |
| 青い魚 | 4匹 | 800G |
| 宇宙キノコ | 6個 | 450G |

**重要**：販売金額・数量・商品管理などのシステムUIはプレイヤーの使用言語で理解できる。**宇宙語なのは住民が発した会話や書いた付箋**であり、すべての管理画面を解読させない。

**【未決定】** レポートの集計単位、履歴の保存期間、住民辞典への連携方法、統計機能の詳細。

## 10. 商店が住民の生活へ与える影響

**【提案】** 購入によって住民の暮らしにも小さな変化が起きる。

- 料理好きの住民が珍しい野菜を購入し、翌日それを料理に使う。
- 雑貨好きの住民が店で買った置物を自宅に飾る。
- 買った商品を話題に、住民同士が会話する。
- 新しい住民が引っ越してくると、売れ筋や店への反応も変化する。

**品物を売る → 住民の生活が変わる → 新しい会話が生まれる → 言語や人物像の発見につながる**、という循環を目指す。

## 13. 今後検討すること

1. 店の営業方式：常時営業か営業時間制か、留守中にどこまでシミュレーションするか。

3. 価格と需要：相場・住民の予算・好み・購入確率など。
4. 付箋：発生条件、表現種類、表示・保管方法、要望との区別。
5. 辞書・住民辞典：付箋の貼り付けUI、自由メモ、検索・比較。
6. 店舗拡張：成長段階、費用、装飾・レイアウトと販売効果。
7. 住民行動：購入商品の利用、住民間の会話、転入・転出による需要の変化。
8. 経済バランス：商店、直接売却、ほかの金策、ロケット修理との収益バランス。
9. マルチプレイ：ゲストの購入・陳列権限や、商店情報・付箋の同期。

## 14. 商店で目指す体験

> プレイヤーは商品を並べて自由に暮らす。留守中に宇宙人たちが買い物をし、帰ってきた店には売上と、顔付きの宇宙語の付箋が残っている。値段を変える、品揃えを変える、住民の好みを探る。観察したことを宇宙語辞書や住民辞典に自分で書き込み、次の商売に活かしていく。住民を知るほど商売が上手くなり、商売をするほど住民のことが分かる。

**「商店経営」と「宇宙語の解読」と「住民との暮らし」が相互に面白くなること**を、このシステムの中心に据える。
