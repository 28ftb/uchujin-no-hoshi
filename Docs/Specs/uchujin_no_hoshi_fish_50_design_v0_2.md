## 1. 全体コンセプト

**【採用方向】** 魚釣りを単なる素材収集ではなく、**釣る・探す・上達する・釣った魚を活用する**こと自体が楽しい独立した生活コンテンツとして扱う。

**【提案】** 各魚の個性は、可能な限り次の観点で表現する。

1. **一目で異なるシルエット**：頭、胴、ヒレ、尾、模様、質感、サイズの組合せで識別できる。
2. **異なる生態**：泳ぎ方、群れ、音、光、水流や天候への反応などに違いがある。
3. **異なる釣り心地**：単純な高体力化ではなく、突進、潜行、跳躍、回転、静止、反転などの特徴的な抵抗を持つ。
4. **釣った後の価値**：生魚販売、料理・加工、住民への贈答、クエスト、水槽展示、記録、特殊素材などへつなげる。
5. **星の暮らしとのつながり**：住民の趣味・会話・宇宙語・ロケット修理・マルチプレイと自然に連動する。

### 1.1 内訳

| カテゴリ | ID | 種類数 | 主な役割 |
|---|---|---:|---|
| 一般魚 | F001〜F020 | 20 | 序盤の釣り、日常販売、料理、水槽展示、各行動タイプの入門 |
| 個性派魚 | F021〜F035 | 15 | 特殊な釣り行動、名人の技を使う遊び |
| 希少魚 | F036〜F045 | 10 | 場所・時間・天候・習性の発見、収集 |
| 伝説魚 | F046〜F050 | 5 | 高度な釣りへの挑戦、大型展示、長期目標 |
| **合計** | **F001〜F050** | **50** | |

- `F` は **Fish（釣り魚）** 用の整理ID。宇宙生物の `001〜050` と混同しないための接頭辞で、ゲーム内に表示するかは【未決定】。
- カテゴリ分類と20・15・10・5の内訳は【提案】。難易度階級や固定の価格ランクを確定させるものではない。
- 魚名はすべて**仮称**。釣り仕様 v0.2 のサンプル魚種「ヒカリウオ」「クルクルウオ」「ハネウオ」「プクフグ」「クリスタルフィッシュ」「リボンウオ」を含む。

### 1.2 表の見方

- **サイズ**：XS（手のひらに乗る）／S（小型）／M（中型）／L（大型）／XL（特大・大型水槽や特別展示向け）。実寸は【未決定】。
- **生息候補**：生態を説明する現段階の候補。厳密な排他的スポーン条件ではない。
- **行動タイプ**：釣り仕様 v0.2 §3.2 の7類型（おとなしい／暴走型／潜行型／跳躍型／反転型／持久型／変則型）のうち主なもの。
- **修理**：ロケット修理の素材候補（§9）。

## 8. 宇宙生物との区別【提案】

宇宙生物仕様 v0.2 では、同じ水辺で魚釣りと生き物取りの両方を楽しめるとされている。プレイヤーが**竿を使うのか網を使うのか**迷わないよう、以下のルールを設ける。

1. **見え方で区別する**：魚は水中の**魚影**と水面の波紋で見える。水辺の宇宙生物は、水面の上、岸辺、岩の上など、網が届く位置に姿が見える。
2. **似たモチーフは動きで区別する**：

| 魚 | 似た宇宙生物 | 区別の仕方 |
|---|---|---|
| F023 ハネウオ | 023 カワハネ（水面を跳ねて移動） | ハネウオは水中の魚影から飛び出し、胸びれで滑空してから水中へ戻る。カワハネは水面上を跳ね続け、岸に上がる |
| F025 リボンウオ | 028 シオリボ（リボン状のひれで岩に張り付く） | リボンウオは開けた水中を泳ぎ続け、岩に張り付かない |
| F021 ヒカリウオ | 007 ヒカリムシ（夜に光る小型生物） | ヒカリウオは水中で群れて点滅する。ヒカリムシは草むらにいて水中には入らない |

3. **開発用仮名でも一字違いの名前は避ける**：v0.1 の「スミカケ」は宇宙生物045「スミカゲ」と一字違いだったため、「モヤハキ」に変更した。v0.1 の「キノハウオ」は宇宙生物011「ハッパリ」と同じ「葉っぱそっくり」のモチーフだったため、F008 を差し替えた。

## 11. 釣りシステムとの接続

**【採用方向】** 魚50種類の行動を生かすため、釣りの成長要素を次の3軸で扱う（釣り仕様 v0.2 §4）。

1. **釣り竿・装備**：釣り竿、リール、ライン、浮き、重り、餌・ルアー、特殊仕掛けなどで、操作の負担や狙える範囲を変える。
2. **釣りレベル**：釣り経験を積むと、以前苦戦した魚も釣りやすくなる。
3. **釣り名人のテクニック**：糸さばき、ため巻き、魚の誘導、精密キャスト、誘い釣り、魚の見極め、名人の極意などの技案。技名・種類・効果は【未決定】。

### 11.1 ミニゲーム方式への依存【未決定】

ただし、以下の魚は「3D空間で魚や糸が見えるライン張力操作型」を前提にした表現を含む。方式を決めるときの判断材料とし、ゲージ型を選んだ場合の代替表現も併記する。

|---|---|---|
| F026 モヤハキ | 煙幕で魚が見えなくなり、糸と波紋で追う | ゲージ上の魚アイコンが一時的に消える |
| F032 ジシャクウオ | 竿の角度で鉱石から引き離す | ゲージの一方へ吸い寄せる力が働く |
| F036 クリスタルフィッシュ | 見える位置と実際の位置のずれ | アイコンが実際の位置からずれて表示される |
| F039 シルベフデ | 光の軌跡で次の進路を予告 | 次の移動先が光で予告される |
| F043 オトナシ | リールを巻く速さへの反応 | 素早く操作すると警戒ゲージが上がる |
| F044 ヒヤシウオ | 深さ・距離による変化 | 取り込みが近づくほど動きが速くなる |
| F046 カガミヌシ | 水面の虚像 | 偽のアイコンが逆方向に動く |
| F048 ウズシロ | 渦への引き込みと角度による誘導 | ゲージ中央へ引き寄せる力と、その向きの反転 |

### 11.2 音以外の手掛かり【提案】

音で分かる要素を持つ魚（F030 ハモリウオ、F041 イワナキ、F043 オトナシ）には、目で見て分かる手掛かりを必ず併せて用意する（各表に記載）。音が聞こえにくい状況やプレイヤーにも対応し、BGMやマルチプレイの会話で聞き取りにくい場面にも配慮する。

### 11.3 スタミナ

**【基本方針】** 行動によって減るスタミナゲージは設けない（基本決定 v0.2）。釣りを長く続けても、強制帰宅や気絶は起きない。

## 12. 宇宙語・住民・釣り名人との接続

- **【基本方針】** 釣りを始める・上達する・魚を釣り上げるために、宇宙語の完全解読を要求しない。
- **【提案】** 住民が魚を指差す、大物に驚く、釣り場を教えるなどの出来事が、プレイヤーの自由な言語推理の材料になる。
- **【採用方向】** 釣り名人は技の自動購入窓口ではなく、実際に生活し、実演や交流を通じて技を教える住民として描く。
- **【基本方針】** 旧案の「顔付き付箋」は採用しない。タブレット・辞書・住民辞典仕様 v0.3 の「**マネピによる声・表情・仕草の再現**」と「**顔付き音声カード**」に合わせる。
- **【基本方針】** 魚種の日本語仮名は開発時の整理用。ゲーム中の呼称や住民の発言は、星のワールドシードで決まる宇宙語と整合させる。

## 14. 本案の結論

- **釣り魚：50種類（一般20・個性派15・希少10・伝説5）**を設計案として整理した。
- **宇宙生物50種類とは別枠**であり、合わせて100種類の未知生物を発見・収集する構想につながる。見た目と見え方のルールで、竿と網のどちらを使うかを迷わせない。
- 魚ごとに**シルエット・サイズ・生態・行動タイプ・生息条件**を割り当て、全水域に一般魚を置き、宇宙固有現象とも結びつけた。
- ロケット修理の素材は装置ごとに複数の候補魚を持たせ、どのシードでも修理が止まらないようにする。
- **魚種の正式採用、実装の難度・数値・出現率・モデル形状は未決定**。本書はこれらを詳細化するための第二稿である。
