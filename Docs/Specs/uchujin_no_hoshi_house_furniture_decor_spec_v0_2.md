## 0. 仕様の確度と本作の前提

| 表記 | 意味 |

### 本作の基本コンセプト【決定／既存方針】

主人公は別宇宙から見知らぬ星へ不時着する。かわいい宇宙人たちと暮らしながら、釣り、鉱山、農業、生き物取り、商店、クエストなどを楽しみ、未知の宇宙語を自分で解読する。大きな目標は、お金を稼ぎ、修理部品を買ってロケットを直し、故郷へ帰ること。

- **宇宙語の単語・文法は星のシードで変化する。**
- **プレイヤーはタブレットの宇宙語辞書・住民辞典へ自由に記録する。** ゲームが正しい意味や住民の本心を勝手に開示・訂正しない。
- **住民は自分の生活を送り、引っ越しもする。** 主人公のいない間にも生活が進む。
- **宇宙生物は約50種類を構想。** 農業のお手伝いをする10種類を含む。
- **商店は商品を並べておけば住民が自分で買っていく方式。** レジ・店番を強制しない。
- **商店の「宇宙語を書いた紙の付箋」は廃止する方向。** 伝言生物マネピによる声・仕草の再現と、タブレットの音声カードへ置き換える。
- **四季は設けない方針。** 昼夜、天候、星特有の自然現象を活用する。
- **マップもシードによって変える方針。** 主人公の家・農場の周辺環境も星ごとに違い得る。

### 家・家具・装飾が目指す体験【採用方向】

**「理想の家を作ると、そこに宇宙人や宇宙生物が集まり、新しい生活・会話・思い出が生まれる」。**

家は単なるセーブ地点や家具の展示画面ではない。プレイヤーが作った空間を住民・生物が実際に使い、家づくりが生活ゲームのほかのコンテンツに結びつくことを目指す。

## 1. 家づくりの4つの柱【採用方向】

1. **家の増築**：部屋や階数・屋外空間を広げ、好きな間取りにする。
2. **家具・装飾の自由配置**：普通のかわいい家具も、不思議な宇宙家具も好きなように組み合わせる。
3. **住民・宇宙生物との生活**：家の設備を使う、遊びに来る、食事する、眠る、演奏するなどの行動が発生する。
4. **思い出が残る家**：もらった家具、住民との出来事、写真や音声が時間とともに蓄積する。

家づくり自体をロケット修理の必須条件にはしない。帰還資金を優先するプレイヤーも、何年も家づくりを楽しむプレイヤーも成立する構成とする。

## 2. 自宅の導入・初期状態【提案】

### 2.1 住居を得る導入

不時着して宇宙船が使えない主人公に、村の宇宙人が小さな空き家を貸してくれる案。最初から最小限の生活はでき、少しずつ家具や部屋を増やしていける。

- 初期：小さな家、寝具、最低限の収納など。
- 自宅は村と農場へ往来しやすい位置にある。
- 家の外観・敷地形状・周辺景色は生成された星の地形に沿って決まる可能性がある。
- 「空き家を借りる」というストーリー設定自体は**未確定**。

### 2.2 自宅の基本機能

| もの | 基本的な用途 |
|---|---|
| ベッド | 睡眠、休息、時間送りとの連携 |
| 収納 | アイテム、家具、素材などの保管 |
| 家具配置モード | 室内の模様替え |
| 展示空間 | 釣果、宝石、化石、生物関連品の展示 |
| タブレット | 辞書・住民辞典・図鑑・依頼帳・写真などの整理 |
| 住民の訪問 | 親しい住民と家で過ごす |

睡眠の必要性、時間停止、料理設備などの正確なルールは、それぞれ時間・天候仕様や料理仕様に準拠する。

## 3. 増築・間取り変更【採用推奨／提案】

前回の「小さな家→大きな家」という単線的な段階拡張から発展させ、**部屋をどのように使うかをプレイヤーが決められる**方式を推す。

| 増築項目 | できること | 状態 |
|---|---|---|
| 部屋追加 | 横方向へ部屋を増やす | 【提案】 |
| 部屋拡張 | 既存の部屋を広くする | 【提案】 |
| 間取り変更 | 間仕切りや扉の位置を変更 | 【提案】 |
| 2階・ロフト | 上の階に部屋を作る | 【提案】 |
| 地下室 | 倉庫、趣味室、展示室などに使う | 【提案】 |
| 屋上・テラス | 屋外家具や植物を配置 | 【提案】 |
| ガラス張りの部屋 | 景色や植物を眺める空間 | 【提案】 |
| 水辺の部屋 | 水槽や水辺の宇宙生物の空間 | 【提案】 |
| 外観改装 | 壁、屋根、窓、ドアなどの見た目を変える | 【提案】 |
| 庭・敷地拡張 | 装飾、農場、飼育スペースなどを増やす | 【提案】 |

### 3.1 部屋の用途は家具によって決まる

- 部屋用途を「寝室」「リビング」などの固定ラベルで制限しない。
- 大きな水槽ばかりの部屋、結晶の展示室、生物の遊び部屋、家具コレクションの部屋などを自由に作る。
- ソファとテーブルを置けば団らんの場になり、水槽や展示棚を並べれば観賞の場になる。
- 住民や生物が何をできるかは、置かれた家具と空間によって変化する。

### 3.2 増築を頼む住民【提案】

- 村の建築家や家具職人にお金・必要素材を渡し、家を増築・改装してもらう。
- 増築前に完成予定の外観・間取りをプレビューする。
- 一度完成した家も、後から配置や装飾を変更できる。
- 建築家も仕事・趣味・友好関係・個別ストーリーを持つ、村の一人の住民として扱う。
- 増築費、工事期間、キャンセル、階数・部屋数の上限は**未決定**。

## 5. 家具配置・模様替え【採用推奨】

### 5.1 基本操作

- 家具を置く、移動する、回転する、片付ける。
- 床、壁、天井、テーブルの上、棚の中、庭、水辺など、家具に適した場所へ設置できる。
- グリッド吸着と細かな位置調整の両立を検討する。
- 卓上小物の複数配置や、展示品の並べ替えを可能にする。
- 壁紙・床材・家具カラー・屋根や外壁の変更を検討する。
- 配置操作の取り消し、配置の保存・呼び出しなども候補とする。
- 家具を移動しても、その家具の中身や保存された思い出が消えないようにする。

### 5.2 自由配置と使用の両立

見た目だけでなく住民・宇宙生物が利用するので、**「家具が置かれている場所」と「どう使うか」**の両方を扱う。

- 住民が座れる位置、テーブルに近づく位置、ベッドで眠る位置などを家具ごとに持たせる案。
- 家具の向きや周囲の空間によって、使用可能な行動が変わる。
- 配置できるものを制作都合で不必要に減らすのではなく、プレイヤーが使い方を理解できる操作性を重視する。
- 具体的な当たり判定、家具の重ね合わせ制限、通路の扱いは実装詳細として**未決定**。

| ソファ・椅子 | 座る・くつろぐ | 座って会話・昼寝 |
| テーブル | 食べ物・小物を置く | 一緒に食事する |
| キッチン | 料理する | 訪問した住民と料理する |
| 本棚 | 書物を閲覧する | 読書好きが手に取る |
| 楽器 | 演奏する | 音楽好きが演奏する |
| 水槽 | 釣った魚を飼育・展示 | 魚好きが眺める |
| 展示棚 | 鉱石・化石などを飾る | 収集家が観察する |
| ランプ | 点灯・消灯 | 光を好む生物が集まる |
| ベンチ | 庭で休む | 散歩中の住民が座る |
| 生物用おもちゃ | 生物と遊ぶ | 生物が自分で遊ぶ |

### 6.1 家具を増やすことで行動が増える

- 椅子1脚しかない部屋にソファとテーブルを追加すると、複数の住民が一緒にくつろげる。
- 楽器がある部屋では音楽好きの住民が演奏することがある。
- 大型水槽があると釣り好き・生物研究家などが観察する機会が生まれる。
- 庭にベンチと花壇を作れば、花好きの住民が座って過ごす可能性がある。

### 6.2 家具の価値は一律の数値だけで決めない

高級ソファを置けば全住民の友好度が上がる、といった一律の加点方式は中心にしない。住民の好みや状況によって、実際に利用するか、どんな感想を持つかが変わる方式を推奨する。

## 8. かわいい宇宙人10デザイン系統と家具【提案】

宇宙人の見た目は多様だが、家具の用途を厳密な種族専用に固定しすぎない。

| 体型・特徴の例 | 家具の使用演出 |
|---|---|
| まんまる型 | クッションに沈み、ころんと転がる |
| 浮遊型 | 椅子の上で浮いてくつろぐ。天井の装飾にも反応 |
| 多腕型 | 複数の手で楽器や小物を扱う |
| 四足・動物寄り型 | 低いクッションで丸くなって眠る |
| もちもち・軟体型 | 柔らかい家具と一緒に伸び縮みする |
| その他の個性的な外見 | 表情・動き・家具の使い方に個性を出す |

- 「10系統」は住民デザインの幅を指す。すべてを単純な別種族として固定した決定事項ではない。
- 特定体型しか家具を使えない制限より、**同じ家具を違う使い方で楽しめる**ことを重視する。
- 同じ体型でも好きな家具・趣味・性格は住民ごとに異なる。

## 9. 宇宙生物50種類と家の連携【既存方向性＋提案】

捕まえた宇宙生物は、農場だけでなく家の中や庭でも飼育・観賞できる方向を検討する。

### 9.1 生物と家具の対応例

| 生物 | 家具・設備 | かわいい行動の例 |
|---|---|---|
| ハコネ | 空き箱 | 箱に入って隠れる |
| ネムリコ | ベッド | 勝手に眠る |
| カラポン | 色付き家具 | 体色が周囲と似た色になる |
| ツミツミ | 石の置物 | 周囲に小石を積む |
| ランプル | ランプ | 明かりの周囲を飛ぶ |
| ミズプク | 小さな池 | 水浴びをする |
| マネピ | 楽器・止まり木 | 音を真似する、伝言を再現 |
| モフピ | クッション | 体をすり寄せて眠る |
| ハナピカ | 花瓶の花 | 花の周りを飛ぶ |
| ヒカリムシ | 夜の植物 | 植物の近くで発光する |

### 9.2 複数の生物が一緒にいる場合

- ランプルとヒカリムシが夜の照明の周囲で光を点滅させる。
- ネムリコとモフピが同じ寝床で丸くなる。
- ハコネが箱に入るのを、ほかの生物が観察する。
- 生物の性格・相性・置いてある家具によって、特別な行動が発生する場合がある。

### 9.3 住み場所とお世話

- 寝床、池、巣箱、止まり木などを自由に設置する。
- 生物が好む環境を用意することで、居場所や行動が変わる。
- 生物の成長、個体差、繁殖は既存の生物・農業案と連携する。
- 「毎日全生物に餌やり・掃除をしないと働かない」という義務的な管理は中心にしない方向。
- 家の中に何匹まで放せるか、どの生物を室内で飼えるかなどは**未決定**。

## 10. 庭・屋外装飾・生き物の誘致【採用方向＋提案】

農場と自宅の庭は、単に畑を作るための空間ではない。景観づくり、住民の交流、生物の生息環境づくりを自由に組み合わせられる場所とする。

| 設置物 | 景観・遊び | 訪れる・反応する生物や住民の例 |
|---|---|---|
| 花畑 | 色とりどりの庭 | ハナピカ、花好き住民 |
| 池・小さな水場 | 水辺の庭 | ミズプク、水辺生物 |
| 大きな木 | 木陰・止まり木 | タネパタ、森の生物 |
| 空き箱 | 小物のある庭 | ハコネ |
| ランプ・街灯 | 夜の景観 | ランプル、発光生物 |
| 石の山・石飾り | 岩場の景観 | ツミツミ、岩場の生物 |
| ベンチ | 休憩・会話 | 散歩中の住民 |
| 楽器や音の出る装飾 | 音楽のある庭 | 音楽好きの住民・生物 |
| 道・柵 | 景観・動線 | 移動しやすさ、区画の区別 |

### 10.1 配置で起きる生活の変化

例：池＋花畑＋ベンチを置いた庭では、ミズプクとハナピカが訪れ、花好きの住民がベンチで生物を眺めることがある。

- 家具・植物・生物の組み合わせによって、訪れる生物や住民の傾向が変わる。
- 主人公が作った庭が村の自然とつながる。
- 天候・時間帯・星のシードによっても見られる行動は変化する。

## 11. 住民の自宅訪問と招待【採用推奨／提案】

住民との親交によって、自宅へ遊びに来てもらえる仕組みを提案する。

### 11.1 訪問の種類

| 種類 | 主な出来事 |
|---|---|
| 普通の訪問 | 家具を見たり、ソファでくつろいだりする |
| 一緒に食事 | 食卓で料理を楽しむ |
| 趣味の交流 | 水槽、釣果、宝石、楽器などを見せる |
| 生物との交流 | 飼っている宇宙生物と遊ぶ |
| 特別なイベント | お祝い・誕生日など |
| 複数人の集まり | 住民同士で会話し、家具を使う |
| プレゼント・お願い | 家具・小物を届ける、手伝いを頼む |

### 11.2 訪問者の反応

- 釣り好きは水槽や釣果に興味を持つ。
- 鉱石好きは結晶や展示棚を眺める。
- 生物好きはペットと遊びたがる。
- 音楽好きは楽器を弾くことがある。
- 料理好きはキッチンや食卓に興味を示す。
- 同じ家具でも、住民ごとの好み・知識・気分により会話内容が異なる。

### 11.3 同時に複数人を招く【提案】

- 大きな食卓、複数の椅子やソファがあれば、みんなで食事や会話ができる。
- 楽器があれば演奏会のような出来事が生まれる。
- 釣りのライバル二人が魚の展示を見て張り合うことがある。
- 仲の良い住民同士が一緒にくつろぎ、住民関係にも変化が生まれる。
- 招待方法、最大人数、訪問時間、住民の自由な訪問頻度は**未決定**。

## 12. 家具と宇宙語の解読【既存方針と連携】

家具を使用している住民の行動は、未知の宇宙語を理解するための手掛かりになる。

| 実際の場面 | 推測できる語彙の例 |
|---|---|
| 柔らかいソファに座る | 柔らかい、気持ちいい |
| 高額な家具を見る | 高い、珍しい |
| 大きなテーブルを見る | 大きい、広い |
| 星結晶ランプを見る | 光る、きれい |
| 水槽の魚を眺める | 魚、泳ぐ |
| 重い家具を運ぶ | 重い、運ぶ |
| 窮屈な椅子を使う | 小さい、狭い |
| 生物がベッドで眠る | 眠る、かわいい |

- 発言内容はその住民の性格・知識・実際の状況に応じて決まり、家具ごとに固定の単語を必ず言わせるわけではない。
- 会話は星の宇宙語で行われ、単語・文法はワールドシードに従う。
- 音声、仕草、実際の行動を手掛かりに推測する。
- 気になる言葉をタブレットに保存して、宇宙語辞書・住民辞典へ関連付けられる。
- **タブレットは正しい翻訳を自動生成しない。**

## 13. マネピによる自宅の留守番伝言【提案】

文字付箋ではなく、**住民の声・仕草を正確に覚えて再現する宇宙生物「マネピ」**を使う方向と整合させる。

### 13.1 家庭用マネピ

- 玄関や部屋にマネピの止まり木を設置できる案。
- 留守中に訪ねてきた住民が、マネピへ伝言を預けられる。
- 主人公の帰宅後、マネピが声・仕草を再現する。
- 必要に応じてタブレットに**音声カード**として保存する。
- 声を受け取った住民の人物情報は、住民辞典と対応付けられる。

### 13.2 伝言の用途

| 伝言 | 内容の例 |
|---|---|
| 留守中の訪問 | 来たことを知らせる |
| 遊びの誘い | 家へ遊びに来たい |
| プレゼント | 品物を届けたことを伝える |
| 頼み事 | 生活の中で手伝ってほしいことを伝える |
| 近況報告 | 仲良しの住民、引っ越した住民からの声 |

- マネピが勝手に住民の会話を常時録音する方式ではない。
- 住民が伝言として預けた内容を再現する。
- 文字の付箋・手紙の自動翻訳へ戻さない。

## 14. 家具に「思い出」を持たせる【重要提案】

家具の中には、単なる同種アイテムとしての種類・価格だけでなく、**個別の来歴や思い出を持つもの**があると面白い。

### 14.1 記録できる情報の例

| 情報 | 例 |
|---|---|
| 入手元 | 家具職人から購入、住民からプレゼント |
| 入手日 | 12日目 |
| 贈り主 | 住民 No.012 |
| 置いた場所 | リビングの窓辺 |
| 特別な出来事 | 釣り名人が座って話した |
| 写真 | 家具を使っている住民と撮影 |
| 自由メモ | プレイヤーが自分で書いた感想 |

### 14.2 具体例：もらった椅子

1. 12日目、ある住民から木製の椅子をもらう。
2. 主人公がリビングに椅子を置く。
3. 18日目、釣り名人が訪問してその椅子に座る。
4. 31日目、数人の住民と集まったときに使う。
5. 椅子を贈った住民が引っ越しても、椅子とその記録は残る。
6. 以前保存した宇宙語の音声を聞き返し、当時の発言を後から理解できることがある。

### 14.3 記録の考え方

- 全家具についてあらゆる使用履歴を無制限に書き込むことを確定したわけではない。
- 入手履歴・特別な出来事・プレイヤーが選んだ思い出などを記録対象にする案。
- 記録の表示はタブレットの住民辞典・写真・資料ボックスと連携する。
- 「大切な思い出かどうか」はゲームが勝手に判断しない。本人が保存・整理できる。
- 家具を別の場所へ移動しても、個別の来歴は保たれる。

## 15. 住民が自分の家で家具を使う【住民生活仕様と連携】

主人公だけでなく、**住民も商店で家具を買い、自分の家へ持ち帰り、実際に使用する**仕組みを目指す。

### 15.1 購入後の行動

| 住民が買ったもの | 起きることの例 |
|---|---|
| ソファ | 自宅に置き、そこで昼寝や休憩をする |
| テーブル | 友達を招いて食事する機会が生まれる |
| 楽器 | 自宅で練習や演奏をする |
| 水槽 | 魚を飼ったり、飾ったりする |
| 生物用寝床 | ペットがそこで眠る |
| 花瓶・飾り | 室内の見た目が変わる |

### 15.2 住民の引っ越しとの連携

- 引っ越し準備で、住民が家具を荷造りする。
- 気に入った家具を新しい住居へ持っていく可能性がある。
- 新しい住民が入居すれば、家具や内装が変わっていく。
- 住民から主人公へ家具が贈られた場合、主人公の家に飾ったものを贈り主が見て反応することもある。

これにより、商店で売った家具が「売上だけ」で終わらず、村の暮らしの変化として目に見える。

## 22. 具体的なプレイ体験例【説明用】

### 22.1 最初の椅子が思い出になる

1. 村の住民から木製の椅子をプレゼントされる。

5. 家を増築し、ソファやテーブルを増やす。
6. 住民たちを招き、食事や音楽を楽しむ。

1. 庭に池、花畑、ベンチを設置する。
2. 水辺の生物と花好きの生物が遊びに来る。

1. 主人公の商店で楽器を販売する。
2. ある住民が楽器を購入する。
3. その住民の家に楽器が増え、演奏する時間が生まれる。

5. 二人が親しくなり、新たな交流が発生する。

いずれも**システムが成立した場合のシナリオ例**であり、固定イベントとしての採用を意味しない。

## 25. 今後の検討事項

以下は**まだ数値や仕様を固定しない**。

1. **家の初期設定**：空き家を借りるのか、別の形で住居を得るのか。
2. **増築の仕組み**：間取りの自由度、階数、建築依頼、工事、改装の費用。
3. **家具の編集操作**：移動・回転・色変更・卓上配置・複数配置・屋外配置のUI。
4. **家具の規模**：全家具数、シリーズ数、色違い、個別の動作数。
5. **家具と住民AI**：同じ家具を使う住民の振る舞い、複数住民の集まり、会話の発生。
6. **生物の住環境**：室内飼育対象、最大飼育数、住み場所・成長との連携。
7. **庭づくり**：農場との境界、水場・植物・家具・生物誘致のルール。
8. **住民の訪問**：訪問時間・招待人数・親交条件・約束・留守中の対応。
9. **家具に残る記録**：何を自動記録し、何をプレイヤーが選んで残すか。
10. **家具の販売・制作**：店の品揃え、素材、制作方法、住民の職業との連携。
11. **星のシードの差**：家具の流通・好み・住宅の初期内装をどこまで変えるか。
12. **マルチの権限**：家への立ち入り・家具編集・受け渡し・写真・生物の扱い。
13. **クリア後**：帰還時や再訪時の家、家具、思い出の保存方法。

## 26. 実装・遊びの検証観点（提案）

技術を先に固定するためではなく、**面白さを成立させるために確認したい内容**を挙げる。

### 家具と家

- 家を増築・改装し、好きな用途の部屋を作れる。
- ソファ、ベッド、テーブル、水槽、展示棚などが実際に使われる。
- 卓上小物や展示品を配置・変更でき、配置変更でも中身や思い出が保たれる。
- 普通の家具と宇宙家具を自由に混ぜられる。

### 住民・生物

- 住民が家を訪問し、本人の性格に合った家具を利用する。
- 複数の住民が家具を使って会話・食事・趣味を楽しめる。
- 異なる体型の住民が、同じ家具をその体型らしい方法で利用できる。
- 生物が寝床・池・箱・照明などに反応し、見て楽しい仕草を見せる。
- 住民が購入した家具が家の内装に反映される。

### 宇宙語・記録

- 家具を使った住民の発言が、その星の宇宙語に従って生成される。
- 住民の仕草や家具の使用が、言葉を推理するための手掛かりになる。
- マネピの伝言は本人の音声・仕草を再現し、文字付箋に戻らない。
- 写真や音声記録、家具の来歴をタブレットで関連付けられる。
- タブレットは宇宙語の正解や住民の本心を勝手に教えない。

### ワールド・マルチ

- 星ごとの地形に合わせて家・農場・庭を楽しめる。
- 家を訪問したゲストが、所有者の許可なく家具や生物を持ち去ったり配置を変更したりできない。
- ホスト星の家・家具・住民の状態が訪問中も一貫して見える。

## 27. 企画の核・引き継ぎ用まとめ

本作の家・家具・装飾は、**単に高価な家具を買い揃えるゲームではない。**

1. 好きなように家・間取り・家具・庭を作る。
2. 家具を住民・宇宙生物が実際に利用する。
3. その結果、会話・訪問・生物の行動・住民同士の交流が生まれる。
4. 生活の中で聞いた未知の宇宙語を、主人公が自分で調べる。
5. 住民からもらった家具や一緒に過ごした出来事が、思い出として残る。
6. 引っ越しや帰還を迎えたときにも、家とタブレットの記録が物語の一部になる。

**「自分が作った家が、かわいい宇宙人や宇宙生物との思い出で満たされていく」**ことを中心に、今後の詳細仕様を検討する。

> **補足**：この文書の【提案】は未承認のため、今後の設計では優先度や内容を変更できる。制作を楽にするためという理由だけで、ユーザーの望む面白さや自由度を勝手に削減しない。
