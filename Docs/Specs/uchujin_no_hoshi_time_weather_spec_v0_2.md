## 0. 状態区分と設計思想

- **【決定】**：ユーザーが明確に採用・修正・否定した内容。
- **【方向性】**：ユーザーの意向が示されている、または他の仕様から自然につながる基本方針。詳細は調整可能。
- **【提案】**：今回までの会話で出た案。採用は未確定。
- **【未決定】**：今後の議論で定める内容。

### 本作における時間・天候の役割

『宇宙人の星』は、言葉の通じない星に不時着した主人公が、かわいい宇宙人たちと生活しながら宇宙語を解読し、お金を稼いでロケットを修理し、故郷への帰還を目指す生活シミュレーションである。

時間と天候は、単なる画面の色替えではなく、**住民の日常、釣り、農業、宇宙生物の活動、商店での購買、出来事、宇宙語の学習機会を生み出す仕組み**として扱う。ただし、難しい気象管理ゲームを作ることは目的ではない。

**異星を地球の常識に無理に合わせない。** 鉱石が目の前で消滅・出現することも、この星での日常的な現象として扱う。

## 1. 全体方針・必ず守ること

1. **【方向性】四季は設けない予定。** 春・夏・秋・冬による季節サイクルを前提としない。
2. **【方向性】昼夜と日付の経過は存在する。** 時間帯によって風景、住民、生物の行動が変わる。
3. **【提案】天候は一日の途中でも変化する。** 晴れから曇り、雨、雨上がりへ移る日もある。
4. **【提案】天候・気候はワールドシードと関連させる。** 星によって晴れや雨、風、特殊現象の頻度が異なる。
5. **【決定】鉱山の鉱石は日付切替時に再配置する。鉱山内にプレイヤーがいても延期しない。** 目の前で鉱石が消えたり出現したりしてよい。
6. **【決定】鉱石は毎日ランダムな種類・数量・場所へ再出現し、長期的に採掘資源が尽きない。** 日ごとの必要鉱石の最低出現数保証は設けない方針。
7. **【方向性】宇宙語の解読を時間・天候に結びつける。** 住民の発言と実際の出来事を照合できるようにする。
8. **【方向性】四季がなくても、時間帯・天気・生息環境で生物や魚の出会い方に変化を付ける。**
9. **【方向性】マルチプレイでは同じ星の時間・天候・日付を共有する。**

## 2. ゲーム内時間の基本設計

### 2.1 一日の長さ

**【提案】現実時間で約30分／ゲーム内の1日**を、初期の比較基準とする。

| 現実時間での1日 | 遊びの特徴 | 扱い |
|---|---|---|
| 約20分 | 日を進めやすく、農業・採掘の反復テンポが速い | 比較候補 |
| 約30分 | 生活・住民交流・探索のバランスを狙う | 推奨初期案 |
| 約40分 | 会話の観察や宇宙語の研究をゆっくり行える | 比較候補 |

**【提案】時間速度を設定で変更できる**方式も候補。実際の1日の長さ、変更幅、途中で変更できるかどうかは未決定。

### 2.2 時刻表示

- **【提案】** タブレットに現地時刻を表示する。
- **【提案】** UI上では24時間制を使用する。異星の自転周期がどうなっていても、端末が現地の1日を24時間表記する設定にできる。
- **【未決定】** 時計を常時画面上に出すか、タブレットで確認するか。

### 2.3 時間帯（仮の区分）

| 時間帯 | 仮の時間 | 主な活動・景色 |
|---|---|---|
| 早朝 | 5:00〜8:00 | 早起きの住民、朝に活動する魚・生物、起床 |
| 午前 | 8:00〜12:00 | 店の営業、農作業、仕事 |
| 午後 | 12:00〜17:00 | 買い物、仕事、釣り、住民同士の交流 |
| 夕方 | 17:00〜20:00 | 仕事帰り、散歩、商店への立ち寄り |
| 夜 | 20:00〜24:00 | 夜釣り、夜行性生物、夜型住民、光る植物 |
| 深夜 | 0:00〜5:00 | 夜型住民、深夜の探索、日付更新後の鉱山 |

上記の境界時刻は**すべて【提案】**。住民全員が同じ時刻に起きたり寝たりするわけではない。

## 3. 睡眠・休息・時間の進行

### 3.1 睡眠

**【提案】** 主人公はベッドで好きな時間に眠り、翌朝まで時間を進められる。

- 睡眠するとHP・スタミナなどが回復する。
- 夜釣り、夜の生き物取り、深夜の採掘などを続けられる。
- 原則として、一定時刻で強制気絶・強制帰宅させない方向。
- **睡眠は日付が進むための必須条件にはしない**方向。眠らずに朝を迎えても、星の時間と日付は進む。

**【未決定】** スタミナの具体的な回復、連続徹夜の扱い、ベッド以外の休息、睡眠によるスキップ先時刻。

### 3.2 タブレット・会話中の時間停止

**【提案】** シングルプレイでは、タブレットで辞書・住民辞典・音声記録・文法比較などを整理している間、時間を停止できるようにする。

- 宇宙語の解読に時間制限をかけないための案。
- 会話を読んでいる間の一時停止も候補。
- 時間停止の有無・設定方式は未決定。
- マルチプレイ中は、一人のタブレット操作では全員の時間を止めない方向。

## 4. 日付切替と日次更新

### 4.1 日付切替時刻

**【提案】0:00**をゲーム内日付の切替時刻とする。何時に切り替えるかは最終決定ではない。

### 4.2 更新する仕組み

| システム | 日次更新の内容・候補 | 状態 |
|---|---|---|
| 鉱山 | 鉱石を即時再配置。位置・種類・数量が変化 | **再配置・延期なしは決定** |
| 農業 | 作物の成長、栽培状態の更新 | 提案 |
| 釣り | 魚の出現傾向を更新。時刻・天候による変動も併用 | 提案 |
| 宇宙生物 | 野生生物の出現傾向などを更新 | 提案 |
| 住民 | 仕事、約束、趣味、予定などを翌日へ反映 | 提案 |
| 商店 | 売上の締めと日別集計。棚・在庫・営業は各仕様と整合 | 提案 |
| クエスト | 日替わり依頼、期限、イベント条件などを更新 | 提案 |
| 天候 | 当日・翌日の天候推移を生成・更新 | 提案 |

日付更新は「すべてをプレイヤーの目の届かない場所でこっそり処理する」ための仕組みではない。**鉱石の即時変化を異星らしい現象として見せて構わない。**

### 4.3 鉱山の再配置（重要な修正事項）

**【決定】**

- 日付が変われば、プレイヤーの位置や探索状況に関係なく鉱石を更新する。
- 目の前の鉱石が突然消滅してもよい。
- 目の前に別の鉱石が突然出現してもよい。
- プレイヤーが鉱山内にいることを理由に、日付変更や鉱石再生成を延期しない。
- 日付ごとの出現数の最低保証を勝手に追加しない。出現確率・分布を適切に設計する。
- 長期的には何度でも採掘できる。

**【未決定】** 再配置エフェクト、採掘操作と再配置が同時に起きた場合の入力処理、岩との衝突処理などの実装詳細。ただし、技術的都合を理由に上記の基本ルールを変更しない。

## 5. 天候は複数要素の組み合わせで扱う

**【提案】** 晴れ・雨・強風などを互いに排他的な固定状態にせず、組み合わせられる項目として扱う。

| 軸 | 状態の候補 |
|---|---|
| 空模様 | 快晴、晴れ、曇り、厚い雲 |
| 降水 | なし、小雨、雨、大雨 |
| 風 | 無風、微風、強風 |
| 視界 | 通常、薄い霧、濃霧 |
| 宇宙固有現象 | 光雨、星風、逆雨、星の光帯など |

例えば、晴れ＋強風、曇り＋小雨、夜＋霧＋光の帯、といった状態があり得る。

この仕様の目的は、複雑な気象観測やプレイヤーによる気圧管理ではない。**見た目、住民の行動、農作物、魚・生物の出現に日々の違いを生むこと**を重視する。

### 一日の途中で天気が変わる

**【提案】** 例：

| ゲーム内時刻 | 天候 |
|---|---|
| 7:00 | 晴れ |
| 12:00 | 曇り |
| 16:00 | 雨 |
| 21:00 | 雨がやみ、星空 |

具体的な切替回数、持続時間、推移の確率は未決定。天候変化に応じて住民が雨宿りしたり、雨好きの生物が活動を始めたりする。

## 6. 四季を設けない世界

**【方向性】四季はなくす予定。**

- 春・夏・秋・冬の季節サイクルを前提にしない。
- 春限定・夏限定・冬限定といった地球的な作物・魚・生物の出現制限を基本にはしない。
- **【提案】** 基本作物は原則、年間を通して栽培できる。
- 魚や野生生物の出現差は、時間帯・天候・場所・生息環境・特殊現象などで表現する。
- 季節の区切りがなくても、日付・誕生日・記念日・村のイベントは存在できる。

以前の農業・釣り・生物案に含まれる「春／夏／秋／冬の出現・栽培条件」は、**この新方針に合わせて読み替え・再設計する対象**とする。

## 7. 農業と時間・天候

**【提案】**

| 条件 | 農業への影響例 |
|---|---|
| 晴れ | 基本的な成長。日光を好む特殊作物にも関係 |
| 曇り | 通常の成長 |
| 雨 | 畑に水が供給され、水やりの手間が減る |
| 大雨 | 水分供給が多く、一部の水好き作物に変化 |
| 強風 | 特定の宇宙作物の成長や実の付き方が変わる |
| 霧 | 湿度を好む特殊植物に影響 |
| 光雨など | 特殊な色・品質・収穫物などが生じる可能性 |

通常の作物は種まき・水やり・成長・収穫で育てられるようにし、天候が複雑な必須パズルにならないようにする。

### 農業用宇宙生物への影響

- **ミズプク**：雨の日には水やりを休んで水遊びをすることがある。
- **ハナピカ**：晴天時に花畑を活発に飛ぶ。
- **タネパタ**：風を利用して移動することがある。
- **ヒカリムシ**：夜に光り、一部の植物の育成を助ける。
- **ポカリス**：気温などの条件に関係した補助を行う案。

農場が賑やかに見えること自体を、天候変化の楽しさにする。

## 8. 釣りと時間・天候

**【提案】** 時間帯・天候・釣り場によって、魚の行動や出現傾向を変化させる。

| 条件 | 変化の例 |
|---|---|
| 早朝 | 朝に活発な魚が釣れやすい |
| 昼 | 日中の魚が中心になる |
| 夕方 | 夕方に活発な魚が釣れやすい |
| 夜・深夜 | 発光魚・夜行性の魚などが活発 |
| 雨・雨上がり | 水面の魚影や活動の傾向が変化 |
| 強風 | 水面や魚の動きが変化 |
| 光雨 | 特別な魚が現れやすくなる可能性 |

- すべての魚を厳しい限定条件にする必要はない。
- 同じ場所でも時間・天候を変えて再訪する価値を持たせる。
- 釣り名人自身も釣りに好む時間・天候があり、住民の行動を観察することが手掛かりになる。
- 宇宙語が理解できれば、住民から魚の活動時間や釣り場の情報を読み取れることがある。

| 宇宙生物（仮称） | 活発になる条件の例 |
|---|---|
| ミズプク | 雨、水辺 |
| ハナピカ | 晴れ、花畑 |
| ヒカリムシ | 夜 |

| ツユツユ | 早朝、雨上がり |

## 10. 住民の日常と時間・天候

**【方向性】** 住民は基本的な生活スケジュールを持ち、現在の天候、好み、仕事、約束、趣味などによって行動を変える。

| 住民の傾向 | 行動例 |
|---|---|
| 晴れ好き | 晴天時に外出しやすい |
| 雨好き | 雨の日に散歩を楽しむ |
| 夜型 | 夜の広場や海岸へ出る |
| 釣り好き | 魚が活発になる天候・時間に釣りへ行く |
| 生物研究家 | 特定の生物が出る条件で探索する |
| 料理好き | 雨の日に室内で料理を楽しむ |
| 社交的 | 晴れの日の屋外活動や会話を好むことがある |

### 天候が交流を生む

急に雨が降り、住民たちが同じ軒下へ集まる。そこで偶然会話が始まり、その後の交友につながることがある。

雨だから全員が帰宅するなどの一律処理にせず、**住民ごとの個性が行動として見えること**を重視する。

### 宇宙語とのつながり

- 雨が嫌いな住民が何を話したか、実際の雨の日の行動と見比べて推測できる。
- 昨日の天気や明日の予定を話す住民の会話から、時間表現や時制の手掛かりが得られる。
- タブレットの宇宙語辞書・住民辞典へ、聞いた発言や観察した出来事を保存できる。

## 11. 商店と天候

**【方向性】** 商店は店番不要のセルフ販売・自動売上方式のまま運用する。

天候によって客の来店や買い物の目的が変われば、売れ行きも自然に変化する。

- 雨の日に家で料理する住民が増えれば、食材が売れることがある。
- 晴れの日に釣りへ行く住民が増えれば、釣り具が売れることがある。
- 住民の予定変更や趣味によって、商品への需要が変わる。

**【提案】天気に応じて全商品へ一律の売上倍率をかけるのではなく、住民の行動変化が販売へ反映される**ようにする。

商店の感想・要望は、文字付箋ではなく**マネピの音声伝言**を通じて保存・確認するという最新方針に従う。

## 12. 宇宙固有の自然現象

これらはすべて**【追加提案】**。名前、発生頻度、各種効果は未確定。

| 現象（仮称） | 見た目・性質 | 遊びへの影響例 |
|---|---|---|
| **光雨** | 夜などに光る雨粒が降る | 畑への水分供給、発光生物・魚、特殊作物への影響 |
| **星風** | 光の粒子を含んだ風が吹く | 飛行生物の活動、種や胞子が運ばれる |
| **逆雨** | 地面の水滴が空へ昇る | 水辺の様子や特殊な生物の活動が変化する |
| **星の光帯** | 夜空に巨大な光の帯が現れる | 住民が高台へ集まる、夜の植物・生物に変化 |

- 地球では起きない現象でも「そういう星」として成立させる。
- 必ず科学的に説明する必要はない。
- 宇宙人たちはその星の自然現象として普通に受け止めている。
- 単なる見た目の演出ではなく、住民の行動や生活・発見に結びつけられる。
- 全ての現象に必ず大きな能力補正や限定アイテムを持たせる必要はない。

## 13. ワールドシードと気候生成

**【提案】** 星のワールドシードによって、地形や宇宙語に加えて気候の傾向も異なる。

| 星の例 | 気候の傾向例 | 生活への変化例 |
|---|---|---|
| 晴天が多い星 | 晴れの日が多く、星風が時折起こる | 昼間の野外活動が盛ん |
| 雨が多い星 | 雨・霧・光雨が比較的多い | 水辺の生物が活動しやすい |
| 風が強い星 | 強風の日が多い | 風に乗る生物を見かけやすい |
| 夜空が特徴的な星 | 星の光帯などの現象が比較的多い | 夜の住民イベントが特徴的になる |

固定された4種類から星のタイプを選ぶのではなく、**晴れ・降水・風・霧・特殊現象の発生傾向などを組み合わせる案**。

### 地形との関係

- 森が多い場所は朝霧が発生しやすいなど、地形と関連させる案。
- 海岸で風が強く、山で霧が出るなど、局所的な違いも候補。
- ただし複雑な気象シミュレーターを必須にはしない。

### 再現性

- **【提案】** 同じワールドシードで生成した初期気候を再現できる。
- **【提案】** 時間・天候・住民生活の進行状態をセーブデータで保持する。
- **【未決定】** 同じシードの異なるプレイで、何日後まで天候が完全一致するか。ゲーム内行動による変化を含めた具体的な乱数管理方法。

## 14. 天気予報・マネピ・宇宙語解読

**【提案】** 村に天気の予測が得意な宇宙人を登場させ、マネピに予報を預ける。

### 例

1. 住民がマネピへ、宇宙語で「明日は雨が降る」と伝える。
2. 主人公がマネピの声と仕草を再生する。
3. 宇宙語の意味は最初は分からない。
4. 翌日の実際の天気と比較し、雨や未来表現の単語を推測する。
5. タブレットに音声カードを保存し、別の日の予報と比較する。

**注意**：予報は**ゲーム内部の真実や正解を日本語で開示する機能ではない**。主人公は自分で宇宙語の意味を調べる。予報の精度（必ず当たるか、多少外れるか）は**未決定**。

### 既存の仕様との整合

- 商店の「文字の付箋」は廃止し、マネピの音声伝言へ置換する。
- 住民の話す宇宙語は、星のシードによる共通の言語ルールで生成する。
- タブレットは推理の記録・比較を助けるが、自動的に正解を翻訳しない。

## 15. 暦・誕生日・イベント

四季がなくても、暦や生活上の記念日は用意できる。

| 項目 | 扱い |
|---|---|
| 経過日数 | 1日目、2日目……という連続する日付を基本案とする |
| 四季 | **設けない方向性** |
| 年・月・週 | **未決定**。地球の12か月を使う必要はない |
| 住民の誕生日 | **提案**。住民ごとのお祝いイベント |
| 定期イベント | **提案**。一定の周期や条件で開催 |
| 記念日 | **提案**。住民との思い出や出来事を記録 |
| 引っ越し | 住民の生活・目標・日数などと関連する |

### 住民の記念日の例

- 誕生日に家へ友人が集まり、プレゼントを渡す。
- 初めて一緒に釣りをした日の出来事を、後日住民が話題にする。
- 過去の出来事が会話や関係性に残る。必ず毎年同じイベントを繰り返すという意味ではない。

**【未決定】** 星独自の1年の長さ、月の数、誕生日の割り当て、行事の開催周期。

## 16. マルチプレイ時の時間・天候

**【方向性】** 同じ星にいる全プレイヤーは、同じ時間・日付・天候・鉱山の状態を共有する。

| 項目 | 提案仕様 |
|---|---|
| 時刻と日付 | ホストの星の時刻・日付を共有 |
| 天候 | 同じ場所では共通の天候が見える |
| 時間速度 | 星の設定を適用する案 |
| 日付更新 | 全員共通 |
| 鉱石の再配置 | 誰が鉱山内にいても日付更新で即時実行 |
| 睡眠による時間送り | 全員の同意で翌朝へ進める案 |
| 個人の休息 | 他人の時間を飛ばさずに休息・回復できる案 |
| タブレット操作 | 一人が開いても星全体の時間は止まらない案 |
| セーブ | ホストの星の時刻・天候・生活状態を保持 |

### オフライン時の時間経過

**【提案】** ホストがゲームを終了している間は、基本的に星の時間を停止する。現実時間に合わせて住民の引っ越し・作物の成長・天候の変化が勝手に進む方式にはしない。

**【未決定】** ゲストの途中参加、全員の睡眠同意方法、ホストの一時停止・終了、時間速度変更権限。

## 17. プレイ体験の具体例

ある日の流れ（説明用）

1. **7:00／晴れ**：農場ではミズプクが水やり。主人公は収穫した作物を商店へ並べる。
2. **10:00／村の広場**：マネピが天気予報を伝える。主人公にはまだ単語の意味が分からない。
3. **14:00／雨が降り始める**：住民が軒下へ集まり、雨好きの住民は散歩を始める。水辺の生物も活動を変える。
4. **18:00／雨上がりの川**：普段とは違う魚が見つかり、釣り名人が何かを宇宙語で話す。
5. **22:00／鉱山**：主人公は採掘を続ける。
6. **0:00／日付更新**：プレイヤーが鉱山にいても周囲の鉱石が突然消え、新しい場所に鉱石が現れる。そのまま採掘を続けられる。
7. **翌朝／村**：商店の売上とマネピの伝言を確認し、前日聞いた宇宙語をタブレットに記録する。

同じ活動をずっと続けても、好きな活動を組み合わせてもよい。時間・天候は**新しい出来事に出会うきっかけ**になる。

## 18. 技術設計時に検証すること（提案）

### 時間・更新

- 同じ時刻がシングル／マルチで一貫して表示される。
- 眠らなくても日付が進む方式を採用した場合、昼夜・住民・農業が正しく連動する。
- 時間スキップ時も、必要な日次処理が欠落・二重実行されない。
- 鉱石の再配置は鉱山内のプレイヤーの有無に関係なく発生する。
- 再配置直前・直後でも採掘操作や保存が破綻しない。

### 天候

- 天候の見た目と、魚・生物・農場・住民の反応が一致する。
- 特殊現象の発生を、出現条件や住民会話へ反映できる。
- シードとセーブ情報から、ワールド固有の気候が一貫して扱える。

### 宇宙語

- 予報や天気の感想に、星の宇宙語を一貫して使用する。
- 会話の意味と住民の行動や天気の観測結果が矛盾しない。
- タブレットが宇宙語の正解を勝手に表示しない。
- マネピは発言の音声と仕草を正確に再現し、保存資料と対応付けられる。

### マルチプレイ

- 全プレイヤーの時刻・天候・日次更新が同期する。
- あるプレイヤーのタブレット操作で、他人の時間が意図せず止まらない。
- 日付変更時の鉱石再配置を全員が同一の状態として見る。

## 21. 他仕様書への引き継ぎ・優先事項

- **鉱山 v0.4**：鉱石の毎日再配置は、プレイヤーが鉱山にいる場合でも日付更新時に即時実行する。以前の「鉱山から退出するまで再配置を延期する」案は採用しない。最低出現数の保証も勝手に導入しない。
- **農業 v0.2**：四季による栽培制限・季節表現を前提とする箇所は更新が必要。農業用宇宙生物と天候を連動する。
- **釣り v0.2**：魚の「季節による出現条件」は時間・天候・場所などへ読み替える。
- **生き物取り v0.2**：50種類、四季なし、時間・天候・生息環境での活動変化を継続する。
- **住民生活 v0.2**：時刻・気象条件が住民の活動、会話、買い物、交流に影響する。
- **クエスト v0.2**：宇宙語の予報や時間に関する依頼は、実際の予定・天候と意味が一致するようにする。
- **タブレット v0.3**：マネピ音声カードや宇宙語辞書で時間・天気に関する発言を記録・比較する。旧「文字付箋」を前提にしない。
- **村・マップ v0.3**：気候のシード差や局所的な天候条件は、この仕様の提案段階として引き継ぐ。

### 総括

**四季を使わなくても、昼夜・天候・宇宙固有現象・住民の暮らしによって、毎日の生活は十分に変化する。**

時間と天候の役割は、釣りや農業を複雑にすることではない。住民や生物の行動が変わり、その出来事を観察することで、主人公がこの星をより深く理解できるようにすることである。
