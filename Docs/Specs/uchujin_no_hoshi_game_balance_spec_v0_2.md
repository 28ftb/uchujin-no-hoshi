## 1. ゲームバランスの目的と基本原則

### 1.1 本作の3本の進行軸

| 進行軸 | 内容 | 主要な達成感 |
|---|---|---|
| **帰還への進行** | お金と4分野由来の特殊素材・能力でロケットの装置を修理する | 壊れた宇宙船が実際に復旧する |
| **暮らしの発展** | 道具強化、農業自動化、飼育、料理・加工、商店、家・家具 | 昨日より多くのことを、より自由にできる |
| **星への理解と愛着** | 宇宙語、住民の人間関係、日常の出来事、引っ越し、思い出 | 最初は知らなかった人や場所が大切になる |

3本の進行は並行してよいが、**同じ速度で進行させる必要はない**。ロケットを優先して早く帰る人も、家づくりや交流に長期間取り組む人も成立させる。

### 1.2 絶対に損なわない体験

1. 【既存決定】主人公は別宇宙から来た訪問者。故障した宇宙船を直し、故郷に帰ることが大きな目的。
2. 【既存決定】主要な生活コンテンツは、**釣り・農業・鉱山・生き物取り・クエスト・セルフ販売商店**。料理・加工、家・家具、宇宙語、住民生活が横断する。
3. 【既存決定】ロケット修理は**お金だけ**では終わらず、釣り・農業・鉱山・生き物取りのそれぞれに修理に関わる固有素材・能力・工程がある。
4. 【既存方向】ただし、各分野の全種類収集・全技能取得・全要素コンプリートを必須にしない。素材の第三者からの譲渡・取引の扱いは未決定部分を残す。
5. 【既存決定】宇宙語の解読をロケット修理や基本的な生活行動の必須条件にはしない。意味はプレイヤーが辞書へ自由に書き、正解を自動補完しない。
6. 【既存決定】商店は**セルフ販売**。プレイヤーがレジ対応をするゲームにしない。
7. 【既存決定】四季は設けない。季節の到来を待たないと必要素材を入手できない構成にしない。
8. 【既存決定】鉱山は約10階層。深いほど高価・硬い鉱石があり、ツルハシは前段階の鉱石とお金を使って鍛冶屋で強化する。
9. 【既存決定】**鉱山の鉱石は日付更新時に即座に再配置**。中にプレイヤーがいても、目の前で消失・出現してもよい。更新を延期しない。
10. 【既存方向】宇宙生物約50種類と、農業用生物10種類の能力を、料理・加工・家具・修理へも活かす。
11. 【既存決定】シードごとに宇宙語が変わる。地形・村配置もシードによって変える方向。星ごとの暮らしの違いを魅力にする。
12. 【既存方向】ロケットが修理できた後もすぐ帰還を強制せず、出発時期はプレイヤーが決める。

### 1.3 「調整」の原則

- 一つの活動が便利になったら、即座に弱体化するのではなく、**それまでの投資・操作・需要・ほかの活動との関係**を見て判断する。
- プレイ時間を延ばしたいからといって、鉱石や魚を大量納品させるだけの作業を追加しない。
- 各活動の**現金収入を同額に揃えない**。即時性、将来の投資効果、固有素材、収集・交流の価値も見る。
- ロケット修理の順序は原則自由。個々の装置の試運転に機能上の前提があっても、素材を先取りしたり並行して進めたりできるようにする。
- 星ごとに攻略体験は違ってよいが、必要な施設・素材が存在せず帰還不能になる星は作らない。
- マルチプレイで協力して短時間で進むのは正常な楽しさ。人数分の費用倍率を自動適用しない。

## 2. 想定プレイ時間と進行のテンポ【仮数値】

### 2.1 初回帰還時間の3案

| バランス案 | 初回帰還の目安 | 特徴 |
|---|---:|---|
| 短め | 15〜25時間 | 帰還までの展開が速く、複数シードでの周回と相性がよい |
| **標準案（第一候補）** | **25〜40時間** | 日常生活と修理を並行して進める |
| 長め | 40〜60時間 | 住民との長期交流や各分野の成長に比重を置く |

- **25〜40時間は仮の検証目標**であり、プレイヤーに強制するクリア時間ではない。
- 生活や交流を深く楽しめば40〜70時間以上になることもある。
- 完成した宇宙船にいつ乗るかは本人が決めるため、帰還可能後も上限なく生活を続けられる方向。
- 帰還時間を合わせるためにロケット必要素材を大量に増やさない。
- ゲーム内経過日数と現実のプレイ時間は別指標。睡眠による時間送りやタブレット操作がある。

### 2.2 進行段階の目安

| 現実プレイ時間 | 主な体験 | ロケットの進行イメージ |
|---|---|---|
| 0〜3時間 | 村を知り、商店・釣り・農業・鉱山・生き物取りなどに触れる | 故障診断、初めての小さな修理 |

| 帰還可能後 | 家、図鑑、料理、宇宙語、住民の人生などを継続 | 自由に出発を選ぶ |

**注意**：これは一例。修理順を固定する進行表ではなく、各活動の面白さがどの時間帯に表れるかを見る資料。

## 3. コンテンツ別の成長バランス

### 3.1 成長の4段階

| 分野 | 導入 | 慣れた頃 | 発展した頃 | やり込み |
|---|---|---|---|---|
| 釣り | 普通の魚を釣る | 竿を強化、名人の技を学ぶ | 大物・特殊魚を狙う | 魚種、サイズ、希少魚などを追求 |
| 農業 | 耕す、植える、水やり、収穫 | 作物・畑を増やす | 生物による自動化、加工 | 大規模農場、特殊な栽培・組合せ |
| 鉱山 | 浅い階層で採掘 | 鍛冶屋でツルハシ強化 | 深層鉱石・高価な結晶 | 希少鉱石、採掘効率や収集 |
| 生き物取り | 身近な生物を捕獲 | 生息地・習性を調べる | 能力を多方面で活用 | 50種類の収集・飼育・観察 |
| 料理・加工 | 簡単な料理を作る | 生物を使った調理方法を発見 | 複数生物の連携・加工工房 | 料理研究、レシピ・設備の追求 |
| 商店 | 商品を並べ、値付け | 売れ行き・住民の好みを知る | 品揃え、加工品、店の発展 | 商いの工夫、星間取引など |
| 家・家具 | 初期家具の配置 | 家を増築、庭を装飾 | 生物や住民が集まる家 | 自由な間取り、コレクション |
| 住民・宇宙語 | 表情・動作から推測 | 頻出語、好み、日常を理解 | 関係性や事情を理解 | 会話、文化、思い出を深掘り |

この4段階は**自動的なレベル解放表ではない**。プレイヤーの遊びに応じた体験の違いを示す。

### 3.2 活動ごとの固有の価値

| 活動 | 即時報酬 | 長期投資・成長 | 修理への固有貢献 |
|---|---|---|---|
| **釣り** | 釣果、販売収入 | 釣り竿、釣り技術、魚の知識 | 冷却・次元観測装置に関わる特殊魚素材（仮） |
| **農業** | 収穫物、加工原料 | 農地、栽培知識、宇宙生物による自動化 | 燃料・特殊植物素材（仮） |
| **鉱山** | 鉱石、宝石、販売収入 | ツルハシ強化、深層進行 | 船体・エンジン・電源用の金属や結晶（仮） |
| **生き物取り** | 捕獲した生物、観察 | 飼育・能力・ほかの仕事への活用 | 装置の加工・調整に利用する能力（仮） |
| **クエスト** | 報酬、プレゼント | 住民関係、村への変化 | 資金・材料・修理への協力が生じうる |
| **商店** | 売上 | 商品研究、店舗設備、常連や需要の理解 | 現金化して精密部品購入・修理費へ |

料理・加工は6主要活動を**横断するシステム**。魚・作物・鉱石・生物能力を組み合わせ、料理、商品、家具素材、修理部品へ展開する。

### 3.3 収益が違ってよい理由

- 釣り・鉱山は、手動で続ければ比較的すぐ収入・素材を得られる。
- 農業は収穫まで時間がかかるが、成長すると大量生産・自動化に強い。
- 生き物取りはその場の売上だけでなく、**捕まえた一匹が将来何度も働く価値**が大きい。
- 料理・加工は新しい用途や付加価値を生むが、投入素材と時間が必要。
- クエスト・住民交流は現金だけで測らない。人や村の変化が報酬となる。
- 商店は独立した無限の現金発生装置ではなく、**商品を住民の購買行動に応じて売る場所**。

## 4. ロケット修理と生活成長のバランス

### 4.1 必要資源の5系統【既存方向】

1. 釣りで得られる特殊な魚由来の素材。
2. 農業で栽培・加工する特殊な植物由来の素材。
3. 鉱山から採掘する特殊金属・結晶。
4. 宇宙生物の能力を用いた加工・装置調整。
5. 精密部品購入・修理・加工費用としてのお金。

**料理・加工も重要**：各分野の素材をそのまま渡すだけではなく、宇宙生物と調理器具／加工設備を組み合わせ、必要な部品や燃料へ変換する工程が候補。

### 4.2 修理進行の原則

- 【既存方向】主要装置を並行して修理でき、好きな分野から素材集めを始められる。
- 【採用推奨】各分野で序盤と後半の修理目標を設け、素材を一度入手しただけで役割が終わる状態を避ける。
- 【採用推奨】装置や部品を修理すると、ロケットの船体・照明・冷却管・エンジンなどが実際に変化する。
- 【採用推奨】必要な素材が先に手に入った場合はそのまま利用できる。
- 【採用推奨】最終素材入手と資金の目途が極端に離れない。最後の長時間が単純な資金稼ぎや低確率素材待ちだけにならないよう調整する。
- 【既存方向】修理のためにすべての魚や50種類の生物をコンプリートさせない。
- 【未決定】各素材を自分で取得しなければならないか、取引・贈与で全部代替できるかの詳細。

### 4.3 仮の修理装置と現金費用【仮数値】

- この費用表は**現金のみ**。素材の数量・入手時間・加工コストを含んだ総合難度は別途算出する。

### 4.4 クリア前後の目標の扱い

- 特殊な魚や生物を見つける難しさはあってよいが、天候と行動観察、道具強化などを通じて**攻略の手掛かりが増える**設計にする。
- 修理が終わった瞬間に帰還を強制しない。
- 帰還できる状態になっても、家づくり・釣り・住民交流・辞書・図鑑を継続できる。
- 【既存方向】エンディング「最後の引っ越し」で、プレイヤーが過ごした生活や関係が別れの場面に反映される。
- 【未決定】帰還後の継続・再訪の具体的な扱い。

## 5. 経済バランスの前提

### 5.1 お金の流れを分けて考える

```text
釣り・農業・鉱山・生き物取り
        ↓ 生産・採集
      魚・作物・鉱石・生物
        ↓ 必要なら料理・加工
      商品・家具素材・加工品
        ↓ 値付け・陳列
   セルフ販売商店／住民との取引
        ↓ 実際に売れた分だけ
       売上 → 経費を控除 → 利益
        ↓
道具強化・農場・商店・家具・ロケット修理
```

**売上と利益の二重計上禁止**：釣った魚を商店で販売して1,000G受け取った場合、釣りの売上と商店売上を足して2,000Gの収入にはしない。活動別収益の分析では、採集→加工→販売をひとつの価値連鎖として追跡する。

### 5.2 評価する4つの価値

| 軸 | 具体的に見るもの |
|---|---|
| **現金収入** | 売上から種・釣り餌・仕入れ・加工費などを引いた利益 |
| **即時性** | 今すぐお金や素材を得られるか |
| **将来への投資効果** | 道具・設備・生物がその後何度も役立つか |
| **固有の成果** | 修理素材、図鑑、技術、住民との思い出など |

短時間で大金を稼げる活動があっても、それだけでその活動が最強とは判定しない。準備費用、時間、手動操作の比重、再現性を含めて比較する。

### 5.3 純収入の定義と注意

- 1日の純収入（経済検証用）＝**実現した売上・報酬 − 通常の材料費・種・餌・仕入れ・加工費等**。
- 家の購入や設備増築など、長期投資の支出は別項目として把握する。
- 農作物を収穫しただけでは現金収入としない。販売が成立した時点で計上する。
- 宇宙生物が将来働く価値を、捕まえた瞬間に現金収入へ換算しない。
- プレイヤーが何もしなくても毎日指定額が入る方式ではない。商品と需要と住民の購買力が必要。

## 6. 経済モデルの初期試算【すべて仮数値】

### 6.1 日別の純収入モデル

| ゲーム内日数 | 1日の平均純収入 | 期間中合計 |
|---|---:|---:|
| 1〜10日 | 500G | 5,000G |
| 11〜30日 | 1,400G | 28,000G |
| 31〜60日 | 2,500G | 75,000G |
| **合計** | — | **108,000G** |

元の検討では、さらに収入の幅の例として、序盤300〜700G／日、中盤1,000〜1,800G／日、後半2,000〜3,500G／日を挙げている。いずれも**実測値ではない**。

### 6.2 支出配分の試算

| 支出先 | 例 |
|---|---:|
| ロケット修理（現金費用） | 60,000G |
| 道具・農場・商店などへの投資 | 20,000G |
| 家・家具・装飾 | 15,000G |
| 手元に残るお金 | 13,000G |
| **合計** | **108,000G** |

この試算で確認したいのは、**修理だけに全財産を注がなくても、家づくりや成長へ投資できる余地があるか**という点。

### 6.3 数値の使い方と限界

- ゲーム内60日×現実30分／日＝時間を飛ばさない場合は**現実30時間相当**。ただし、睡眠・タブレットでの時間停止・各プレイヤーの行動により実プレイ時間と一致しない。
- 108,000Gの収入は、住民が購入し、商品が売れることを前提とした**検証用モデル**。全員が毎日この額を得るわけではない。
- **60,000Gという目標に合わせて、住民に不自然な無限購買をさせない**。先に経済シミュレーションで購買力を確認する。
- 20,000Gの投資でこの収益成長を実現できるかも、作物・採掘・道具・生物・加工設備の実際の仕様から検証する。
- これらの仮数値は、完成した個別システムの値が決まった後に見直す。

### 6.4 修理資金の不足／過剰の判定

| 兆候 | 問題 | 見直す対象 |
|---|---|---|
| すべての素材が揃った後、長時間お金だけを稼ぐ | 修理が単純な金策へ変わる | 装置価格、収益曲線、修理順序 |
| 農業自動化の直後に全装置を余裕で購入できる | 目標が早く消える可能性 | それまでの投資、修理素材、商品の需要、価格 |
| 生活の買い物をすると修理が全く進まない | 家づくりを事実上罰する | 修理価格、家具費、収入機会 |
| お金は十分だが一つの素材だけが長く残る | 特定活動への偏り | 必須素材の見つけ方、発見・捕獲の手触り |

問題が生じたときは**やみくもな値上げ・出現率引き下げ・収益弱体化**から始めない。

## 7. 商店とNPC経済のバランス

### 7.1 商店はセルフ販売【既存決定】

- プレイヤーは棚へ商品を並べ、価格を設定する。
- 住民は仕事・買い物・料理・交流などの生活の中で自発的に購入する。
- 購入された商品は、住民が実際に食べたり、家に置いたり、贈ったりする。
- プレイヤー不在でもホストの星のゲーム時間中に売れる。
- マネピが住民の声や仕草を再現し、プレイヤーは売上・購入事実・音声を照合できる。
- 価格を変更して言葉と購買行動を比較できる。文字の付箋で母語訳を伝える案は採用しない。

### 7.2 購買を左右する要素

| 要素 | 影響 |
|---|---|
| 住民の所持金・収入 | 購入できる商品の価格帯 |
| 住民の好み | 買いたい魚、食材、料理、家具など |
| 仕事・生活計画 | 料理を作る、釣りに行く、模様替えをするなど |
| 住民の自宅の持ち物 | 同じ家具を繰り返し買うかどうか |
| 消費と保存 | 食品などは消費、家具などは長く残る |
| 価格と品質 | 高価格や高品質をどう評価するか |
| 時間帯・天気 | 屋外活動や料理などの需要変化 |
| 店頭在庫・品揃え | 欲しいものを買えるか |

### 7.3 消耗品と耐久品を区別

- 魚・作物・料理は食べて消費されるため、同じ住民に継続需要が生まれる。
- 家具・道具は購入後も残るため、毎日同じものを買うとは限らない。
- プレゼントや引っ越し、家の模様替えで新しい家具需要が生まれる可能性はある。
- 売値の高いものが常に最も売れるわけではない。**住民にとっての必要性**を尊重する。

### 7.4 村全体の購買力の試算方法

**説明用の仮例**：住民25人が平均120G／日を買い物に使い、その60%が主人公の商店へ向かうと、

`25人 × 120G × 60% = 売上 1,800G／日`

となる。ただし、実際には住民の収入・財布・需要・取引先によって変わる。**純利益ではなく売上の試算**であり、住民25人も確定人数ではない。

### 7.5 生産量が増えたときの対応

- 農業の自動化によって大量生産できるなら、それは正当な成長の報酬として尊重する。
- 一方、同じ村の少数の住民が無限に商品を買い続ける設計にはしない。
- 新たな売り方として、料理・加工による付加価値、住民の店への納品、村の外からの客、星間取引などを検討する。**いずれも採用未確定の案**。
- 見えない販売上限で強制的に抑え込む前に、商品構成、購入頻度、住民の所得、販売先の発展を確認する。
- 家・庭・設備・家具など、発展して大金を得たプレイヤーが欲しくなる消費先も重要。

### 7.6 住民の財布と経済循環

住民は仕事をして収入を得、自分の生活のために買い物をする。お金を使った住民は買い物の頻度を変えるが、働けばまた収入を得る。恒久的に財布が空になり経済停止する問題を避けつつ、**購入が実際の生活行動に結びついていること**を維持する。

住民の仕事、収入、村内外での商取引、物価の具体数値は【未決定】。

## 8. 農業・自動化のバランス

### 8.1 成長ループ

1. 種まき・水やり・収穫を自分で覚える。
2. 農地や作物を増やす。
3. ミズプク、モギモギ、ハコバチなど農業用宇宙生物を迎える。
4. 生物同士が水やり・収穫・運搬などを分担する。
5. プレイヤーの時間が空き、より大きな農場、料理・加工、釣り、鉱山、住民交流へ広げられる。

### 8.2 自動化を不必要に弱くしない

- 【採用推奨】農業用宇宙生物を揃えた成果は、**明確な時間短縮と生産力向上**として表す。
- 無理に毎日手作業を残さない。農業を自動化したのに強制日課が減らなければ意味が薄い。
- 作物の成長時間、必要な農地、投入した資金・素材、飼育・配置の工夫まで含めて収益性を判定する。
- 農業で大金を得られるようになったプレイヤーがいても、それだけで失敗としない。
- 生物10種の具体的な作業範囲、作業効率、育成段階、維持費は【未決定】。

### 8.3 バランス検証に必要な指標

| 指標 | 意味 |
|---|---|
| 初期農場の1日あたり作業時間 | 水やりなどに何分かかるか |
| 生物1匹導入時の削減時間 | 自動化を体感できるか |
| 完全自動化に近づいた際の生産量 | 投資に見合うか |
| 加工まで含む純利益 | 収穫量がそのまま収入ではないことを反映 |
| 未販売在庫 | 商店の需要と供給が釣り合っているか |

## 9. 釣り・鉱山・生き物取りの成長調整

### 9.1 釣り

- 【既存方向】竿の強化・釣り経験・名人の技で、**以前より難しい魚が実際に釣りやすくなる**。
- 基本魚の収入と、高品質・大物・特殊魚の達成感を両立。
- 時刻・天候・魚の生態をヒントにできる。宇宙語が読めなくても観察や試行錯誤で発見できる。
- 低確率だけを頼りに修理用魚を探す設計にはしない。発見・挑戦・上達に意味を持たせる。
- 魚の種類・具体的な釣り操作・竿段階・経験値の補正は【未決定】。

### 9.2 鉱山

- 【既存決定】10階層程度の鉱山。深いほど良い鉱石、硬い鉱石がある。
- 【既存決定】ツルハシの強化には前段階の鉱石とお金を使い、鍛冶屋で行う。
- 【既存決定】日付が変われば鉱石が即座に再配置。**鉱山内のプレイヤーの目の前で出現・消失してもよい**。
- 強化したツルハシは新鉱石に対応するだけでなく、以前の岩をより楽に採掘できるようにする。
- 通常の出現確率・再配置数・採掘回数は調整するが、根拠なく日別の最低鉱石数保証、長期待ち救済、更新延期などを加えない。
- 120階建てや大規模ダンジョンなどへ勝手に拡張しない。**シンプルな採掘と強化の楽しさ**を維持する。

### 9.3 生き物取り

- 【既存方向】宇宙生物約50種類。うち農業支援生物10種を含む。
- 捕獲時の楽しさ、飼育、家具との相性、料理・加工・修理での能力を同時に評価する。
- レア度が高いほど作業能力が高い、と単純な序列にしない。
- 珍しい生物の価値は、動作・観察・生態・コレクション性だけでも成立する。
- 修理に必要な能力は既存生物の中から選ぶ方針。捕獲後も使えるようにし、修理で生物を消費しない方式を推奨。
- 50種類全部をロケット修理の条件にしない。

### 9.4 料理・加工

- 【既存方向】普通のフライパン・オーブンだけを中心にせず、**宇宙生物そのもの／生物が住む器具／複数生物の協力**を主役にする。
- 一度覚えた料理の量産は快適にし、発見・新調理法には工夫の余地を残す。
- 調理・素材加工を含む多段階の価値連鎖を評価する。
- 各生物の具体能力・料理数・調理ミニゲームの詳細は【未決定】。

## 10. ゲーム内時間・日課・スタミナ

### 10.1 1日の長さ【仮数値】

| 候補 | 特徴 |
|---|---|
| 20分／日 | テンポ重視、日付サイクルが速い |

時間速度を変更できる機能も【提案】であり未決定。

### 10.2 30分の使い方（例）

| 行動 | 現実時間の例 |
|---|---:|
| 朝の農作業 | 4分 |
| 好きな活動（例：釣り） | 14分 |
| 商店の商品補充・確認 | 4分 |
| 住民交流・宇宙語観察 | 5分 |
| 移動・その他 | 3分 |
| **合計** | **30分** |

**これは行動のノルマではない**。30分を全部採掘や釣りに使ってもよい。

### 10.3 日課が時間を奪いすぎない

- 毎日すべての畑へ水やり、全生物への餌やり、全加工機の操作、商店補充、NPCの依頼を強制する構造は避ける方向。
- 自動化や道具強化で、以前は手間だった作業を軽くする。
- タブレットを使った辞書や音声の整理が落ち着いてできる仕組みを重視。
- 【提案／未決定】シングルプレイ時のタブレットや会話中の時間停止。マルチでは全員の時間を共有。

### 10.4 睡眠・日付・スタミナ

- 【既存方向】眠らなくても時間と日付は進み、深夜の釣りや鉱山探索ができる。
- 【提案】眠れば翌朝まで時間を進める。睡眠が強制帰宅とならないようにする。
- 【提案】日付の切替時刻は0:00。厳密な時刻は未決定。
- 【未決定】スタミナの有無・上限・回復・疲労。強い制限で好きな活動を何度も中断させる設計より、料理・休息・道具強化で対応できる方式を推奨。
- 日付変更時には鉱山の鉱石を即時更新。採掘中でも例外にしない。

### 10.5 四季なし・天候の役割

- 【既存方向】季節限定の作物・魚・生物を前提としない。
- 天気・時間・場所・特殊現象によって出現や生活行動が変わる。
- シードで気候に差があっても、特定の天候待ちで長期間クリアが止まる状態は避ける。
- 宇宙らしい光雨・星風・逆雨などは【追加提案】。地球の常識を優先した不必要な制限を加えない。

## 11. 宇宙語の難易度と報酬

### 11.1 「解読しなくても遊べる／解読すると世界が分かる」

| 理解の深まり | 例 | 遊びへの効果 |
|---|---|---|
| 最初 | 身振り、行動、表情から推測 | 基本生活の開始が可能 |
| 単語の推測 | 魚、食事、買い物、天気などの頻出語 | ヒントや住民の好みを理解しやすい |
| 文法の推測 | 昨日、明日、否定、お願いなど | 住民の意図や予定が分かりやすい |
| 複雑な会話の理解 | 人間関係、悩み、別れ、故郷への思い | 住民の物語を深く理解できる |

これは**語彙の自動解放段階**ではない。星の宇宙語は初めから一貫して存在し、理解が深まるのはプレイヤー側。

### 11.2 絶対に避けること

- 宇宙語の正解を、経験値や遭遇回数で自動表示しない。
- 間違って書いた辞書の意味を自動訂正しない。
- 宇宙語の「理解率」で修理や生活施設を解放しない。
- NPCが都合よく主人公の言語を習得した設定にしない。
- 現地文字の付箋を、翻訳済みの答えとして利用しない。マネピの音声・ジェスチャーと場面の証拠を利用する。

### 11.3 バランスの取り方

- よく出る言葉が、**違う生活場面でも繰り返される機会**を作る。
- 天気予報、価格変更、食事、魚や生物の習性など、行動と会話を照合できる。
- 辞書は本人の自由入力。単語・表現・音声カード・地図・住民の記録を関連付けて比較できる方向。
- シードによる語彙・語順・文法の違いがあっても、破綻なく規則的で、観察できる証拠が生まれることを検証する。
- 解読の楽しさは**答えを教える頻度ではなく、推理に使える材料の豊かさ**で高める。

## 12. NPCの交流・引っ越し・住民生活

### 12.1 交流の報酬は友好度だけではない

| 交流 | 残る成果 |
|---|---|
| 一緒に釣る | 共通の趣味や思い出 |
| 料理を振る舞う | 食の好み、反応、関係 |
| 商店で買い物をしてもらう | 店主と常連の関係、生活に使う品物 |
| 家へ招く | 家具や宇宙生物を使った交流 |
| クエストを手伝う | 住民の暮らしや人生への影響 |
| 家具・魚などを贈る | 住民が実際に家で使ったり飾ったりする |

プレゼントを連打するだけが最適解にならないよう、**一緒に過ごした時間や出来事**も重要とする。

### 12.2 引っ越し頻度とのバランス

- 初期住民の人数は【未決定】。20〜30人同時居住、総登場100人以上は過去の検討例であって確定値ではない。
- 住民の顔を覚え、自然に何度か会う前に大量に引っ越してしまう構造は避けたい。
- 一方で、長期間住んでも顔ぶれがまったく変わらないと、引っ越しの存在感が弱くなる。
- 住民ごとの仕事、目標、人間関係に基づいて滞在・転出を決める。全住民が一定周期で交代する方式に限定しない。
- 引っ越した後も家具・伝言・タブレットの記録などに生活の痕跡を残す。
- 特定の住民が引っ越したことで鍛冶屋や修理などの必要サービスが消えて進行不能にならない設計を検討する。

### 12.3 住民の生活と経済・言葉は一体

住民が店で魚を買い、料理し、友人と食べ、感想を話す。プレイヤーは販売履歴、実際の食事、マネピの声を見比べて、住民の好みや宇宙語を推測する。**購買行動・人間関係・解読材料を別々の見せかけのシステムにしない**。

## 13. 家・家具・料理・加工の経済上の役割

### 13.1 家づくりはロケットと並行する長期目標

- 家の増築、部屋数、外観、家具、水槽、展示室、宇宙生物の住環境を充実させる。
- 家具を置くと住民や宇宙生物の行動が変化し、交流と発見につながる。
- 高額な家具や増築は**後半の重要な資金の使い道**となる。
- 家を豪華にすることを帰還の必須条件にしない。
- 帰還資金か生活への投資かはプレイヤーが選択する。

### 13.2 料理・加工で素材の価値が広がる

- 魚をそのまま売る／焼き魚・燻製魚として売るなど、複数の選択肢を作る。
- 作物からジュースやジャムを作り、さらに料理へ加工できる。
- 鉱石や植物繊維なども家具・修理部品の素材になる。
- 料理・加工は**宇宙生物の能力が中心**。既存50種の能力を複数用途に生かす。
- 加工品が必ず原料より利益率が高いとは限らない。材料、作業、設備、需要の関係を評価する。
- 一度覚えた調理を繰り返し大量生産する場合、毎回の長いミニゲームを強制しない方向。

### 13.3 価格とアイテム総数

家具・料理・加工品・道具・作物の正式な品目数と価格帯は未決定。**魅力的な量や種類を最初から理由なく縮小する前提にはしない**。内容と楽しさを固めた後に価格・収益・必要時間を設計する。

| 変動要素 | プレイ体験への影響 |
|---|---|
| 地形、川、森、海岸 | 釣り・採集・移動の体験が変わる |
| 村、施設、道路 | 日常の動線や住民との遭遇場所が変わる |
| 初期住民や関係 | 店の需要、交流相手、暮らしの出来事が変わる |
| 気候・天候の傾向 | 水やり、釣り、生物との出会いが変わる |
| 生物・魚の生息分布 | 探索のルートや発見しやすさが変わる |
| 宇宙語 | 言葉の音・語順・文法・推理過程が変わる |

### 14.2 共通して成立させるもの

- 主要な生活コンテンツにアクセスできる。
- ロケット修理に必要な部品・素材・機能を獲得する手段が存在する。
- 必須設備やサービスを利用できる。
- 採掘・釣り・農業・捕獲・商店・NPC生活が機能する。
- 現地語を十分に理解しなくても基本行動を進められる。

**同じクリア日数にする必要はない**。ただし、極端に不利な地形で日常の移動や修理が苦痛にならないかは検証する。

### 14.3 移動時間の検証

- 家〜広場〜商店〜鍛冶屋など、毎日よく行く施設の行き来が煩雑にならないか調べる。
- 遠くの森や海岸は、探検としての距離の意味を持ってよい。
- 建物・道路・橋の配置が変わっても、NPCが自然に通行・買い物・交流できる。
- 全シードで建物を同じ配置に揃え、特色を失わせるような調整はしない。

### 14.4 不必要な地球常識の制限を導入しない

- この星の鉱石が日付変更時に目の前で消えても問題ない。
- 四季がないことに合わせて、魚・作物・生物の生息／栽培を季節で縛らない。
- 光雨などの特殊現象を採用する場合は、現実の気象学で説明することをゲーム成立の条件にしない。

## 15. マルチプレイのバランス

### 15.1 協力が強いのは正常

| 協力内容 | バランス上の扱い |
|---|---|
| 釣り・農業・鉱山・生物探索の分担 | 作業効率が上がってよい |
| 修理費や素材の提供 | 一気に修理が進んでもよい |
| 他の星からの魚・生物・家具の持ち込み | 星間交流の価値として扱う |
| 宇宙生物の貸し借り・共同調理 | 生物の能力の組合せを楽しめる |
| 宇宙語辞書の共有 | **自動配布はしない**。教える／教えないを選べる |
| 住民との関係 | ゲストも個人として住民に覚えられる方向 |

- ソロを基準に活動と修理の基本バランスを作る。
- 4人で遊んだから費用4倍、といった単純な人数倍率は設けない方向。
- ゲストが大金や高性能生物を持参して帰還まで早めても問題ない。
- マルチ専用の必須素材や、ソロではできない必須調理工程を増やさない。

### 15.2 P2P・セーブ上の留意点

- 【既存方向】ホストの星が時間・住民・商店・鉱山等の状態を管理する。
- 進行度、持ち物、委託販売、住民との記憶などのデータ帰属を分ける。
- ソロとマルチで同じ星のセーブを使う方向。
- 複数人で同じ鉱石や収穫物を取っても意図しない二重入手が生じないよう、同時操作はホストが確定する。
- 【未決定】最大人数、共同生活の物語上の立場、星主不在のアクセス、共同帰還の詳細。

## 16. バランスの検証方法

### 16.1 数値だけでなく体験も評価

| 観点 | 例 |
|---|---|
| 収益 | 日別純収入、入手素材、売上・在庫、修理費の支払い |
| 成長 | 道具強化での操作負担軽減、自動化後の時間短縮 |
| 発見 | 新しい魚、生物、料理、言葉を発見する頻度 |
| 修理進行 | 装置ごとの完成時期、最後に残る工程 |
| 生活 | 住民と自然に出会えるか、変化が記憶に残るか |
| 快適さ | 移動時間、必須日課、操作の反復、加工待ち |
| シード差 | 初期配置・気候・言語の違いによる極端な偏り |
| マルチ | 協力効率、持ち物の整合性、住民の継続状態 |

### 16.2 測定する指標の例

| 指標 | 算出・観察の仕方 |
|---|---|
| 初回販売時間 | 開始から最初の商品購入成立までの時間 |
| 初回修理時間 | 開始から最初の修理部位完成までの時間 |
| 日別純収入 | 売上・報酬 − 通常経費 |
| 各活動の実労働時間 | 釣り・採掘・農業などへの直接操作時間 |
| 農業の自動化効果 | 生物導入前後の作業時間と生産量差 |
| 販売回転率 | 一定期間に売れた数量 ÷ 棚に置いた数量 |
| 修理の最後の詰まり | 最後に残った現金・素材・能力・設備と、その解消に要した時間 |
| 住民遭遇数 | 通常生活で顔を合わせたり会話を聞ける頻度 |
| 言語観察機会 | 同じ意味・形式が異なる状況で現れる回数 |
| 引っ越しまでの交流時間 | 出会いから転居までに自然に交流できた時間 |
| 施設間移動時間 | 家、商店、広場、鉱山などの実移動時間 |

これらの指標は監視・分析用であり、**プレイヤーにすべてをゲージ表示する必要はない**。

### 16.3 プレイスタイル別の検証

| プレイスタイル | 重点チェック |
|---|---|
| 釣り中心 | 技術の上達、収入、修理素材への到達 |
| 農業中心 | 自動化の達成感、投資回収、販売先 |
| 鉱山中心 | ツルハシの強化、深層への進行、採掘効率 |
| 生き物取り中心 | 捕獲の楽しさ、50種の価値、能力の応用 |
| 商店・料理中心 | 値付け・商品研究・加工による利益と住民反応 |
| 住民交流・言語中心 | 収入を追わなくても生活が面白いか |
| ロケット修理優先 | 素材待ちや金策だけの時間が長すぎないか |
| マルチプレイ | 分担、持ち込み、共同生活、P2P同期 |

### 16.4 シード別の検証

- 川・池が多い、森が多い、山が近い、施設が分散しているなど、地形の違う星。
- 晴れ・雨・霧・風の傾向が違う星。
- 初期住民・需要・会話の出現状況が異なる星。
- 語順や文法の異なる宇宙語シード。
- これらに加え、多数のランダムシードで必須要素への到達可能性を検証する。

**プレイ時間を一律化しない**。世界が成立しており、異なる攻略を楽しめるかを確認する。

### 16.5 開発中の検証順

1. 各活動の実際の入手量・所要時間・道具成長を確認。
2. 作物・魚・鉱石・生物・料理・加工の全体の価値連鎖を計測。
3. 住民の仕事・所持金・消費・商店購買をシミュレーション。
4. その結果から修理の現金費用・素材難度・設備価格を調整。
5. 日付・天候・NPC転居・宇宙語・シード差を組み込んで通し検証。
6. ソロとマルチで、収益・進行・アイテム取引の整合性を確認。
7. 数値的に成立した後も、**作業の面白さ・発見の頻度・村への愛着**を別に評価。

途中段階の数値だけを根拠に、面白い要素を一律削減しない。開発側の自動・通し検証と、完成状態での実際のプレイ体験の双方で判断する。

## 20. 最終的に目指すプレイ体験

最初は、宇宙語も分からず、道具もお金も少ない。何を売ればよいか、住民はどんな暮らしをしているかも分からない。

釣りを続けると釣りが上達し、鉱山ではツルハシの強化によって深い場所の鉱石を掘れるようになる。農場では宇宙生物たちが作業を手伝い、家では料理や加工ができるようになる。商店では住民の好みを知り、売れる商品や値段を考える楽しさが生まれる。

宇宙生物を捕まえれば、農業・料理・加工・家具・ロケット修理まで活躍の場が広がる。住民は買ったものを使い、時には引っ越し、別の住民がやって来る。マネピの声を通じて、知らなかった言葉や住民の気持ちも少しずつ分かってくる。

そして、釣り・農業・鉱山・生き物取りで得た成果と、暮らしの中で稼いだお金が、少しずつロケットを修復していく。

**ロケットが完成したとき、「ようやく作業が終わった」ではなく、「もう帰れる。でもこの星でまだ暮らしたい」と思えること。**

それを成立させるために、**個々の活動を面白く成長させ、暮らしの自由と修理の達成感を両立させる**。これを本作のゲームバランスの中心方針とする。
