## 2. モジュール別：実装済み／未実装・簡略化

### Core（統括・共通）
- 実装：Game（星の生成・ロード・ゲスト参加・セーブ・日次更新・睡眠）、TimeSystem（30分/日【仮】・速度設定・ソロのみ一時停止）、アイテム/所持品、セーブ（星／持ち物／星ごとの知識を分離）、入力（旧/新 Input System 両対応）、移動・カメラ3方式、IMGUI の UI、ホスト権威コマンド、連携契約、エディタメニュー。

### World（ワールド生成）

## 3. Unity 上で優先して確認すべきこと
1. **コンパイル**：Unity 6 で開いた時のエラー（API差、Editor フォルダのスクリプト、新 Input System 分岐）。
2. **起動**：空シーンで再生 → タイトル → キャラメイク → プロローグ → 自由行動まで。
3. **日本語表示**：IMGUI が OS フォントを動的に使う設計。文字化け・豆腐がないか（`Core/UI/UIStyles.cs`）。
4. **シェーダー**：URP/Built-in で `Shader.Find` が見つかるか（ピンク表示にならないか）。ビルド時は Always Included Shaders の設定が必要。
5. **パフォーマンス**：地形メッシュ、点光源（街灯）、住民16人の AI、生物の出現数、IMGUI の描画量。
6. **セーブ／ロード**：保存して再開した時に全システムの状態が戻るか。
7. **マルチ**：LAN UDP で同一PCの2起動テスト → EOS の設定と動作。
8. **数値バランス**：全モジュールの仮数値（1日30分、修理費合計60,000G など）。

## 4. 仕様上の未決定事項のうち、暫定で決めて実装したもの
- 1日の長さ 30分（設定で 0.5〜3 倍）、日付切替 0:00、1週間の日数は星ごとに 5〜8 日。
- 初期住民 16人、住宅区画 最大24。住民は100人のデザインから星のシードで選ぶ（同じデザインは1つの星に1人まで）。住民モデルの大きさは `ResidentModelBuilder.GameScale` = 1.5 倍（ポルン 約1.2m）。マルチ最大 4人（定数で変更可）。
- 次の星への引き継ぎ：見た目は引き継ぎ、持ち物・お金・道具は選択式。元の星のセーブは残り「続きから」で再訪可能。
- 生物の能力のうち圧搾・発酵・冷却・安定化・感知の担当種。
- 食事の用途：短時間の能力補助（提案、無効化可）。
- 鍛冶屋の鉱石買い取り（目安価格の35%、1日20個まで）。
- カメラは3方式を切替可能（斜め見下ろしが既定）。
- UI は IMGUI（プロトタイプ用）。

## 5. 統合レビューで直したもの（コードを読んでの追跡。実行確認ではない）
4系統のレビューで約50件の不具合を修正済み（詳細は git の履歴「統合レビュー」）。主なもの：
- 起動〜エンディング：読み込み失敗時の暗転、睡眠中にタイトルへ戻った時の日付更新、「次の星へ」の後に元の星を再訪すると帰還不能、エンディングで住民が歩かない（時計だけ止める仕組みを追加）、プロローグ前にロケットが見える、エリア移動時のカメラ。
- 暮らしと交流：住民が主人公の商店に予定で来ない、来店・記憶の二重処理、贈り物で品質が食い違う、依頼への身振りの二重反応、伝言広場のマネピの位置、[K]保存が会話中に使えない。
- 活動と世界：家・鉱山の中で釣りができる、住処の生物記録が残って生物が勝手に戻る、増築完成時に家の中のプレイヤーが壁に埋まる、施設前の操作物と飾りの重なり、屋内での餌の消失。
- マルチ：大きな状態の送信間引き、受領確認を保存後に返す（異常終了で品物が消えない）、再起動したゲストの再参加、読み込み中の終了で知識を空で上書き、ゲストの時刻の巻き戻しで日付更新が二重に走る、品質まで一致する取り出し（ゲストの品質詐称防止）。
