# World モジュール（ワールド生成・地形・村・地図）

`Uchujin.World.WorldSystem`（SaveKey `"world"`、DailyUpdateOrder 20）。仕様：`uchujin_no_hoshi_village_map_spec_v0_3.md`。

## ファイル
| ファイル | 内容 |
|---|---|
| `WorldSystem.cs` | システム本体（生成→表示→引っ越し反映→踏み跡・公共施設→地図→セーブ） |
| `WorldTuning.cs` | 調整用の【仮数値】すべて |
| `VillageChanges.cs` | 生活による変化（踏み跡・公共施設の整備）、寄付コマンド、整備物の外観 |
| `Generation/WorldGenerator*.cs` | 決定的なワールド生成（地形・水系・村・道路・区画・自然・釣り場・エリア・生息地点・検証） |
| `Generation/TerrainShape.cs` | 海岸・山・高台・平地のうねりの解析関数 |
| `Generation/Heightfield.cs` | 高さ・水面グリッド（HeightSampler / WaterTester の正本、橋の上は橋板の高さ） |
| `Generation/RoadPlanner.cs` | 道路の A*（勾配・水・建物を避け、既存の道を再利用） |
| `Generation/WorldPaletteFactory.cs` | 星ごとの配色 |
| `Generation/FallbackWorld.cs` | 生成がすべて例外で失敗した時だけ使う非常用ワールド |
| `Scene/TerrainBuilder.cs` | カラーマップ地形（チャンク＋MeshCollider）、外周の景色、水面・滝、外周の壁、地図テクスチャ |
| `Scene/MeshBatcher.cs` | 低ポリ形状、パレットテクスチャ、チャンク結合（自然物を軽く描く） |
| `Scene/NatureBuilder.cs` | 木・岩・花・草・キノコ・倒木・葦・貝・結晶 |
| `Scene/StructureBuilder.cs` | 施設の外観、橋、桟橋、農場の柵、看板・道標 |
| `Scene/HouseBuilder.cs` | 住民の家（区画・住民ごとに形と色が違う）／空き地 |
| `Scene/WorldBehaviours.cs` | 夜の灯り、看板、工事中の目印、ゆれる小物 |
| `Map/MapKnowledge.cs`・`Map/MapApp.cs` | 地図アプリ（AppId `"map"`）と個人の記録 |

## 生成バージョン3の試作（2026-10-17。`Docs/Design/uchujin_no_hoshi_world_map_seed_design_v0_3.md` §13.1 の1〜2）
新しい星は版3で作る（`PlanetInfo.CurrentWorldGenVersion = 3`）。**版1・版2の星はその版のまま作る**（版3の処理はすべて `if (V3)` / `version >= 3` の中）。
- **星の骨格**（`Generation/StarSkeleton.cs`、乱数キー `world.gen3.skeleton`）：5地域（r1 暮らしの谷＝村・r2 湖の森・r3 滝の山・r4 浜と岬・r5 星見の高原）と6道中（t1〜t5、t6 はシードで t6a 海風の林／t6b 崖の小道）の方角・つながり・ゲートの高さを、各マップの地形より先に決める。村の海の方角は骨格の値を使う（`TerrainShape.Create` の `seaAngle`。乱数の並びは変えない）。
- **村のゲート**（`WorldGenerator.V3.cs`）：骨格の方角に近い村の端（見えない壁の内側）に、花の野道へのゲートを置き、広場から道でつなぐ。候補は道を作る時と同じ A* で道のりを見積もり、短い所を選ぶ（広場から300m以内）。その方角の端が版2の湖・山・静かな高台でふさがっている時は、方角を100°まで、それでもだめなら全方向から選ぶ。
- **村の外のマップ**（`Generation/FieldMap.cs`・`FieldMapGenerator.cs`、乱数キー `world.gen3.map.<ID>.aN`）：村ができた後に、村のゲートの高さを骨格に入れてから作る。マップごとに検証し、通らなければそのマップだけ作り直す（最大6回）。屋外から離れた座標（`WorldTuning.FieldMapOriginBase` から 800m おき）に置き、遊べる範囲のまわりに見た目だけの縁（36m）を付ける。
  - **T1 花の野道**（240 × 120m）：**道中の型（シード）で本道の形と地形が変わる**（2026-10-17 ユーザー指示：曲がりくねりを優先、ただし全部ではない。移動は45秒まで）。型0「開けた野の一本道」（段丘の段1本・まっすぐ寄り、道のり÷直線 約1.1）／型1「丘を回り込む道」（門を結ぶ線の上に丘2〜3、約1.2）／型2「段丘を折り返して登る道」（段3本の切れ目が左右に互い違い、約1.3〜1.5）。段丘の段は高さ2〜4mの崖（飛び降りられる。切れ目はゆるい坂）。本道は坂の罰つきの A*（`FieldMapGenBase.FindPath`）で地形に沿って探し、坂8%に均す（浅瀬では小川の水面を道に合わせ、ゲートの前12mは骨格の高さに固定）。走って33〜45秒。高低差12〜26m。湖の森からの流れ出しの小川（大きく蛇行し、本道と浅瀬＝飛び石で何度か交わる）、野の池、花畑、果樹の段（果樹4〜5本）、開けた草原、東屋、丘の上の隠れた場所（本道側は崖、裏から脇道で回り込む。光る結晶）、道標（宇宙語）。寄り道ポケット5・隠れた場所1。
  - **R2 湖の森**（320 × 300m）：湖のまわりの低地 → **台地の崖**（高さ8〜20m。遠浅の側は低地が広く、急深の側は崖が岸に迫る。切れ目2か所＋流れ出しの谷はゆるい坂）→ 森の台地（36〜48m）。湖（水面24m・差し渡し90m以上・最深部9〜11.5m・遠浅・急深・泥の入り江・砂泥底の方角）、最深部へ届く岬（本道の行き先。ゲートから走って18〜24秒）、流れ出しの谷と小川（花の野道へ）、北の端からの流れ込み、湖畔の東屋と桟橋、反対側の静かな岸（本道から40m以上）、森の池2（明るい林側・湿った森側）、明るい林（果樹4以上）と湿った森（倒木5以上・キノコ・光るキノコ）。
- **見た目とゲート**（`Scene/FieldMapBuilder.cs`）：地形メッシュ（チャンクごとにコライダー）、水面、見えない壁、自然物（`NatureBuilder`）、東屋・桟橋・飛び石・道標、ゲート（木の門・灯り・布・柵）。マップはエリア `map:<ID>` として登録（`AreaIds.FieldMap`、屋外・天候あり。HUD にマップの名前）。**ゲートは歩いて入るだけで移る**（`FieldGate`：範囲の外に一度出てから入った時だけ、0.2秒の暗転のあとでとなりのマップのゲートの前へ）。
- **水深**：`WorldLayout.WaterDepthSampler` を村の外のマップにも広げ、深さ0.6mを超える水には入れない（`PlayerController.LimitWading` は村と村の外のマップで働く）。村の外のマップで奈落へ落ちたら、そのマップの入口へ戻す。
- **地形と道の作り方**（2026-10-17 ユーザー指示：平坦なマップにしない）：先に起伏のある地形（段丘・崖・丘・谷・台地・露頭）を作り、道は後から通す。経路探し（`FieldMapGenBase.FindPath`）は坂の目安を超える所も通れるが、越える高さ1mあたり約25m遠回りと同じ手間として数える（近くに自然な坂があれば回り込み、無ければ段差に坂を作って越える）。道の高さ（`PlanRoadHeights`）は両端をゲートの高さに固定して坂の目安以下にならし、道の所だけ削る・盛る（切り通し・盛り土）。両端の差を登りきれない時は坂の上限を最大 +3% 上げる。検証で陸の高低差と段・崖の割合の下限を見る（`RequireRelief`）。
  - **T3 渓流の坂道**（`Generation/FieldMapGenerator.Slope.cs`、260 × 110m）：深い谷（谷の壁は渓流から離れるほど高い）、谷を横切る段（3〜5m。渓流はここで小さな滝になり、下に滝つぼ）、段の切れ目は左右に互い違い（本道はつづら折り）、渓流沿いの崖（狭い谷。真ん中に渡れる切れ目）、湧水の淵（シモマダラ）、石積みの跡、滝の上の岩棚（隠れた場所）、東屋。本道の坂は 11%（滝の山の入口は村のゲート＋24〜30m）。
- **マップごとの配置データ**（2026-10-17。§10.2・§13.1 の3。`Generation/FieldMapLayout.cs`）：星の配置データ（＝村の `WorldLayout`）の下に、村の外のマップの配置データ（`WorldLayout.Maps`）を付ける。マップは離れた座標にあるので位置からマップが決まる（`LayoutAt`・`LayoutOfArea`・`AllMaps`）。各マップの配置データには、エリア（草原・花畑・林・小川・池・丘の上・湖・湖の静かな岸・岬・森）、水域、**釣り場**（村と同じタグ：小川は瀬・浅瀬・よどみ・水草、池は浅場・中層・湧水・泥底・濁り・静かな岸、湖は浅場・中層・深場・最深部（岬の先）・泥底・砂泥底・濁り（流れ込み）・静かな岸・桟橋）、**生息地点**（自然物・水辺の泥・水面・隠れた場所の結晶）、高さ・水・水深の判定が入る。
  - 村の配置データの高さ・水・水深・エリアの問い合わせは、位置が村の外のマップならそのマップに回す（生き物の足元・連れて歩く子・天候の局所差（湖の霧）・地名がそのまま動く）。
  - **釣り**（`FishSpawnModel`）：村と村の外のマップの釣り場をすべて読み、投げた先の水面はその位置のマップで判定する。
  - **生き物**（`CreatureSystem.Spawning`）：村か村の外のマップにいるプレイヤーのまわりに、そのマップの生息地点から出す（野生の個体のエリアはプレイヤーのいるマップ）。餌で呼ぶのも村の外のマップで動く。
  - 住民の行き先・地図アプリ・踏み跡などは今までどおり村の配置データだけを使う。
  - 100シード：花の野道 釣り場 17〜19・住める魚 17種・生息地点 約420・好む地点のある生き物 約36種、湖の森 釣り場 約43・住める魚 34種・生息地点 約620・生き物 約26種。スモークテストで、花の野道と湖の森に野生の生き物が出て、釣り場の魚影ができることを確かめた。
- **試作の割り切り**（§13.1 の4以降で直す）：村には版2の湖・滝・滝の裏の洞・静かな高台・桟橋が残る（100種の住める場所を減らさないため。湖の森に湖があっても、村の湖もそのまま）。村の外のマップに**住民はまだ来ない**（住民のマップをまたぐ移動は §13.1 の5）。地図アプリは村の地図だけ。T2〜T6・R3〜R5 は骨格だけで、マップは作らない。近道（§3.4）はまだ無い。ロードした時に村の外のマップにいた場合は、そのマップの入口から再開する。

## 生成バージョン2（2026-10-16。`Docs/Design/uchujin_no_hoshi_world_map_seed_design_v0_2.md` §2 の設計決定）
版3の村も、この版2の作り方で作る（2026-10-17 から新しい星は版3）。**版1で作った星は版1のまま作る**（`WorldGenerator.Generate(seed, 星の worldGenVersion)`。乱数のキーも `world.gen1.*` / `world.gen2.*` で別）。版2の処理は `Generation/WorldGenerator.V2.cs` にまとめ、既存の処理からは `if (V2)` で呼ぶ。版1の結果は変更前のコードと20シードで一致することを確かめた（地形・施設・釣り場・道の要約）。
- **湖を必ず作る**（§2.3）：差し渡し90m以上（岸の波打ちを含めて一番狭い所で）・最深部9〜11.5m。方角で遠浅（浅場）・急深・泥の入り江・砂泥底を分ける。山から湖へ小川が注ぎ、流れ込み口は濁り。最深部の近くまで細い岬（陸）が突き出し、そこから最深部を狙える（本道の行き先）。岬の反対側の、道・家・見晴らし台から40m以上離れた岸が「静かな岸」。水の種類 `WaterType.Lake`／`WaterKind.Lake`、エリア `AreaType.Lake`。
- **川の区間**（§2.4）：勾配と曲がりから 急流（滝の下30m・6%以上）・早瀬（4〜6%）・瀬（2〜4%）・淵（曲がりの外側）・よどみ（内側）・水草帯 のタグを付け、足りなければ近い条件の釣り場に付け足す（各2か所以上）。上流の淵1か所と森の池1か所を「冷たい湧水」にする。
- **歩いて渡れる浅瀬**（§2.7）：勾配2〜4%の所（本流で足りなければ中流に2か所）の川底を浅くし（水深0.5m前後）、飛び石を並べる。版2の星では深さ0.6mを超える水に入れない（`WorldLayout.WaterDepthSampler`・`PlayerController.LimitWading`）。橋の上は通れる。
- **8m以上の滝**（§2.10）：本流の上流側で地形の落差が一番大きい所を選び、上流側の地面を盛って崖にする（落差9m）。滝つぼは深さ3m以上に掘る。滝つぼの脇の崖に**滝の裏の洞**の入口（`Scene/WaterfallCaveBuilder`。別エリア `cave:waterfall`、屋外から離れた座標）。中の暗い淵は釣り場 `spot.waterfall_cave`（タグ behind_waterfall / dark）。
- **静かな高台**（§2.6）：海から遠く、見晴らしの丘・山から離れた場所に、上が平らな高い丘（高さ17〜22m）。家・見晴らし台から80m、本道から75m 以上離す（道の探索の重みで本道を遠ざけ、検証で確かめる）。木立（5本以上）・草地・小さな池（直径13〜17m）を置き、灰色の小道だけでつなぐ（`RoadSegment.Trail`）。エリア `area.highland.quiet`（`AreaRegion.quiet = true`）。住民の行き先には選ばれない（`WorldLayout.GetVisitableAreas`）。
- **桟橋を必ず作る**（§2.9）：海岸線から沖へ22m。先端の釣り場と、岩の突端の釣り場が「沖」。海の釣り場には砂底・海底近く・岩場・砂泥底を必ずそろえる。
- **鍛冶屋・修理屋**（§2.12）：広場から離れて建つ時も、広場から道のりで180m以内。
- **住宅区画**：最低15・目標17（同時居住の上限15人。引っ越しの入れ替わり用に少し空き家）。版1の星は従来どおり最低20・目標24。
- **検証**（`ValidateV2`）：湖の大きさ・深さ・釣り場のタグ（浅場・中層・最深部・泥底・砂泥底）、濁り・静かな岸・泥底の数、川の区間、冷たい湧水の水域、滝の落差と洞の入口、桟橋と沖、静かな高台の離れ方と池、鍛冶屋・修理屋の道のり。足りなければ別の乱数系列で作り直す。湖・桟橋・滝・静かな高台が無いのは最後の試行でも致命的。
- **大量シード検査**：`Editor/WorldSeedAudit.cs`（`Tools/Unity-Check.ps1 -Mode SeedAudit -Seeds N`、メニュー「宇宙人の星 → 検証 → ワールド生成の大量シード検査」）。魚50種・生物50種の生息地・天候の間隔・道のり・再現性・地図の画像（`Logs/WorldAudit/`）。

## 実装した内容（仕様との対応）
- **シードからの決定的生成**（§1.1〜1.4、§15）：用途ごとに独立した乱数キー（`world.gen1.aN.*`）。同じシード・同じ生成バージョンなら同じ結果（コンソール検証で確認）。生成バージョンは `WorldTuning.GeneratorVersion`、星の `worldGenVersion` で作る（版1の星は版1のまま）。
- **地形**（§3.1）：海岸の向き・海岸線のゆらぎ・山（鉱山）・高台（見晴らし台）・平地のうねり・外周の丘。シードで海の方角・山の位置・川の流れ・池の数・村の場所・配色が変わる。
- **水系**：山の中腹から海へ蛇行する本流（上流で落差の大きい所を滝に）、55%で池へ注ぐ小川、池2〜4個、片側の海。
- **村**（§2.2、§4）：広場（目印の大きな木・井戸・掲示板・ベンチ・街灯・看板）、広場を囲む主人公の商店・伝言広場（商店の隣）・種屋・雑貨屋・家具職人・共用調理場・鍛冶屋・修理屋。40%ずつ鍛冶屋は鉱山への道沿い、修理屋は不時着地への道沿いに建つ（ロケット仕様 §15.2）。釣り小屋は村に近い水辺（裏に小さな桟橋）。海岸が近ければ桟橋。
- **主人公の拠点**（§6）：家＋農場 `FarmRect`（24m×18m、平坦）＋周囲 12m の拡張用の余地（平坦・木や家を置かない・道が避ける）。柵は余地の3辺（家の側は開ける、コライダーなし）。
- **不時着地**（§9）：村から 100〜165m の開けた場所。クレーター（中央は平ら）・残骸・工具箱・煙。`PlayerSpawn` はクレーターの外の村側。
- **鉱山入口**（§8）：山の斜面を均した前庭、岩肌・木枠・暗い入口・レール・トロッコ・ランタン。
- **道路**（§3.2）：広場から各目的地へ A*、さらに近道を2本、森の小道。川を渡る所は橋（`bridgeEdges`、橋の上は `HeightAt` が橋板を返す）。施設の入口・各住宅の入口を道路グラフに接続。
- **住宅区画**（§5.1）：道沿いに最大24区画（最低20、足りなければ外周に追加）、各区画に `FacilityInfo(ResidentHouse, plotIndex)`（`id = facility.house.N`、`HousePlot.facilityId` も設定済み）。
- **釣り場**（釣り仕様 §6）：川（`river` `upstream/downstream` `deep/shallow` `bridge` `waterfall` `estuary` `forest` `rocky` `village` `stream`）、池（`pond` `still` `deep/shallow` `forest` `village`）、海（`sea` `beach/rocky` `estuary`）、桟橋（`sea` `pier` `deep`）。通常 35〜60 箇所。
- **生息地点**（生き物仕様 §4・§7.3）：`tree` `bush` `rock` `flower` `grass` `mushroom` `fallen_log` `reed` `shell` `crystal` `mud` `water` `sand` `roof` `window` `garden` `streetlight` `bench` `well` `box` `debris` `cave` `lookout` `field`。通常 900〜1200 点。
- **エリア**：方角つきの名前（例「東の森」「南の浜辺」「川の上流」「北西の住宅地」）。HUD の地域名に使われる。
- **検証と再試行**（§16）：必須施設・道でつながるか・入口が道に近いか・家/鉱山/不時着地/釣り小屋までの道のり・区画数・釣り場数・生息地点数・農場の平坦さ・開始地点。問題があれば別の乱数系列で決定的に再試行（最大6回）。200シードで全件成立（約1割が再試行）。
- **表示**：ランタイム生成のカラーマップ（草・森の床・花畑・砂浜・岩肌・道・石畳・農場の土・クレーター）を貼ったチャンク地形と MeshCollider、外周の見た目の地形、水面（海・川・池・滝）、外周の見えない壁。建物は施設ごとに特徴のある外観。街灯（Light付き）・窓・ランタンは夜（18〜6時、暗い天気）に灯る。
- **看板**（宇宙語）：`ISpeechService.RenderWord("PLACE:"+facilityId)` を `WorldLabels`（宇宙語スタイル）で表示。翻訳しない。広場の出口には矢印つきの道標。
- **引っ越しで村が変わる**（§5.3、§11）：`ResidentMovedInEvent/OutEvent` と2秒ごとの確認で、区画の外観を作り直す（住民の系統・色で家の形と色が変わる。空き地は「空き家」の看板。引っ越し準備中は荷物の箱）。
- **生活による変化**（§11）【提案を実装】：
  - 踏み跡：プレイヤー（マルチは全員）と住民がよく通る所の草が踏まれて土の道の色になる。毎日少し戻る。`SaveScope.Planet`。
  - 公共施設の整備：広場の花壇・伝言広場の飾り・見晴らし台の東屋・橋の灯り・桟橋の延長・池の木の桟橋・森の休憩所・小さな公園を、シードの順に1つずつ。住民の暮らし（商店の売上・依頼の達成・贈り物・修理）と毎日の進み、主人公の寄付（材料・100G、`ContributeToProjectCommand`）で完成。ロケット修理の必須条件ではない。
- **地図アプリ**（§13、AppId `"map"`、M キー）：上から見た地図（陰影・等高線・建物の形）、探索した範囲だけ表示（霧）、プレイヤーと他のプレイヤーの位置、自分の拠点（家・畑・自分の店・宇宙船）だけ自分の言葉で表示、ピン（名前・自由メモ・色）、看板で見た宇宙語（見た場所に表示・自分の推測を書き添え可能）。施設の用途や和名は出さない。看板を調べると資料ボックスに「看板の文字」（事実のみ）を追加。`SaveScope.PlayerPlanetKnowledge`（星ごと・個人ごと）。タブレットが無い場合は M キーで予備ウィンドウ。

## 未実装・簡略化
- 住民が置いた物（日常の痕跡のうち「物」）は未実装（踏み跡で代替）。住民モジュール側のイベント・契約が無いため。
- 地図の「写真」「住民の家に呼び名を関連付け」「生物・魚の発見場所の自動記録」（§13.1）は未実装（ピンとメモで代用可能）。
- 版1の星では川の上を歩いて渡れる（泳ぎは無く、川底を歩く）。版2の星では深さ0.6mまでの浅瀬と橋だけ（上の「生成バージョン2」）。
- 地形のセルフシャドウ（地形メッシュは影を落とさない設定）。
- 鍛冶屋・修理屋の「担当住民」は住民モジュールが `ownerResidentId` に設定（World は設定しない）。

## Unity 上で確認が必要な点
- 見た目全般（配色・建物の大きさ・看板ラベルの位置・夜の灯りの明るさ・水の透明度）。URP では `MaterialCache` の透明設定、`Sprites/Default`（滝などには未使用、Weather 側）の可否。
- 読み込み時間（生成はコンソールで 0.15〜0.4 秒。Unity 上ではカラーマップ作成・メッシュ結合が加わる）。
- 点光源の数（街灯 30 前後＋家の灯り）。Built-in の Pixel Light Count / URP の追加ライト上限で見え方が変わる。
- 住民の歩行：道路グラフ・橋の高さ・入口の位置（`FacilityInfo.entrance` は建物前の地面）。
- 鉱山入口の外観と Mining のポータル位置（`Layout.MineEntrance` は入口の開口部の地面、正面は `rotationY`）。
- 主人公の商店の土台（Shop の店舗が `facility.player_shop` の position/rotationY/size(10×4.5×8) に合うか）。

## 他モジュールとの連携
- 設定する：`ctx.Layout` / `WorldSystem.Layout`（`Game.Layout`）、`ctx.Shared["world.generated"]`（内部データ）。

- 購読：`ResidentMovedInEvent` `ResidentMovedOutEvent` `ShopItemSoldEvent` `QuestStateChangedEvent` `GiftGivenEvent` `RocketDeviceRepairedEvent`。
